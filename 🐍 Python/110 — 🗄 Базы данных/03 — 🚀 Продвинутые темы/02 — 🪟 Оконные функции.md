# 🪟 Оконные функции — памятка

> Оконные функции вычисляют результат по набору строк (окну) без группировки — каждая строка остаётся в результате. Мощный инструмент для ранжирования, нарастающих итогов, сравнения со средним.

## Справка

| Функция | Категория | Что делает |
|---|---|---|
| `ROW_NUMBER()` | Ранжирование | Уникальная нумерация строк (1, 2, 3...) |
| `RANK()` | Ранжирование | Ранг с пропусками при одинаковых (1, 2, 2, 4) |
| `DENSE_RANK()` | Ранжирование | Ранг без пропусков (1, 2, 2, 3) |
| `NTILE(n)` | Ранжирование | Разбить строки на n групп |
| `SUM()` | Агрегат | Сумма по окну |
| `AVG()` | Агрегат | Среднее по окну |
| `COUNT()` | Агрегат | Количество по окну |
| `MIN()` / `MAX()` | Агрегат | Мин/макс по окну |
| `FIRST_VALUE(col)` | Смещение | Первое значение в окне |
| `LAST_VALUE(col)` | Смещение | Последнее значение в окне |
| `NTH_VALUE(col, n)` | Смещение | N-е значение в окне |
| `LAG(col, n)` | Смещение | Значение n строк назад |
| `LEAD(col, n)` | Смещение | Значение n строк вперёд |

## 📊 Общая схема

```
Без GROUP BY:                   С оконной функцией:
SELECT dept, SUM(salary)        SELECT name, dept, salary,
FROM Employees                         SUM(salary) OVER (PARTITION BY dept)
GROUP BY dept;                  FROM Employees;

→ 2 строки (по dept)            → 5 строк (все сотрудники!)
→ имена сотрудников пропали     → у каждого видна сумма по отделу

Синтаксис оконной функции:
функция() OVER (
    PARTITION BY col   ← разбить на окна
    ORDER BY col       ← порядок внутри окна
    ROWS/RANGE ...     ← границы окна
)
```

## 🎯 Синтаксис OVER

| Клауза | Что делает |
|---|---|
| `OVER ()` | окно = вся таблица |
| `OVER (ORDER BY col)` | окно нарастающее — от первой до текущей строки |
| `OVER (PARTITION BY col)` | отдельное окно для каждого значения col |
| `OVER (PARTITION BY col ORDER BY col2)` | раздел + порядок внутри |

```sql
-- Вся таблица как одно окно
SELECT salary,
       SUM(salary) OVER () AS total_payroll
FROM Employees;

-- Отдельное окно для каждого отдела
SELECT name, department, salary,
       SUM(salary) OVER (PARTITION BY department) AS dept_payroll
FROM Employees;

-- Результат:
-- name  | department | salary | dept_payroll
-- ------+------------+--------+--------------
-- Alice | HR         | 70000  | 195000
-- Bob   | HR         | 60000  | 195000
-- Carol | HR         | 65000  | 195000
-- Dan   | IT         | 80000  | 160000
-- Eve   | IT         | 80000  | 160000

-- Ранжирование внутри каждого отдела
SELECT name, department, salary,
       ROW_NUMBER() OVER (PARTITION BY department ORDER BY salary DESC) AS rank
FROM Employees;
```

## 🔢 Ранжирующие функции

| Функция | Одинаковые значения | Пример |
|---|---|---|
| `ROW_NUMBER()` | разные номера | 1, 2, 3, 4 |
| `RANK()` | одинаковый ранг + пропуск | 1, 2, 2, 4 |
| `DENSE_RANK()` | одинаковый ранг без пропуска | 1, 2, 2, 3 |
| `NTILE(n)` | разбивает на n групп | 1, 1, 2, 2, 3 |

```sql
-- ROW_NUMBER — строго уникально
SELECT name, salary,
       ROW_NUMBER() OVER (ORDER BY salary DESC) AS row_num
FROM Employees;
-- 1, 2, 3, 4, 5 — всегда уникально

-- RANK — пропуски при одинаковых
SELECT name, salary,
       RANK() OVER (ORDER BY salary DESC) AS rnk
FROM Employees;
-- 1, 2, 2, 4, 5 — после двух вторых сразу четвёртый

-- DENSE_RANK — без пропусков
SELECT name, salary,
       DENSE_RANK() OVER (ORDER BY salary DESC) AS dense_rnk
FROM Employees;
-- 1, 2, 2, 3, 4 — после двух вторых идёт третий

-- NTILE — разбить на 4 квартиля
SELECT name, salary,
       NTILE(4) OVER (ORDER BY salary) AS quartile
FROM Employees;
-- 1, 1, 2, 2, 3, 3, 4, 4

-- Топ-1 в каждом отделе
SELECT * FROM (
    SELECT name, department, salary,
           RANK() OVER (PARTITION BY department ORDER BY salary DESC) AS rnk
    FROM Employees
) t
WHERE rnk = 1;
```

## 📊 Агрегатные функции как оконные

```sql
-- Зарплата сотрудника + средняя по отделу
SELECT name, department, salary,
       ROUND(AVG(salary) OVER (PARTITION BY department), 2) AS dept_avg,
       salary - AVG(salary) OVER (PARTITION BY department) AS diff_from_avg
FROM Employees;

-- Результат:
-- name  | dept | salary | dept_avg | diff_from_avg
-- ------+------+--------+----------+---------------
-- Alice | HR   | 70000  | 65000    | +5000
-- Bob   | HR   | 60000  | 65000    | -5000
-- Carol | HR   | 65000  | 65000    | 0

-- Нарастающая сумма (running total)
SELECT name, salary,
       SUM(salary) OVER (ORDER BY id) AS running_total
FROM Employees;

-- Результат:
-- name  | salary | running_total
-- ------+--------+--------------
-- Alice | 70000  | 70000
-- Bob   | 60000  | 130000
-- Carol | 65000  | 195000

-- % от общей суммы
SELECT name, salary,
       ROUND(salary / SUM(salary) OVER () * 100, 1) AS pct_of_total
FROM Employees;
```

## 📍 Функции смещения

```sql
-- LAG — значение предыдущей строки
SELECT name, salary,
       LAG(salary) OVER (ORDER BY id) AS prev_salary,
       salary - LAG(salary) OVER (ORDER BY id) AS salary_change
FROM Employees;

-- Результат:
-- name  | salary | prev_salary | salary_change
-- ------+--------+-------------+---------------
-- Alice | 70000  | NULL        | NULL
-- Bob   | 60000  | 70000       | -10000
-- Carol | 65000  | 60000       | +5000

-- LEAD — значение следующей строки
SELECT name, salary,
       LEAD(salary) OVER (ORDER BY id) AS next_salary
FROM Employees;

-- LAG/LEAD с шагом и значением по умолчанию
SELECT name, salary,
       LAG(salary, 2, 0) OVER (ORDER BY id) AS two_rows_back
FROM Employees;
-- LAG(col, n, default) — n строк назад, default если нет

-- FIRST_VALUE — первое в окне
SELECT name, department, salary,
       FIRST_VALUE(salary) OVER (PARTITION BY department ORDER BY salary DESC) AS top_salary
FROM Employees;

-- LAST_VALUE — последнее в окне (нужны явные границы!)
SELECT name, department, salary,
       LAST_VALUE(salary) OVER (
           PARTITION BY department
           ORDER BY salary DESC
           ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING
       ) AS min_salary
FROM Employees;

-- NTH_VALUE — n-е значение
SELECT name, salary,
       NTH_VALUE(salary, 2) OVER (ORDER BY salary DESC) AS second_highest
FROM Employees;
```

## 🎪 Границы окон ROWS и RANGE

По умолчанию при `ORDER BY` окно = от начала до текущей строки. Изменить можно через `ROWS` или `RANGE`:

```sql
функция() OVER (
    ORDER BY col
    ROWS BETWEEN начало AND конец
)
```

| Граница | Что означает |
|---|---|
| `UNBOUNDED PRECEDING` | от самой первой строки |
| `n PRECEDING` | n строк назад от текущей |
| `CURRENT ROW` | текущая строка |
| `n FOLLOWING` | n строк вперёд от текущей |
| `UNBOUNDED FOLLOWING` | до самой последней строки |

```sql
-- Скользящее среднее за 3 строки (текущая + 2 предыдущих)
SELECT name, salary,
       AVG(salary) OVER (
           ORDER BY id
           ROWS BETWEEN 2 PRECEDING AND CURRENT ROW
       ) AS moving_avg
FROM Employees;

-- Сумма от начала до конца (вся таблица)
SELECT name, salary,
       SUM(salary) OVER (
           ORDER BY id
           ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING
       ) AS grand_total
FROM Employees;

-- LAST_VALUE правильно — нужно UNBOUNDED FOLLOWING
SELECT name, salary,
       LAST_VALUE(name) OVER (
           ORDER BY salary
           ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING
       ) AS richest
FROM Employees;

-- ROWS vs RANGE:
-- ROWS — физические строки (по позиции)
-- RANGE — логические строки (одинаковые значения ORDER BY как одна группа)
```

## 🪟 Именованные окна WINDOW

Когда одно окно используется несколько раз — вынеси в `WINDOW`:

```sql
-- Без WINDOW — дублирование
SELECT name, salary,
       SUM(salary) OVER (PARTITION BY department ORDER BY salary) AS running_sum,
       AVG(salary) OVER (PARTITION BY department ORDER BY salary) AS running_avg,
       COUNT(*) OVER (PARTITION BY department ORDER BY salary) AS running_count
FROM Employees;

-- С WINDOW — один раз определил, везде используешь
SELECT name, salary,
       SUM(salary) OVER w AS running_sum,
       AVG(salary) OVER w AS running_avg,
       COUNT(*) OVER w AS running_count
FROM Employees
WINDOW w AS (PARTITION BY department ORDER BY salary);
```

## ⚡ Быстрые примеры

```sql
-- Ранг по зарплате в отделе
SELECT name, dept, salary,
       RANK() OVER (PARTITION BY dept ORDER BY salary DESC) AS rnk
FROM Employees;

-- Нарастающий итог
SELECT date, amount,
       SUM(amount) OVER (ORDER BY date) AS cumulative
FROM Sales;

-- Сравнение с предыдущим периодом
SELECT month, revenue,
       LAG(revenue) OVER (ORDER BY month) AS prev_revenue,
       revenue - LAG(revenue) OVER (ORDER BY month) AS growth
FROM Monthly;

-- % от общего
SELECT name, salary,
       ROUND(salary * 100.0 / SUM(salary) OVER (), 1) AS pct
FROM Employees;

-- Топ-3 в каждом отделе
SELECT * FROM (
    SELECT *, DENSE_RANK() OVER (PARTITION BY dept ORDER BY salary DESC) AS dr
    FROM Employees
) t WHERE dr <= 3;

-- Скользящее среднее за 7 дней
SELECT date, value,
       AVG(value) OVER (ORDER BY date ROWS BETWEEN 6 PRECEDING AND CURRENT ROW) AS ma7
FROM DailySales;
```

## 💡 Практические замечания

- Оконные функции нельзя использовать в `WHERE` и `HAVING` — только в `SELECT` и `ORDER BY`
- Для фильтрации по результату оконной функции — оберни в подзапрос или CTE
- `LAST_VALUE` без явных границ окна работает неожиданно — всегда добавляй `ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING`
- `LAG`/`LEAD` без значения по умолчанию возвращают `NULL` для первой/последней строки
- `ROWS` работает с физическими строками, `RANGE` — с логическими группами одинаковых значений

## ⚠️ Частые ошибки

**❌ Оконная функция в WHERE:**
```sql
SELECT * FROM Employees
WHERE RANK() OVER (ORDER BY salary) <= 3;  -- ❌ ошибка!

SELECT * FROM (
    SELECT *, RANK() OVER (ORDER BY salary) AS rnk FROM Employees
) t WHERE rnk <= 3;  -- ✅
```

**❌ LAST_VALUE без границ:**
```sql
LAST_VALUE(name) OVER (ORDER BY salary)
-- ❌ вернёт текущую строку, не последнюю!

LAST_VALUE(name) OVER (
    ORDER BY salary
    ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING
)  -- ✅
```

**❌ Путаешь RANK и DENSE_RANK:**
```sql
-- RANK: 1, 2, 2, 4 (пропускает 3)
-- DENSE_RANK: 1, 2, 2, 3 (без пропуска)
-- Для рейтинга без дыр — всегда DENSE_RANK
```

---

## ✅ Главные правила

✅ `PARTITION BY` — разбивает на окна, `ORDER BY` — порядок внутри окна  
✅ `ROW_NUMBER` — уникально, `RANK` — с пропусками, `DENSE_RANK` — без пропусков  
✅ Агрегатные функции с `OVER` — не группируют строки  
✅ `LAG(col, n, default)` — n строк назад, `LEAD` — вперёд  
✅ `LAST_VALUE` — всегда нужны явные границы `ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING`  
✅ Оконные функции нельзя в `WHERE` — используй подзапрос или CTE  
✅ `WINDOW w AS (...)` — именованное окно чтобы не дублировать
