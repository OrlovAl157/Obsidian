# 🧰 Диагностические команды — метаданные и состояние сервера

> Команды, которые не читают данные **из** таблиц, а показывают информацию **о** структуре базы, индексах и состоянии сервера. `EXPLAIN` разобран отдельно — [[07 — 📈 EXPLAIN и анализ запросов|EXPLAIN и анализ запросов]].

## Справка

| Команда | Что показывает |
| --- | --- |
| `DESCRIBE table` (`DESC table`) | Колонки таблицы: тип, `NULL`/`NOT NULL`, ключи, default |
| `DESCRIBE SELECT ...` | Синоним `EXPLAIN SELECT ...` — исторический алиас |
| `SHOW CREATE TABLE table` | Полный `CREATE TABLE` (включая индексы, `FOREIGN KEY`) |
| `SHOW INDEX FROM table` | Все индексы таблицы |
| `SHOW PROCESSLIST` | Активные подключения и выполняющиеся прямо сейчас запросы |
| `SHOW STATUS` | Статистика сервера (запросы, соединения, кэш) |
| `SHOW VARIABLES LIKE '...'` | Текущие настройки сервера |
| `ANALYZE TABLE table` | Пересчитывает статистику для оптимизатора |

## 🧱 DESCRIBE — структура таблицы

```sql
DESCRIBE Books;
-- Field  | Type         | Null | Key | Default | Extra
-- id     | int          | NO   | PRI | NULL    | auto_increment
-- title  | varchar(255) | YES  |     | NULL    |
-- author | varchar(255) | YES  | MUL | NULL    |
-- price  | decimal(6,2) | YES  |     | NULL    |
```

Быстрый способ узнать структуру таблицы, не открывая `CREATE TABLE` целиком. `MUL` в `Key` — колонка участвует в обычном (не уникальном) индексе.

## 👁 SHOW — разные варианты

**Полная структура таблицы (с индексами и ограничениями):**
```sql
SHOW CREATE TABLE Books;
-- выдаёт CREATE TABLE целиком, которым можно пересоздать таблицу
```

**Все индексы таблицы** (быстрее, чем искать их по `SHOW CREATE TABLE`):
```sql
SHOW INDEX FROM Books;
```

**Что сейчас выполняется на сервере** — полезно искать "зависший" запрос:
```sql
SHOW PROCESSLIST;
-- Id | User | Host | db | Command | Time | State | Info
```

**Настройки сервера**, например уровень изоляции транзакций:
```sql
SHOW VARIABLES LIKE '%isolation%';
-- аналог: SELECT @@transaction_isolation;
```

## 🔄 ANALYZE TABLE — обновление статистики

```sql
ANALYZE TABLE Orders;
```

Пересчитывает внутреннюю статистику таблицы (число строк, разнообразие значений в колонках) — именно её использует оптимизатор, решая между индексом и full table scan.

> 💡 Запускать после массовых изменений данных (удаление/вставка большого числа строк) — устаревшая статистика может привести к неоптимальному плану в `EXPLAIN` (например, `type = ALL` там, где индекс был бы выгоднее).

## 💡 Практические замечания

- `DESCRIBE` перед именем таблицы — структура; `DESCRIBE` перед `SELECT` — синоним `EXPLAIN`
- `SHOW CREATE TABLE` надёжнее для копирования структуры, чем `DESCRIBE` — включает индексы и внешние ключи
- Расхождение прогноза и факта в `EXPLAIN ANALYZE` — сигнал запустить `ANALYZE TABLE`
- Эти команды не относятся к функциям/операторам SQL — это отдельные top-level команды интроспекции
