SQL JOIN — шпаргалка

Как объединяются таблицы A (левая) и B (правая)

INNER JOIN
Только строки с совпадением в обеих таблицах
SELECT * FROM A INNER JOIN B ON A.id = B.id;
LEFT JOIN
Все строки из A + совпадения из B. Нет совпадения — NULL
SELECT * FROM A LEFT JOIN B ON A.id = B.id;
RIGHT JOIN
Все строки из B + совпадения из A. Нет совпадения — NULL
SELECT * FROM A RIGHT JOIN B ON A.id = B.id;
FULL OUTER JOIN
Все строки из A и B. Нет совпадения — NULL с обеих сторон
SELECT * FROM A LEFT JOIN B ... UNION SELECT * FROM A RIGHT JOIN B ...;
LEFT EXCLUDING JOIN
Только строки из A которых нет в B
SELECT * FROM A LEFT JOIN B ON A.id = B.id WHERE B.id IS NULL;
RIGHT EXCLUDING JOIN
Только строки из B которых нет в A
SELECT * FROM A RIGHT JOIN B ON A.id = B.id WHERE A.id IS NULL;
