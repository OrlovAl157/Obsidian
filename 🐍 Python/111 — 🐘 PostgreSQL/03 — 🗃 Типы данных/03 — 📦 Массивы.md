# 📦 Массивы — памятка

> PostgreSQL поддерживает массивы как полноценный тип данных. Любой тип можно использовать как массив: `INTEGER[]`, `TEXT[]`, `BOOLEAN[]`. Это уникальная возможность PostgreSQL, отсутствующая в MySQL.

## Справка

| Оператор/функция | Что делает |
|---|---|
| `arr[1]` | элемент массива (индекс с 1!) |
| `arr[1:3]` | срез массива |
| `@>` | содержит ли элемент |
| `<@` | является ли подмножеством |
| `&&` | есть ли общие элементы |
| `ANY(arr)` | совпадает ли с любым элементом |
| `ALL(arr)` | совпадает ли со всеми |
| `array_append(arr, val)` | добавить элемент |
| `array_remove(arr, val)` | удалить элемент |
| `array_length(arr, dim)` | длина массива |
| `unnest(arr)` | развернуть в строки |
| `ARRAY_AGG(col)` | собрать в массив |

## 🟢 Создание и вставка

```sql
CREATE TABLE Articles (
    id      SERIAL PRIMARY KEY,
    title   TEXT,
    tags    TEXT[],
    scores  INTEGER[]
);

-- Вставка
INSERT INTO Articles (title, tags, scores)
VALUES
    ('PostgreSQL', ARRAY['sql', 'db', 'open-source'], ARRAY[10, 8, 9]),
    ('Python',     '{python, programming}',            '{9, 7, 10}');
```

---

## 🔵 Извлечение данных

```sql
-- Индексация с 1 (не с 0!)
SELECT tags[1] FROM Articles;       -- первый элемент
SELECT tags[1:2] FROM Articles;     -- срез: первые два

-- Поиск по массиву
SELECT * FROM Articles WHERE 'sql' = ANY(tags);
SELECT * FROM Articles WHERE tags @> ARRAY['sql', 'db'];  -- содержит оба

-- Развернуть массив в строки
SELECT title, unnest(tags) AS tag FROM Articles;
```

## 🔴 Операторы и функции

```sql
-- @> — содержит ли все элементы
SELECT * FROM Articles WHERE tags @> '{sql, db}';

-- && — есть ли общие элементы
SELECT * FROM Articles WHERE tags && '{python, sql}';

-- Добавить элемент
UPDATE Articles
SET tags = array_append(tags, 'new-tag')
WHERE id = 1;

-- Удалить элемент
UPDATE Articles
SET tags = array_remove(tags, 'old-tag')
WHERE id = 1;

-- Длина массива
SELECT array_length(tags, 1) FROM Articles;   -- 1 = первое измерение

-- Собрать значения в массив
SELECT ARRAY_AGG(name ORDER BY name) FROM Authors;
```

---

## ✅ Главные правила

✅ Индексация массивов в PostgreSQL начинается с **1**, не с 0  
✅ `ANY(arr)` — проверить вхождение элемента  
✅ `@>` — содержит ли все указанные элементы  
✅ `unnest()` — развернуть массив в строки для аналитики  
✅ GIN-индекс ускоряет операторы `@>`, `&&` на массивах
