## Справка

| Понятие | Описание |
|---|---|
| `SELECT` | извлечь данные |
| `INSERT` | добавить данные |
| `UPDATE` | изменить данные |
| `DELETE` | удалить данные |

## 🟢 Базовые концепции

```sql
-- Порядок выполнения SELECT
FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT

-- Строковые литералы — только одинарные кавычки!
SELECT 'Hello World';   -- ✅
SELECT "Hello World";   -- ❌ в PostgreSQL двойные кавычки для имён объектов

-- Имена объектов с пробелами или зарезервированными словами — двойные кавычки
SELECT "first name" FROM Users;
CREATE TABLE "my table" (...);

-- Комментарии
-- Однострочный
/* Многострочный */
```

## 🔵 Отличия от MySQL

| Возможность | PostgreSQL | MySQL |
|---|---|---|
| Строки | только `'...'` | `'...'` и `"..."` |
| Регистронезависимый поиск | `ILIKE` | нет (нужен `LOWER()`) |
| Приведение типа | `::type` или `CAST` | только `CAST` |
| Автоинкремент | `SERIAL`, `GENERATED AS IDENTITY` | `AUTO_INCREMENT` |
| FULL JOIN | ✅ | ❌ |
| EXCEPT/INTERSECT | ✅ | только с 8.0 |
| Массивы как тип | ✅ | ❌ |
| JSONB | ✅ | ограниченно |
| Схемы | ✅ | ❌ |

---

## ✅ Главные правила

✅ Строки — только одинарные кавычки `'...'`  
✅ Имена объектов — двойные кавычки `"..."` (только при необходимости)  
✅ `NULL = NULL` → NULL, используй `IS NULL`  
✅ PostgreSQL чувствителен к регистру в именах только если использованы `"..."`
