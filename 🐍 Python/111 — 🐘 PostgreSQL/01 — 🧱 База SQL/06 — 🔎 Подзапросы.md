# 🔎 Подзапросы — памятка

> Подзапрос — SELECT внутри другого SQL-запроса. В PostgreSQL поддерживаются все виды подзапросов, включая `LATERAL` — специальный тип, позволяющий подзапросу ссылаться на строки из предшествующих таблиц.

## Справка

| Тип | Описание |
|---|---|
| Скалярный | возвращает одно значение |
| В WHERE | `WHERE price > (SELECT AVG(price) FROM Books)` |
| В FROM | подзапрос как временная таблица |
| Коррелированный | ссылается на внешний запрос |
| `EXISTS` | проверка существования |
| `LATERAL` | подзапрос с доступом к строкам внешнего запроса |

---

## 🟢 В WHERE

```sql
-- Книги дороже средней цены
SELECT title, price FROM Books
WHERE price > (SELECT AVG(price) FROM Books);

-- IN с подзапросом
SELECT title FROM Books
WHERE author_id IN (SELECT id FROM Authors WHERE country = 'UK');

-- EXISTS
SELECT name FROM Authors a
WHERE EXISTS (
    SELECT 1 FROM Books b WHERE b.author_id = a.id
);
```

---

## 🔵 В FROM

```sql
-- Подзапрос как таблица (нужен псевдоним)
SELECT * FROM (
    SELECT author, COUNT(*) AS cnt
    FROM Books
    GROUP BY author
) AS author_stats
WHERE cnt > 3;
```

---

## 🔴 В SELECT

```sql
-- Коррелированный подзапрос
SELECT
    title,
    price,
    (SELECT AVG(price) FROM Books) AS avg_price,
    price - (SELECT AVG(price) FROM Books) AS diff
FROM Books;
```

---

## 🟣 LATERAL

`LATERAL` — PostgreSQL-специфика. Позволяет подзапросу в `FROM` ссылаться на столбцы из предшествующих таблиц (как коррелированный подзапрос, но в FROM):

```sql
-- Топ-3 книги для каждого автора
SELECT a.name, top_books.title, top_books.price
FROM Authors a,
LATERAL (
    SELECT title, price
    FROM Books b
    WHERE b.author_id = a.id
    ORDER BY price DESC
    LIMIT 3
) AS top_books;
```

---

## ✅ Главные правила

✅ CTE (`WITH`) часто читаемее вложенных подзапросов  
✅ `EXISTS` быстрее `IN` для больших подзапросов  
✅ `LATERAL` — уникальная возможность PostgreSQL  
✅ Подзапрос в `FROM` требует псевдонима (`AS name`)
