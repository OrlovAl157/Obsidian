# 📊 Агрегатные функции — памятка

> Агрегатные функции вычисляют одно значение из набора строк. В PostgreSQL есть `STRING_AGG`, `ARRAY_AGG`, `BOOL_AND`, `BOOL_OR` — аналоги `GROUP_CONCAT` и другие расширения.

## Справка

| Функция | Описание | MySQL аналог |
|---|---|---|
| `COUNT(*)` | количество строк | `COUNT(*)` |
| `COUNT(col)` | количество не-NULL | `COUNT(col)` |
| `SUM(col)` | сумма | `SUM` |
| `AVG(col)` | среднее | `AVG` |
| `MIN(col)` | минимум | `MIN` |
| `MAX(col)` | максимум | `MAX` |
| `STRING_AGG(col, sep)` | склеить строки | `GROUP_CONCAT` |
| `ARRAY_AGG(col)` | собрать в массив | нет |
| `BOOL_AND(col)` | все TRUE? | нет |
| `BOOL_OR(col)` | хотя бы один TRUE? | нет |

---

## 🟢 Основные функции

```sql
SELECT COUNT(*) FROM Books;                      -- 42
SELECT COUNT(author) FROM Books;                 -- без NULL
SELECT COUNT(DISTINCT author) FROM Books;        -- уникальные авторы
SELECT SUM(price) FROM Books;                    -- сумма
SELECT AVG(price)::NUMERIC(10,2) FROM Books;     -- среднее, округлённое
SELECT MIN(price), MAX(price) FROM Books;
```

---

## 🔵 PostgreSQL-специфика

```sql
-- STRING_AGG — аналог GROUP_CONCAT в MySQL
SELECT STRING_AGG(title, ', ') FROM Books;
SELECT author, STRING_AGG(title, ', ' ORDER BY title) FROM Books
GROUP BY author;

-- ARRAY_AGG — собрать в массив
SELECT author, ARRAY_AGG(title ORDER BY price DESC) AS books
FROM Books GROUP BY author;

-- BOOL_AND / BOOL_OR
SELECT BOOL_AND(is_active) FROM Users;   -- все активны?
SELECT BOOL_OR(is_admin) FROM Users;     -- есть хотя бы один admin?
```

---

## 🔴 FILTER — условная агрегация

```sql
-- Считать только дорогие книги
SELECT
    COUNT(*) AS total,
    COUNT(*) FILTER (WHERE price > 10) AS expensive,
    AVG(price) FILTER (WHERE price > 0) AS avg_positive
FROM Books;

-- Эффективнее чем CASE WHEN внутри агрегата
```

---

## ✅ Главные правила

✅ `COUNT(*)` — все строки, `COUNT(col)` — только не-NULL  
✅ `STRING_AGG` — аналог `GROUP_CONCAT` в MySQL  
✅ `ARRAY_AGG` — собрать строки в массив  
✅ `FILTER (WHERE ...)` — условная агрегация без подзапросов  
✅ `::NUMERIC(10,2)` — округлить результат AVG
