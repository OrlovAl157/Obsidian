## Справка

| Функция | Описание |
|---|---|
| `COALESCE(a,b,...)` | первое не-NULL значение |
| `NULLIF(a, b)` | NULL если a = b |
| `CASE WHEN ... THEN ... END` | условное выражение |
| `CAST(val AS type)` | приведение типа (стандарт) |
| `val::type` | приведение типа (PostgreSQL) |
| `GENERATE_SERIES(from, to, step)` | генерация числового ряда |

## 🟢 COALESCE и NULLIF

```sql
-- COALESCE — первое не-NULL
SELECT COALESCE(NULL, NULL, 'default');   -- 'default'
SELECT COALESCE(name, 'Аноним') FROM Users;

-- NULLIF — NULL если два значения равны
SELECT NULLIF(0, 0);       -- NULL
SELECT NULLIF(5, 0);       -- 5
-- Частый паттерн: избежать деления на ноль
SELECT total / NULLIF(count, 0) FROM Stats;
```

## 🔵 CASE

```sql
-- Простой CASE
SELECT title,
    CASE status
        WHEN 'new'    THEN 'Новый'
        WHEN 'active' THEN 'Активный'
        ELSE 'Другой'
    END AS status_ru
FROM Books;

-- Поисковый CASE
SELECT title, price,
    CASE
        WHEN price < 5  THEN 'дёшево'
        WHEN price < 15 THEN 'средне'
        ELSE 'дорого'
    END AS price_category
FROM Books;

-- CASE в ORDER BY
SELECT * FROM Books
ORDER BY CASE status
    WHEN 'new' THEN 1
    WHEN 'active' THEN 2
    ELSE 3
END;
```

## 🔴 GENERATE_SERIES

Мощная PostgreSQL-функция — генерирует ряд значений:

```sql
-- Числовой ряд
SELECT generate_series(1, 10);           -- 1, 2, ..., 10
SELECT generate_series(0, 100, 10);      -- 0, 10, 20, ..., 100

-- Даты
SELECT generate_series(
    '2025-01-01'::DATE,
    '2025-12-31'::DATE,
    '1 month'::INTERVAL
) AS month;

-- Паттерн: заполнить пропуски в данных
SELECT gs::DATE AS date, COALESCE(s.sales, 0) AS sales
FROM generate_series('2025-01-01', '2025-01-31', '1 day') gs
LEFT JOIN DailySales s ON s.date = gs::DATE
ORDER BY date;
```

---

## ✅ Главные правила

✅ `COALESCE` — замена NULL на дефолтное значение  
✅ `NULLIF(a, b)` — превратить конкретное значение в NULL (для деления)  
✅ `GENERATE_SERIES` — генерировать ряды чисел и дат (нет в MySQL)
