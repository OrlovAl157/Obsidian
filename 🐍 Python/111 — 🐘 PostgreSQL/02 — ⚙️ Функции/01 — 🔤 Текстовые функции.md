# 🔤 Текстовые функции — памятка

> Функции для работы со строками в PostgreSQL. Основные отличия от MySQL: `CONCAT_WS`, `SPLIT_PART` вместо `SUBSTRING_INDEX`, `||` для конкатенации.

## Справка

| Функция | Описание | MySQL аналог |
|---|---|---|
| `UPPER(str)` | в верхний регистр | `UPPER` |
| `LOWER(str)` | в нижний регистр | `LOWER` |
| `INITCAP(str)` | первая буква заглавная | нет |
| `LENGTH(str)` | длина в символах | `CHAR_LENGTH` |
| `TRIM(str)` | убрать пробелы | `TRIM` |
| `LTRIM`, `RTRIM` | слева/справа | те же |
| `REPLACE(str,from,to)` | замена | `REPLACE` |
| `CONCAT(a,b,...)` | конкатенация | `CONCAT` |
| `CONCAT_WS(sep,a,b,...)` | с разделителем | `CONCAT_WS` |
| `\|\|` | оператор конкатенации | нет |
| `SUBSTRING(str,pos,len)` | подстрока | `SUBSTRING` |
| `SPLIT_PART(str,delim,n)` | часть по разделителю | `SUBSTRING_INDEX` |
| `POSITION(sub IN str)` | позиция подстроки | `LOCATE` |
| `LPAD`, `RPAD` | дополнить до длины | те же |
| `REVERSE(str)` | перевернуть | `REVERSE` |
| `REPEAT(str, n)` | повторить | `REPEAT` |
| `REGEXP_REPLACE` | замена по регулярке | `REGEXP_REPLACE` |

## 🔡 Регистр

```sql
SELECT UPPER('hello');           -- HELLO
SELECT LOWER('HELLO');           -- hello
SELECT INITCAP('hello world');   -- Hello World (PostgreSQL!)
```

---

## ✂️ Обрезка и замена

```sql
SELECT TRIM('  hello  ');                    -- hello
SELECT TRIM(LEADING '-' FROM '--hello--');   -- hello--
SELECT TRIM(TRAILING '-' FROM '--hello--');  -- --hello
SELECT TRIM(BOTH '-' FROM '--hello--');      -- hello
SELECT LTRIM('   hello');                    -- hello
SELECT RTRIM('hello   ');                    -- hello

SELECT REPLACE('hello world', 'world', 'PostgreSQL');  -- hello PostgreSQL
```

---

## 📏 Длина и поиск

```sql
SELECT LENGTH('hello');                     -- 5 (символы)
SELECT OCTET_LENGTH('hello');               -- 5 (байты, отличается для UTF-8!)
SELECT POSITION('world' IN 'hello world'); -- 7
SELECT STRPOS('hello world', 'world');     -- 7 (PostgreSQL-функция)
```

## 🔗 Склейка

```sql
SELECT CONCAT('Hello', ' ', 'World');          -- Hello World
SELECT 'Hello' || ' ' || 'World';              -- Hello World (оператор ||)
SELECT CONCAT_WS(', ', 'Anna', 'Ivan', NULL);  -- Anna, Ivan (NULL пропускается!)
```

---

## 📐 Извлечение

```sql
SELECT SUBSTRING('Hello World', 7);         -- World
SELECT SUBSTRING('Hello World', 7, 5);      -- World
SELECT LEFT('Hello World', 5);              -- Hello
SELECT RIGHT('Hello World', 5);             -- World

-- SPLIT_PART — вместо MySQL SUBSTRING_INDEX
SELECT SPLIT_PART('Ivan Petrov', ' ', 1);   -- Ivan (первая часть)
SELECT SPLIT_PART('Ivan Petrov', ' ', 2);   -- Petrov (вторая часть)
SELECT SPLIT_PART('Ivan Petrov', ' ', -1);  -- Petrov (последняя, PostgreSQL 14+)
```

## ✅ Главные правила

✅ `||` — оператор конкатенации (дополнение к CONCAT)  
✅ `INITCAP` — первая буква заглавная (нет в MySQL)  
✅ `SPLIT_PART` вместо `SUBSTRING_INDEX`  
✅ `CONCAT_WS` пропускает NULL-значения  
✅ `ILIKE` — регистронезависимый поиск (см. [[01 — ⚖️ Операторы и условия]])
