## 🟢 Что такое база данных

База данных — это структурированное хранилище данных. Для работы с ней используется СУБД (система управления базами данных), которая обеспечивает:

- Хранение данных на диске
- Выполнение запросов (SQL)
- Контроль целостности данных
- Управление доступом и правами
- Транзакционность (ACID)

## 🔵 PostgreSQL vs другие СУБД

| | PostgreSQL | MySQL | SQLite |
|---|---|---|---|
| Тип | Объектно-реляционная | Реляционная | Встраиваемая |
| Лицензия | PostgreSQL (свободная) | GPL / коммерческая | Public domain |
| JSONB | ✅ Нативно | ⚠️ Ограниченно | ❌ |
| Массивы | ✅ | ❌ | ❌ |
| Полнотекстовый поиск | ✅ | ⚠️ | ❌ |
| Сложные типы | ✅ | ❌ | ❌ |
| Производительность | Высокая | Высокая | Низкая (для OLTP) |

**Главные преимущества PostgreSQL:**
- Полная поддержка стандарта SQL
- Богатая система типов (JSONB, массивы, UUID, геометрия)
- Расширяемость через расширения (`pgcrypto`, `PostGIS` и др.)
- Надёжность и ACID-транзакции
- Активное сообщество и открытый код

## 🔴 Основные понятия

| Понятие | Описание |
|---|---|
| **База данных** | Контейнер для схем, таблиц, функций и других объектов |
| **Схема** | Namespace внутри БД (аналог папки) — `public` по умолчанию |
| **Таблица** | Структурированный набор строк и столбцов |
| **Строка** | Одна запись в таблице |
| **Столбец** | Поле с определённым типом данных |
| **Первичный ключ** | Уникальный идентификатор строки |
| **Внешний ключ** | Ссылка на первичный ключ другой таблицы |
| **Индекс** | Структура для ускорения поиска |
| **Транзакция** | Группа операций, выполняемых атомарно |
