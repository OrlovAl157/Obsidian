# 👁 Представления (VIEW) — памятка

> Представление — сохранённый запрос, работающий как виртуальная таблица. В PostgreSQL есть обычные VIEW и материализованные (`MATERIALIZED VIEW`) — последние хранят данные физически и требуют обновления.

## Справка

| Синтаксис | Что делает |
|---|---|
| `CREATE VIEW name AS SELECT ...` | создать представление |
| `CREATE OR REPLACE VIEW` | создать или обновить |
| `DROP VIEW name` | удалить представление |
| `CREATE MATERIALIZED VIEW` | материализованное VIEW |
| `REFRESH MATERIALIZED VIEW` | обновить данные |
| `\dv` | список VIEW (psql) |

---

## 🟢 Обычное VIEW

```sql
-- Создать
CREATE VIEW expensive_books AS
SELECT title, author, price
FROM Books
WHERE price > 15;

-- Использовать
SELECT * FROM expensive_books ORDER BY price DESC;

-- Создать или заменить
CREATE OR REPLACE VIEW expensive_books AS
SELECT title, author, price
FROM Books
WHERE price > 20;   -- изменили порог

-- Удалить
DROP VIEW IF EXISTS expensive_books;

-- VIEW с JOIN
CREATE VIEW books_with_authors AS
SELECT b.title, a.name AS author_name, b.price
FROM Books b
JOIN Authors a ON b.author_id = a.id;
```

## 🔵 MATERIALIZED VIEW

В отличие от обычного VIEW, `MATERIALIZED VIEW` физически хранит результат запроса. Данные не обновляются автоматически — нужно вызывать `REFRESH`.

```sql
-- Создать материализованное VIEW
CREATE MATERIALIZED VIEW monthly_stats AS
SELECT
    DATE_TRUNC('month', created_at) AS month,
    COUNT(*) AS orders,
    SUM(total) AS revenue
FROM Orders
GROUP BY DATE_TRUNC('month', created_at);

-- Обновить данные (без блокировки таблицы)
REFRESH MATERIALIZED VIEW CONCURRENTLY monthly_stats;

-- Нужен уникальный индекс для CONCURRENTLY
CREATE UNIQUE INDEX ON monthly_stats(month);

-- Удалить
DROP MATERIALIZED VIEW monthly_stats;
```

**Когда использовать:**
- Обычный VIEW — живые данные, тяжёлый запрос выполняется при каждом обращении
- MATERIALIZED VIEW — кэш результата, обновляется по расписанию или вручную

---

## ✅ Главные правила

✅ VIEW — всегда актуальные данные, но запрос выполняется каждый раз  
✅ MATERIALIZED VIEW — быстро, но данные могут быть устаревшими  
✅ `REFRESH CONCURRENTLY` — обновить без блокировки (требует уникальный индекс)  
✅ `CREATE OR REPLACE VIEW` — обновить без DROP
