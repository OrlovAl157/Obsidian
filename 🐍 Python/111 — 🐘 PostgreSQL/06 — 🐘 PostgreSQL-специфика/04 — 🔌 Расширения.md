# 🔌 Расширения — памятка

> PostgreSQL расширяется через расширения (`EXTENSION`). Они добавляют новые типы данных, функции, операторы. Устанавливаются командой `CREATE EXTENSION`.

## Справка

| Синтаксис | Что делает |
|---|---|
| `CREATE EXTENSION name` | установить расширение |
| `CREATE EXTENSION IF NOT EXISTS name` | без ошибки если уже есть |
| `DROP EXTENSION name` | удалить расширение |
| `\dx` | список расширений (psql) |

---

## 🟢 Управление расширениями

```sql
-- Установить расширение
CREATE EXTENSION IF NOT EXISTS pgcrypto;
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";
CREATE EXTENSION IF NOT EXISTS pg_trgm;

-- Список установленных
SELECT * FROM pg_extension;
-- или в psql: \dx

-- Удалить
DROP EXTENSION pgcrypto;
```

---

## 🔵 Популярные расширения

| Расширение | Что добавляет |
|---|---|
| `pgcrypto` | криптографические функции, `gen_random_uuid()` |
| `uuid-ossp` | генерация UUID v1-v5 |
| `pg_trgm` | поиск по схожести строк (fuzzy search) |
| `unaccent` | поиск без учёта диакритики |
| `hstore` | key-value хранилище |
| `PostGIS` | геопространственные данные |
| `pg_stat_statements` | статистика запросов |
| `tablefunc` | crosstab (сводные таблицы) |

```sql
-- pgcrypto — хэширование паролей
CREATE EXTENSION pgcrypto;
INSERT INTO Users (email, password)
VALUES ('a@mail.com', crypt('mypassword', gen_salt('bf')));

-- pg_trgm — нечёткий поиск
CREATE EXTENSION pg_trgm;
SELECT * FROM Books WHERE title % 'Hobbit';
SELECT similarity('Hobbit', 'The Hobbit');   -- 0.5
```

## ✅ Главные правила

✅ `CREATE EXTENSION IF NOT EXISTS` — безопасная установка  
✅ `\dx` — посмотреть установленные расширения  
✅ Расширения устанавливаются в схему (обычно `public`)  
✅ `pg_stat_statements` — обязательно для мониторинга производительности
