Отлично! Давай разберу структуру полностью:

## **Топ-уровневые ключи:**

```python
CONFIG = {
    'version': 1,                          # ✅ ОБЯЗАТЕЛЬНО! Версия схемы (всегда 1)
    'disable_existing_loggers': False,     # Не отключай существующие логгеры
    
    'formatters': {...},                   # Форматы вывода
    'filters': {...},                      # Кастомные фильтры
    'handlers': {...},                     # Обработчики (куда писать логи)
    'loggers': {...},                      # Настройки для конкретных логгеров
    'root': {...},                         # Корневой логгер (fallback)
    'incremental': False,                  # Перезаписать ли всю конфиг
}
```

---

## **1. `formatters` — как форматировать сообщения**

```python
'formatters': {
    'simple': {
        'format': '%(levelname)s - %(message)s',
        'style': '%',  # или '{' или '$'
    },
    'detailed': {
        'format': '{asctime}:{levelname}:{name}:{funcName}:{lineno}:{message}',
        'style': '{',
        'datefmt': '%d.%m.%Y %H:%M:%S',  # Формат даты
    },
},
```

**Доступные атрибуты:**
- `%(asctime)s` — время
- `%(levelname)s` — уровень (DEBUG, INFO, WARNING...)
- `%(name)s` — имя логгера
- `%(message)s` — само сообщение
- `%(funcName)s` — имя функции
- `%(lineno)d` — номер строки
- `%(filename)s` — имя файла

---

## **2. `filters` — фильтрация логов**

```python
'filters': {
    'level_filter': {
        '()': '__main__.LevelFilter',  # Класс фильтра
        'level': 'ext://logging.INFO',  # Параметры для класса
    },
    'only_errors': {
        '()': 'logging.Filter',
        'name': 'my_app.errors',  # Только логи с этим именем
    },
},
```

**`'()'`** — спецсинтаксис для вызова класса с параметрами  
**`'ext://'`** — ссылка на внешний объект (например, `logging.INFO`)

---

## **3. `handlers` — куда писать логи**

```python
'handlers': {
    'console': {
        'class': 'logging.StreamHandler',     # Тип обработчика
        'level': 'DEBUG',                     # Уровень этого хендлера
        'formatter': 'simple',                # Какой форматер использовать
        'stream': 'ext://sys.stdout',         # Куда писать
        'filters': ['level_filter'],          # Какие фильтры применить
    },
    'file': {
        'class': 'logging.FileHandler',
        'filename': 'app.log',                # Путь к файлу
        'encoding': 'utf-8',
        'mode': 'a',                          # 'a' = append, 'w' = write
        'formatter': 'detailed',
    },
    'rotating_file': {
        'class': 'logging.handlers.RotatingFileHandler',
        'filename': 'app.log',
        'maxBytes': 1024*1024,                # 1 МБ
        'backupCount': 5,                     # Хранить 5 файлов
        'formatter': 'detailed',
    },
    'syslog': {
        'class': 'logging.handlers.SysLogHandler',
        'address': '/dev/log',
        'formatter': 'simple',
    },
},
```

**Популярные классы:**
- `StreamHandler` — консоль
- `FileHandler` — файл
- `RotatingFileHandler` — файл с ротацией
- `TimedRotatingFileHandler` — ротация по времени
- `SysLogHandler` — системный лог

---

## **4. `loggers` — конфиг отдельных логгеров**

```python
'loggers': {
    __name__: {                    # Имя логгера (часто __name__)
        'level': 'DEBUG',          # Минимальный уровень
        'handlers': ['console', 'file'],  # Какие хендлеры использовать
        'propagate': False,        # Не пробрасывать вверх по иерархии
    },
    'beegeek': {
        'level': 'INFO',
        'handlers': ['console'],
        'propagate': True,         # Пробросить родителю
    },
},
```

---

## **5. `root` — корневой логгер (fallback)**

```python
'root': {
    'level': 'WARNING',
    'handlers': ['console', 'file'],
}
```

Если логгер не найден в `loggers`, будет использован `root`.

---

## **Полный минимальный пример:**

```python
CONFIG = {
    'version': 1,
    'formatters': {
        'default': {
            'format': '[%(levelname)s] %(name)s: %(message)s'
        }
    },
    'handlers': {
        'console': {
            'class': 'logging.StreamHandler',
            'formatter': 'default',
        }
    },
    'root': {
        'level': 'INFO',
        'handlers': ['console'],
    }
}

logging.config.dictConfig(CONFIG)
logger = logging.getLogger(__name__)
logger.info("Работает!")
```

**Нужно помнить:**
- `version: 1` — всегда обязателен
- `handlers` — минимум один нужен
- `loggers` И/ИЛИ `root` — хотя бы один должен быть
- `formatters` — опционально, работает и без него
