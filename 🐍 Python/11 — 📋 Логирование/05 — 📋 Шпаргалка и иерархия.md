## Справка

| Компонент | Создание | Назначение |
|---|---|---|
| `Logger` | `logging.getLogger(name)` | Точка входа — принимает сообщения |
| `Handler` | `StreamHandler()`, `FileHandler()` | Куда отправить — консоль, файл, email |
| `Formatter` | `logging.Formatter(fmt)` | Как выглядит — шаблон строки лога |
| `Filter` | `logging.Filter(name)` | Что пропустить — доп. фильтрация |

| Уровень | Число | Метод |
|---|---|---|
| `DEBUG` | 10 | `logger.debug()` |
| `INFO` | 20 | `logger.info()` |
| `WARNING` | 30 | `logger.warning()` |
| `ERROR` | 40 | `logger.error()` |
| `CRITICAL` | 50 | `logger.critical()` |

---

## 📊 Общая схема

```
                    LOGGER (логгер)
                "Точка входа для кода"
         logger = logging.getLogger('name')
                        │
                        ▼
                   FILTER (фильтр)
             "Дополнительная фильтрация"
                        │
                        ▼
                  HANDLER (обработчик)
              "Куда отправлять логи?"
         StreamHandler / FileHandler / SMTPHandler
                        │
                        ▼
                 FORMATTER (форматер)
              "Как форматировать вывод?"
     '%(asctime)s - %(levelname)s - %(message)s'

Цепочка: Logger → Filter → Handler → Formatter → Вывод

Иерархия имён:
root
  └── app
       ├── app.api
       │    └── app.api.auth
       └── app.db
```

## 🟢 Быстрый старт

**Минимальный вариант:**

```python
import logging

logging.basicConfig(level=logging.DEBUG, format='[%(levelname)s] %(message)s')
logger = logging.getLogger(__name__)

logger.debug('Отладка')         # → [DEBUG] Отладка
logger.info('Информация')       # → [INFO] Информация
logger.warning('Внимание')      # → [WARNING] Внимание
logger.error('Ошибка')          # → [ERROR] Ошибка
logger.critical('Критично')     # → [CRITICAL] Критично
```

**Логирование исключений:**

```python
try:
    1 / 0
except ZeroDivisionError:
    logger.exception('Произошла ошибка!')  # автоматически добавляет traceback
    # ИЛИ
    logger.error('Ошибка', exc_info=True)  # то же самое
```

## 🔵 Уровни логирования

| Уровень | Число | Когда использовать |
|---|---|---|
| `DEBUG` | 10 | Значения переменных, шаги выполнения |
| `INFO` | 20 | Обычные события, запуск/остановка |
| `WARNING` | 30 | Что-то неожиданное, но работает (по умолчанию) |
| `ERROR` | 40 | Ошибка — часть функциональности сломана |
| `CRITICAL` | 50 | Критический сбой — приложение не может работать |

**Важно — два уровня проверяются:**

```python
logger.setLevel(logging.DEBUG)      # уровень логгера
handler.setLevel(logging.WARNING)   # уровень хендлера

# Сообщение проходит ТОЛЬКО если уровень >= обоих
# DEBUG: проходит логгер ✅ блокирует хендлер ❌
# WARNING: проходит логгер ✅ проходит хендлер ✅
```

## 🔴 Хендлеры

```python
import logging, sys
from logging.handlers import RotatingFileHandler

# StreamHandler — вывод в консоль
console = logging.StreamHandler(sys.stdout)

# FileHandler — вывод в файл
file_h = logging.FileHandler('logs.log', mode='a', encoding='utf-8')
# mode='a' — добавлять, mode='w' — перезаписывать

# RotatingFileHandler — файл с ротацией
rotating = RotatingFileHandler(
    'logs.log',
    maxBytes=10 * 1024 * 1024,  # 10 МБ — максимальный размер файла
    backupCount=5               # хранить 5 архивных файлов
)
# Когда logs.log > 10 МБ → переименуется в logs.log.1
# Архивы: logs.log.1, logs.log.2, ..., logs.log.5
```

**Отключение логгеров сторонних библиотек:**

```python
logging.getLogger('requests').setLevel(logging.WARNING)
logging.getLogger('urllib3').setLevel(logging.WARNING)
```

## 🟡 Иерархия логгеров

Логгеры образуют дерево через точки в именах:

```python
root   = logging.getLogger()               # корневой
app    = logging.getLogger('app')          # дочерний root
api    = logging.getLogger('app.api')      # дочерний app
auth   = logging.getLogger('app.api.auth') # дочерний api
db     = logging.getLogger('app.db')       # дочерний app
```

**Правила распространения:**

```python
# propagate=True (по умолчанию) — сообщение идёт вверх по дереву
# auth.error() → auth → api → app → root

# Остановить распространение:
logging.getLogger('app.api').propagate = False
# auth.error() → auth → api (стоп)

# Если у логгера нет уровня — наследует от родителя
logging.getLogger('app').setLevel(logging.DEBUG)
# api, db, auth тоже будут DEBUG если у них не задан свой
```

## 🟣 Пошаговое создание

**Уровень 1 — только логгер:**
```python
logger = logging.getLogger('my_app')
logger.warning('Предупреждение')
```

**Уровень 2 — с хендлером:**
```python
logger = logging.getLogger('my_app')
handler = logging.StreamHandler(sys.stdout)
logger.addHandler(handler)
```

**Уровень 3 — с форматером:**
```python
formatter = logging.Formatter('%(asctime)s - %(levelname)s - %(message)s')
handler.setFormatter(formatter)   # форматер → хендлер
logger.addHandler(handler)        # хендлер → логгер
```

**Уровень 4 — с фильтром:**
```python
class ErrorOnlyFilter(logging.Filter):
    def filter(self, record):
        return record.levelno >= logging.ERROR

handler.addFilter(ErrorOnlyFilter())  # фильтр на конкретный хендлер
# ИЛИ
logger.addFilter(ErrorOnlyFilter())   # фильтр на все хендлеры логгера
```

**Уровень 5 — полная конфигурация:**
```python
import logging, sys

logger = logging.getLogger('my_app')
logger.setLevel(logging.DEBUG)

# Консоль — WARNING и выше
console = logging.StreamHandler(sys.stdout)
console.setLevel(logging.WARNING)
console.setFormatter(logging.Formatter('%(levelname)s - %(message)s'))

# Файл — всё включая DEBUG
file_h = logging.FileHandler('app.log', encoding='utf-8')
file_h.setLevel(logging.DEBUG)
file_h.setFormatter(logging.Formatter(
    '%(asctime)s - %(name)s - %(levelname)s - %(message)s'
))

logger.addHandler(console)
logger.addHandler(file_h)

logger.debug('Отладка')    # только в файл
logger.warning('Внимание') # в файл и консоль
logger.error('Ошибка')     # в файл и консоль
```

## ⚡ Шаблон проекта

```python
# config.py — настраивается один раз
import logging, sys
from logging import Logger

def setup_logger(name: str, log_file: str = 'logs.log') -> Logger:
    logger: Logger = logging.getLogger(name)
    logger.setLevel(logging.DEBUG)

    formatter = logging.Formatter(
        '[%(levelname)s] | %(asctime)s | %(name)s | %(message)s'
    )

    file_handler = logging.FileHandler(log_file, 'a', encoding='utf-8')
    file_handler.setLevel(logging.DEBUG)
    file_handler.setFormatter(formatter)

    console_handler = logging.StreamHandler(sys.stdout)
    console_handler.setLevel(logging.WARNING)
    console_handler.setFormatter(formatter)

    logger.addHandler(file_handler)
    logger.addHandler(console_handler)

    return logger


# main.py, utils.py — используют готовый логгер
from config import setup_logger

logger = setup_logger(__name__)

logger.debug('Только в файл')
logger.warning('В файл и консоль')
```

Структура проекта:
```
my_project/
├── config.py      # настройка логгера
├── main.py
├── utils.py
└── logs/
    └── logs.log
```

## 💡 Практические замечания

- Один логгер на модуль — `logging.getLogger(__name__)`
- `basicConfig()` работает только если хендлеры ещё не добавлены к root
- Уровень логгера — минимальный порог, уровень хендлера — дополнительный фильтр
- `logger.exception()` внутри `except` — самый удобный способ залогировать с traceback
- Для отключения чужих библиотек — ставь `WARNING` на их логгеры
- Проверяй `logger.handlers` перед добавлением — иначе дублирование логов

## ⚠️ Частые ошибки

**❌ Использовал имя переменной вместо `__name__`:**
```python
logger = logging.getLogger(name)     # ❌ NameError если name не определена
logger = logging.getLogger(__name__) # ✅
```

**❌ Режим `'w'` перезаписывает логи:**
```python
FileHandler('logs.log', 'w')  # ❌ удаляет старые логи при каждом запуске
FileHandler('logs.log', 'a')  # ✅ добавляет к существующим
```

**❌ Потеря traceback:**
```python
except ValueError:
    logger.error('Ошибка')      # ❌ без деталей
    logger.exception('Ошибка')  # ✅ автоматически traceback
```

**❌ Дублирование логов:**
```python
logger.addHandler(handler)      # ❌ если basicConfig уже добавил хендлеры
if not logger.handlers:
    logger.addHandler(handler)  # ✅ проверяй перед добавлением
```

---

## ✅ Главные правила

✅ Один логгер на модуль — `logging.getLogger(__name__)`  
✅ Уровень логгера ≥ уровень хендлера — иначе сообщения не дойдут  
✅ `mode='a'` в `FileHandler` — никогда не теряй старые логи  
✅ `logger.exception()` внутри `except` — traceback автоматически  
✅ Несколько хендлеров — разные уровни для консоли и файла  
✅ `propagate=False` — если не хочешь дублирования в родительском логгере  
✅ Настройку логгера выноси в отдельную функцию `setup_logger()`
