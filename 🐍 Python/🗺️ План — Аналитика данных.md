## 🛠️ Блок 0. Подготовка
- Окружение: Python, Jupyter или VS Code, DBeaver или MySQL Workbench, Git
- Учебная БД: Sakila или Northwind (MySQL)
- Датасеты: Kaggle, открытые данные по продажам и транзакциям

## 🔍 Блок 1. SQL для аналитики
1. Выборки: `WHERE`, `ORDER BY`, `LIMIT`, `DISTINCT`, `CASE WHEN`
2. Агрегация: `GROUP BY`, `HAVING`, `COUNT(DISTINCT)`, работа с `NULL`
3. Джойны: `INNER`, `LEFT`, `RIGHT`, self join, анти-джойн (в MySQL нет `FULL JOIN`)
4. Подзапросы и CTE (`WITH`)
5. Оконные функции: `ROW_NUMBER`, `RANK`, `LAG`/`LEAD`, `OVER (PARTITION BY ...)`
6. Даты: группировка по месяцам, основы когортного анализа
7. Производительность: `EXPLAIN`, индексы

**Проект:** отчёт по выручке и удержанию пользователей

## 🐍 Блок 2. Python + pandas
1. Повторение: comprehensions, функции, модули
2. Структуры: `Series`, `DataFrame`, `loc` / `iloc`
3. Загрузка: `read_csv`, `read_sql`
4. Очистка: пропуски, дубликаты, типы, `to_datetime`
5. Преобразования: `groupby` + `agg`, `pivot_table`, `merge`
6. Временные ряды: `resample`, `rolling`
7. Визуализация: `matplotlib`, `seaborn`

**Проект:** очистка и EDA датасета в ноутбуке

## 📊 Блок 3. Статистика и A/B-тесты
1. Описательная статистика: среднее, медиана, дисперсия, перцентили
2. Распределения: нормальное, биномиальное, пуассоновское
3. Центральная предельная теорема и стандартная ошибка
4. Доверительные интервалы
5. Проверка гипотез: H0 и H1, p-value, ошибки I и II рода
6. Тесты: t-test, z-test для пропорций, хи-квадрат, Mann-Whitney
7. Мощность и размер выборки
8. Дизайн A/B-теста: рандомизация, основная и guardrail-метрики, подглядывание, множественные сравнения

**Проект:** разбор готового A/B-теста

## 📈 Блок 4. Метрики и продуктовое мышление
1. Ключевые метрики: DAU/MAU, retention, конверсия, ARPU, LTV, churn
2. Дерево метрик и декомпозиция
3. Диагностика падения метрики: сегментация, сезонность, изменения в продукте
4. Гипотезы и приоритизация (ICE, RICE)

**Проект:** разбор кейса «упала конверсия»

## 📉 Блок 5. BI и визуализация
1. Принципы дашбордов: что показывать и какой график выбрать
2. Инструмент: Power BI, Tableau или Metabase / Superset
3. Подключение к SQL, вычисляемые поля, фильтры

**Проект:** дашборд по данным из блока 1 или 4

## 🎯 Блок 6. Итоговый проект и портфолио
- Полный цикл: вопрос → SQL → pandas → статистика → выводы → дашборд
- Оформление на GitHub или в Notion
- Подготовка к собеседованиям: SQL-задачи, кейсы, объяснение A/B-теста

## ⚠️ Частые ошибки
- Учить инструмент раньше, чем задачу: сначала вопрос, потом код
- Пропускать статистику и считать «красивую» разницу значимой без проверки
- Делать проекты только в конце, а не после каждого блока
