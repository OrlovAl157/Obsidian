# ✂️ split() и join() — памятка

> `split()` — разбивает строку на список частей по разделителю. `join()` — собирает список обратно в строку. Логичная пара: одна разрезает, другая склеивает.

## Справка

| Метод | Что делает | Возвращает |
|---|---|---|
| `str.split(sep, maxsplit)` | Разбивает по разделителю слева | `list` |
| `str.rsplit(sep, maxsplit)` | Разбивает по разделителю справа | `list` |
| `str.splitlines(keepends)` | Разбивает по символам новой строки | `list` |
| `sep.join(iterable)` | Склеивает элементы через разделитель | `str` |
| `re.split(pattern, string)` | Разбивает по регулярному выражению | `list` |

## 📊 Общая схема

```
split()                          join()
────────────────────────────     ──────────────────────────
"a,b,c".split(",")               ",".join(["a", "b", "c"])
       │                                  │
       ▼                                  ▼
  ["a", "b", "c"]              →      "a,b,c"

Разделитель не задан → по пробельным символам:
"  hello   world  ".split()  →  ["hello", "world"]
                                  пустые строки не возникают!

Разделитель задан → режет в каждом месте:
"a,,b".split(",")  →  ["a", "", "b"]
                        пустые строки возможны!
```

## 🟢 split() — базовый синтаксис

```python
str.split(sep=None, maxsplit=-1)
```

**Без аргументов — по пробельным символам:**

```python
"hello world".split()              # → ["hello", "world"]
"  hello   world  ".split()        # → ["hello", "world"]  пробелы схлопываются
"hello\tworld\n".split()           # → ["hello", "world"]  \t \n тоже разделители
"".split()                         # → []
```

**С разделителем `sep`:**

```python
"a,b,c".split(",")                 # → ["a", "b", "c"]
"a::b::c".split("::")              # → ["a", "b", "c"]
"a,,b".split(",")                  # → ["a", "", "b"]  пустая строка!
",a,b,".split(",")                 # → ["", "a", "b", ""]  пустые по краям!
```

**С ограничением `maxsplit`:**

```python
"a,b,c,d".split(",", maxsplit=2)   # → ["a", "b", "c,d"]  только 2 разреза
"a,b,c,d".split(",", maxsplit=1)   # → ["a", "b,c,d"]
"a b c d".split(maxsplit=2)        # → ["a", "b", "c d"]
```

**Важное:**
- `split()` без аргументов — пробельные символы схлопываются, пустые строки не возникают
- `split(sep)` с аргументом — каждое вхождение `sep` создаёт разрез, пустые строки возможны

## 🔵 split() vs rsplit()

`rsplit()` — то же самое что `split()`, но разбивает **справа налево**. Разница видна только при `maxsplit`:

```python
"a,b,c,d".split(",", maxsplit=2)   # → ["a", "b", "c,d"]  слева
"a,b,c,d".rsplit(",", maxsplit=2)  # → ["a,b", "c", "d"]  справа

# Без maxsplit — результат одинаковый
"a,b,c".split(",")                 # → ["a", "b", "c"]
"a,b,c".rsplit(",")                # → ["a", "b", "c"]
```

**Когда нужен `rsplit()`:**

```python
# Отделить расширение файла
"archive.tar.gz".rsplit(".", maxsplit=1)   # → ["archive.tar", "gz"]
"archive.tar.gz".split(".", maxsplit=1)    # → ["archive", "tar.gz"]
```

## 🔴 splitlines()

Разбивает строку по символам переноса строки:

```python
str.splitlines(keepends=False)
```

```python
"line1\nline2\nline3".splitlines()          # → ["line1", "line2", "line3"]
"line1\r\nline2\r\nline3".splitlines()      # → ["line1", "line2", "line3"]
"line1\nline2\n".splitlines()               # → ["line1", "line2"]  без пустой!
"line1\nline2\n".split("\n")                # → ["line1", "line2", ""]  с пустой!

# keepends=True — сохранить символы переноса
"line1\nline2\n".splitlines(keepends=True)  # → ["line1\n", "line2\n"]
```

**Распознаёт:** `\n`, `\r\n`, `\r`, `\v`, `\f`, `\x1c`, `\x1d`, `\x1e`, `\x85`, `\u2028`, `\u2029`

## 🟡 join() — склейка списка

```python
sep.join(iterable)
```

```python
# Базовое использование
", ".join(["apple", "banana", "cherry"])   # → "apple, banana, cherry"
"-".join(["2025", "05", "05"])             # → "2025-05-05"
"".join(["a", "b", "c"])                  # → "abc"  без разделителя
" ".join(["hello", "world"])              # → "hello world"

# Из кортежа
"/".join(("usr", "local", "bin"))         # → "usr/local/bin"

# Из генератора
" ".join(word.upper() for word in ["hi", "there"])  # → "HI THERE"

# Числа — нужно преобразовать в str!
", ".join(str(n) for n in [1, 2, 3])     # → "1, 2, 3"
```

**Важное:** все элементы должны быть строками — иначе `TypeError`.

## 🔧 split() изнутри — алгоритм

**`split()` без аргумента — собирает слова:**

```
Идея: "работаем с токенами, игнорируя пробелы"

"   Hello   World   "
 ↑           ↑
 пробелы     слово начинается здесь
 пропускаем
```

```python
# Псевдокод split()
def split_whitespace(s):
    result = []
    i, n = 0, len(s)
    while i < n:
        while i < n and s[i].isspace():  # пропускаем пробелы
            i += 1
        if i >= n:
            break
        start = i
        while i < n and not s[i].isspace():  # копим слово
            i += 1
        result.append(s[start:i])
    return result
# Пустые строки не возникают — слова начинаются только после пробелов
```

**`split(sep)` с аргументом — режет по разделителю:**

```
Идея: "разделитель = место разреза"

"a,,b,c"
 ↑ ↑ ↑ ↑
 │ │ │ └── часть после последнего разделителя
 │ │ └── пустая часть между разделителями ← значима!
 │ └── часть между разделителями
 └── часть до первого разделителя
```

```python
# Псевдокод split(sep)
def split_with_sep(s, sep):
    result = []
    i, n, sep_len = 0, len(s), len(sep)
    while True:
        j = s.find(sep, i)       # ищем разделитель
        if j < 0:
            j = n
        result.append(s[i:j])   # берём часть (даже пустую!)
        if j == n:
            break
        i = j + sep_len          # перепрыгиваем через разделитель
    return result
```

| Аспект | `split()` | `split(sep)` |
|---|---|---|
| Пустые строки | Не возникают | Возможны |
| Пробелы в начале/конце | Игнорируются | Создают пустые части |
| Несколько пробелов подряд | Схлопываются | Каждый создаёт разрез |

## ⚙️ re.split() — разбивка по паттерну

```python
import re

# Разбить по нескольким разделителям сразу
re.split(r'[,;|]', "a,b;c|d")        # → ["a", "b", "c", "d"]

# Разбить по одному или более пробельных символов
re.split(r'\s+', "hello   world\t!")  # → ["hello", "world", "!"]

# Разбить по НЕ-цифрам
re.split(r'\D+', '1 + 2 - 3 =')      # → ["1", "2", "3", ""]
```

**Почему пустая строка в конце?**

```python
re.split(r'\D+', '1 + 2 - 3 =')
# '1 + 2 - 3 =' заканчивается на '=' — это разделитель
# После последнего разделителя нет ничего → пустая строка

# То же самое в обычном split:
'1,2,3,'.split(',')   # → ['1', '2', '3', '']
```

**Как убрать пустые строки:**

```python
# Вариант 1 — list comprehension
[x for x in re.split(r'\D+', '1 + 2 - 3 =') if x]   # → ["1", "2", "3"]

# Вариант 2 — filter
list(filter(None, re.split(r'\D+', '1 + 2 - 3 =')))  # → ["1", "2", "3"]

# Вариант 3 — findall (лучше для этой задачи)
re.findall(r'\d+', '1 + 2 - 3 =')                    # → ["1", "2", "3"]
```

## ⚡ Быстрые примеры

```python
# Парсинг CSV строки
"Alice,25,Moscow".split(",")              # → ["Alice", "25", "Moscow"]

# Разбить путь к файлу
"usr/local/bin/python".split("/")         # → ["usr", "local", "bin", "python"]

# Получить расширение файла
"archive.tar.gz".rsplit(".", maxsplit=1)  # → ["archive.tar", "gz"]

# Построить путь
"/".join(["usr", "local", "bin"])         # → "usr/local/bin"

# Слова в верхнем регистре
" ".join(w.capitalize() for w in "hello world".split())
# → "Hello World"

# Обратить слова в строке
" ".join("hello world python".split()[::-1])
# → "python world hello"

# Убрать лишние пробелы
" ".join("  hello   world  ".split())    # → "hello world"

# Разбить по нескольким разделителям
import re
re.split(r'[,;\s]+', "a, b; c d")        # → ["a", "b", "c", "d"]

# Число строк в тексте
len(text.splitlines())
```

## 💡 Практические замечания

- `split()` без аргумента — самый надёжный способ разбить на слова, не боится лишних пробелов
- `join()` всегда быстрее чем конкатенация `+` в цикле — используй его для сборки строк
- `splitlines()` лучше чем `split("\n")` для текста — корректно обрабатывает `\r\n`
- Пустая строка из `split(sep)` — не баг, а поведение по дизайну (значимо для CSV)
- Для сложных разделителей (несколько символов, паттерны) — `re.split()`

## ⚠️ Частые ошибки

**❌ join() с не-строками:**
```python
", ".join([1, 2, 3])                    # ❌ TypeError
", ".join(str(n) for n in [1, 2, 3])   # ✅
```

**❌ Перепутал порядок в join():**
```python
["a", "b"].join(",")    # ❌ AttributeError — join это метод строки!
",".join(["a", "b"])    # ✅
```

**❌ Ожидал что split(sep) схлопнет разделители:**
```python
"a,,b".split(",")       # → ["a", "", "b"]  ← пустая строка!
"a,,b".split()          # → ["a,,b"]  ← нет! запятая не пробел
# Правильно:
[x for x in "a,,b".split(",") if x]  # → ["a", "b"]
```

**❌ split("\n") вместо splitlines():**
```python
"line1\r\nline2".split("\n")        # → ["line1\r", "line2"]  ← \r остался!
"line1\r\nline2".splitlines()       # → ["line1", "line2"]    ✅
```

## ✅ Главные правила

✅ `split()` без аргументов — схлопывает пробелы, пустые строки не возникают  
✅ `split(sep)` с аргументом — каждый разделитель создаёт разрез, пустые строки возможны  
✅ `rsplit(sep, maxsplit)` — то же что `split()` но справа налево  
✅ `splitlines()` — для текста с переносами строк, лучше чем `split("\n")`  
✅ `join()` — метод **разделителя**, не списка: `",".join(list)`  
✅ `join()` требует чтобы все элементы были строками  
✅ `re.split()` — когда нужно разбить по нескольким разделителям или паттерну
