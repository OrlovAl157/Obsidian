# 🎯 Спецификатор формата — памятка

> Мини-язык форматирования Python — единый синтаксис для управления выводом чисел и строк. Работает одинаково в `f"{value:формат}"`, `"{:формат}".format(value)` и `format(value, "формат")`.

## Справка

| Часть спецификатора | Что делает | Пример |
|---|---|---|
| `[[fill]align]` | выравнивание с заполнителем | `*^10` → по центру, заполнить `*` |
| `[sign]` | знак числа | `+` → всегда, `-` → только минус |
| `[#]` | альтернативный формат | `#x` → `0xff` вместо `ff` |
| `[0]` | дополнение нулями | `05d` → `00042` |
| `[width]` | минимальная ширина | `10` → минимум 10 символов |
| `[,]` или `[_]` | разделитель тысяч | `,` → `1,000,000` |
| `[.precision]` | точность | `.2f` → два знака после точки |
| `[type]` | тип представления | `f`, `d`, `s`, `x`, `%` и т.д. |

**Порядок обязателен:** `[[fill]align][sign][#][0][width][,][.precision][type]`

---

## 📊 Общая схема

```
{value: [[fill]align] [sign] [#] [0] [width] [,] [.precision] [type]}
           │     │      │     │    │    │        │       │        │
           │     │      │     │    │    │        │       │        └── тип: f d s x b o e %
           │     │      │     │    │    │        │       └── знаков после точки
           │     │      │     │    │    │        └── разделитель тысяч
           │     │      │     │    │    └── минимальная ширина поля
           │     │      │     │    └── заполнить нулями слева
           │     │      │     └── альтернативный вид (0x, 0b, 0o)
           │     │      └── знак: + - (пробел)
           │     └── < > ^ =
           └── символ заполнения (любой символ)
```

## 🟢 Выравнивание и заполнение

| Символ | Выравнивание | Пример | Результат |
|---|---|---|---|
| `<` | влево | `f"{'Hi':<10}"` | `"Hi        "` |
| `>` | вправо | `f"{'Hi':>10}"` | `"        Hi"` |
| `^` | по центру | `f"{'Hi':^10}"` | `"    Hi    "` |
| `=` | знак слева, цифры справа | `f"{42:0=10}"` | `"0000000042"` |

```python
text = "Hello"

# Базовое выравнивание (заполнитель — пробел по умолчанию)
f"{text:<10}"              # → "Hello     "
f"{text:>10}"              # → "     Hello"
f"{text:^10}"              # → "  Hello   "

# С заполнителем
f"{text:*<10}"             # → "Hello*****"
f"{text:*>10}"             # → "*****Hello"
f"{text:*^10}"             # → "**Hello***"
f"{text:-^10}"             # → "--Hello---"

# Числа
f"{42:010}"                # → "0000000042"  (нули слева)
f"{42:+10}"                # → "       +42"  (знак + ширина)
f"{-42:010}"               # → "-000000042"
```

## 🔵 Числа: целые и float

**Целые числа:**

```python
n = 42

f"{n:d}"                   # → "42"       тип int явно
f"{n:10d}"                 # → "        42"  ширина 10
f"{n:010d}"                # → "0000000042"  нули слева
f"{n:+d}"                  # → "+42"      всегда знак
f"{n: d}"                  # → " 42"      пробел вместо +
f"{-n:d}"                  # → "-42"
```

**Вещественные числа:**

```python
pi = 3.14159265

f"{pi:f}"                  # → "3.141593"   по умолчанию 6 знаков
f"{pi:.2f}"                # → "3.14"
f"{pi:.4f}"                # → "3.1416"
f"{pi:.0f}"                # → "3"
f"{pi:10.2f}"              # → "      3.14"  ширина + точность
f"{pi:010.2f}"             # → "0000003.14"  нули + точность
```

**Разделитель тысяч:**

```python
big = 1234567890

f"{big:,}"                 # → "1,234,567,890"
f"{big:_}"                 # → "1_234_567_890"
f"{big:,.2f}"              # → "1,234,567,890.00"  (если float)
```

**Проценты:**

```python
ratio = 0.7562

f"{ratio:%}"               # → "75.620000%"
f"{ratio:.1%}"             # → "75.6%"
f"{ratio:.2%}"             # → "75.62%"
```

**Научная нотация:**

```python
big = 1234567.89

f"{big:e}"                 # → "1.234568e+06"
f"{big:.2e}"               # → "1.23e+06"
f"{big:.2E}"               # → "1.23E+06"  (заглавная E)
```

## 🔴 Системы счисления

```python
n = 42

# Двоичная
f"{n:b}"                   # → "101010"
f"{n:#b}"                  # → "0b101010"  (с префиксом)
f"{n:08b}"                 # → "00101010"  (с нулями)

# Восьмеричная
f"{n:o}"                   # → "52"
f"{n:#o}"                  # → "0o52"

# Шестнадцатеричная
f"{n:x}"                   # → "2a"  (строчные)
f"{n:X}"                   # → "2A"  (заглавные)
f"{n:#x}"                  # → "0x2a"
f"{n:#X}"                  # → "0X2A"

# Практический пример: цвет в HEX
color = 0xFF5733
f"#{color:06X}"            # → "#FF5733"
```

## ⚡ Быстрые примеры

```python
# Самые частые сценарии
f"{3.14159:.2f}"           # → "3.14"          два знака
f"{42:05d}"                # → "00042"          нули слева
f"{1000000:,}"             # → "1,000,000"      тысячи
f"{0.756:.1%}"             # → "75.6%"          проценты
f"{42:+}"                  # → "+42"            знак
f"{'Hi':^10}"              # → "    Hi    "      центр
f"{'Hi':*<10}"             # → "Hi********"     заполнитель
f"{255:#x}"                # → "0xff"           hex с префиксом
f"{1234:.2e}"              # → "1.23e+03"       научная запись

# Динамические параметры (работает в format() и f-строках)
width = 10
prec = 2
f"{3.14159:{width}.{prec}f}"   # → "      3.14"
```

## 💡 Практические замечания

- Спецификатор одинаков для `f""`, `.format()` и `format()` — выучил один раз, работает везде
- `width` — **минимальная** ширина, не максимальная. Строка длиннее width — не обрезается
- `0` перед width (`05d`) — сокращение для `fill=0, align==`
- Для строк тип `s` обычно не пишут — он по умолчанию
- `precision` для строк ограничивает максимальное количество символов: `f"{'Hello':.3}"` → `"Hel"`

## ⚠️ Частые ошибки

**❌ Неправильный порядок частей:**
```python
f"{42:d10}"                # ❌ ValueError — тип должен быть последним
f"{42:10d}"                # ✅
```

**❌ `fill` без `align`:**
```python
f"{'Hi':*10}"              # ❌ ValueError — заполнитель требует выравнивание
f"{'Hi':*<10}"             # ✅
```

**❌ Точность для целых чисел:**
```python
f"{42:.2d}"                # ❌ ValueError — .precision не работает с d
f"{42.0:.2f}"              # ✅ нужен float
```

**❌ Разделитель тысяч с не-числом:**
```python
f"{'hello':,}"             # ❌ ValueError
f"{1000:,}"                # ✅
```
