# 🔧 %-форматирование — памятка

> Старейший способ форматирования строк в Python. Встречается в старом коде и в модуле `logging`. Использует символ `%` и спецификаторы типов как в языке C.

## Справка

| Спецификатор | Тип | Пример | Результат |
|---|---|---|---|
| `%s` | строка (любой объект) | `"Hello %s" % "Alice"` | `"Hello Alice"` |
| `%d` | целое число | `"Лет: %d" % 25` | `"Лет: 25"` |
| `%i` | целое число (синоним `%d`) | `"Лет: %i" % 25` | `"Лет: 25"` |
| `%f` | число с плавающей точкой | `"Цена: %f" % 3.14` | `"Цена: 3.140000"` |
| `%e` | экспоненциальная запись | `"%e" % 1000` | `"1.000000e+03"` |
| `%x` | шестнадцатеричное | `"%x" % 255` | `"ff"` |
| `%o` | восьмеричное | `"%o" % 8` | `"10"` |
| `%%` | литеральный `%` | `"100%%"` | `"100%"` |

---

## 📊 Общая схема

```
"шаблон %спец" % значение
"шаблон %спец %спец" % (знач1, знач2)
"шаблон %(имя)спец" % {"имя": значение}
        │
        ├── одно значение → можно без скобок
        ├── несколько значений → кортеж обязателен
        └── именованные → словарь обязателен
```

---

## 🟢 Позиционные поля

**Назначение:** подстановка значений по порядку через кортеж.

```python
# Одно значение — скобки опциональны
"Hello %s!" % "Alice"              # → "Hello Alice!"
"Возраст: %d" % 25                 # → "Возраст: 25"

# Несколько значений — кортеж обязателен
"%s — %d лет" % ("Alice", 25)      # → "Alice — 25 лет"
"%d + %d = %d" % (2, 3, 5)        # → "2 + 3 = 5"

# С форматированием
"Цена: %.2f руб." % 19.9           # → "Цена: 19.90 руб."
"Код: %05d" % 42                   # → "Код: 00042"
```

**Важное:**
- При нескольких значениях справа от `%` **обязательно кортеж** `(a, b)`
- При одном значении-кортеже нужна запятая: `("%s",) % ("text",)` иначе Python распакует

---

## 🔵 Именованные поля

**Назначение:** подстановка значений по именам через словарь. Удобно когда значение используется несколько раз.

```python
user = {"name": "Alice", "age": 25}

# Базовый синтаксис
"%(name)s — %(age)d лет" % user    # → "Alice — 25 лет"

# Повтор значения — не нужно дублировать в кортеже
template = "%(name)s работает в %(company)s и %(name)s любит Python"
data = {"name": "Bob", "company": "TechCorp"}
template % data                    # → "Bob работает в TechCorp и Bob любит Python"

# С форматированием чисел
data = {"price": 19.9, "qty": 5}
"Цена: %(price).2f, кол-во: %(qty)03d" % data
# → "Цена: 19.90, кол-во: 005"
```

**Важное:** при именованных полях справа **обязательно словарь**. Кортеж вызовет `TypeError`.

## 🔴 Форматирование чисел

**Синтаксис:** `%[флаг][ширина][.точность]тип`

```python
# Ширина поля
"%10s" % "Hi"              # → "        Hi"  (выравнивание вправо)
"%-10s" % "Hi"             # → "Hi        "  (выравнивание влево)

# Дополнение нулями
"%05d" % 42                # → "00042"
"%08.2f" % 3.14            # → "00003.14"

# Знак числа
"%+d" % 42                 # → "+42"
"%+d" % -42                # → "-42"

# Точность float
"%.2f" % 3.14159           # → "3.14"
"%.4f" % 3.14159           # → "3.1416"
"%.0f" % 3.14159           # → "3"

# Экспоненциальная запись
"%.2e" % 1234567           # → "1.23e+06"

# Системы счисления
"%x" % 255                 # → "ff"
"%X" % 255                 # → "FF"
"%#x" % 255                # → "0xff"
"%o" % 8                   # → "10"
```

## ⚡ Быстрые примеры

```python
# Логирование (% до сих пор используется в logging)
logger.warning("Ошибка: %s в строке %d", msg, lineno)

# Простой вывод
print("Привет, %s! Ты %d лет." % ("Alice", 25))

# Проценты
print("Успешно: 95.5%%")           # → "Успешно: 95.5%"

# Таблица
for name, price in [("Apple", 2.5), ("Banana", 1.8)]:
    print("%-10s %6.2f руб." % (name, price))
# Apple       2.50 руб.
# Banana      1.80 руб.
```

## ⚠️ Частые ошибки

**❌ Забыл кортеж при нескольких значениях:**
```python
"%s и %s" % "Alice", "Bob"    # ❌ TypeError
"%s и %s" % ("Alice", "Bob")  # ✅
```

**❌ Передал кортеж вместо словаря для именованных полей:**
```python
"%(name)s" % ("Alice",)        # ❌ TypeError
"%(name)s" % {"name": "Alice"} # ✅
```

**❌ Одиночное значение-кортеж без запятой:**
```python
items = ("Alice",)
"%s" % items                   # ❌ не то что ожидаешь
"%s" % (items,)                # ✅
```

**❌ Забыл %% для литерального процента:**
```python
"Скидка: 10%"                  # ❌ TypeError (Python видит незакрытый %)
"Скидка: 10%%"                 # ✅ → "Скидка: 10%"
```
