# ✨ f-строки — памятка

> Современный способ форматирования строк (Python 3.6+). Позволяет встраивать любые выражения Python прямо в строку через `f"{выражение}"`. Быстрее и читабельнее чем `%` и `.format()`.

## Справка

| Синтаксис | Что делает | Пример |
|---|---|---|
| `f"{var}"` | подставляет переменную | `f"Hello {name}"` |
| `f"{expr}"` | вычисляет выражение | `f"{x + y}"` |
| `f"{var:формат}"` | подставляет с форматом | `f"{price:.2f}"` |
| `f"{var!r}"` | применяет `repr()` | `f"{name!r}"` → `"'Alice'"` |
| `f"{var!s}"` | применяет `str()` | `f"{obj!s}"` |
| `f"{var=}"` | отладка: имя + значение | `f"{x=}"` → `"x=10"` |

---

## 📊 Общая схема

```
f"текст {выражение!conversion:формат} текст"
              │          │         │
              │          │         └── спецификатор формата (необязательно)
              │          │              .2f, >10, 05d и т.д.
              │          │
              │          └── conversion (необязательно)
              │               !s → str()
              │               !r → repr()
              │               !a → ascii()
              │
              └── любое выражение Python
                   переменная, вызов, арифметика, условие...
```

## 🟢 Базовый синтаксис

```python
name = "Alice"
age = 25

# Переменные
f"Hello, {name}!"                  # → "Hello, Alice!"
f"{name} — {age} лет"              # → "Alice — 25 лет"

# Многострочные
message = f"""
Имя: {name}
Возраст: {age}
"""

# Вложенные кавычки
f"{'Привет'}"                      # → "Привет"
f'{"Привет"}'                      # → "Привет"

# Conversion
f"{name!r}"                        # → "'Alice'"  (с кавычками)
f"{name!s}"                        # → "Alice"
```

## 🔵 Выражения и вызовы

f-строки позволяют писать любой валидный Python-код внутри `{}`:

```python
x, y = 10, 5

# Арифметика
f"{x} + {y} = {x + y}"            # → "10 + 5 = 15"
f"{x ** 2}"                        # → "100"

# Методы строк
text = "hello"
f"{text.upper()}"                  # → "HELLO"
f"{text.capitalize()}"             # → "Hello"

# Встроенные функции
numbers = [1, 2, 3, 4, 5]
f"Сумма: {sum(numbers)}"           # → "Сумма: 15"
f"Длина: {len(numbers)}"           # → "Длина: 5"

# Индексация
items = ["apple", "banana"]
f"Первый: {items[0]}"              # → "Первый: apple"

# Словари
user = {"name": "Bob", "age": 28}
f"{user['name']} — {user['age']} лет"  # → "Bob — 28 лет"

# Тернарный оператор
score = 85
f"{'Сдал' if score >= 60 else 'Не сдал'}"  # → "Сдал"

# Форматирование datetime
from datetime import datetime
now = datetime.now()
f"{now:%Y-%m-%d %H:%M}"           # → "2025-05-05 14:30"
```

## 🔴 Отладка через =

Python 3.8+ — оператор `=` выводит имя переменной и её значение:

```python
x = 10
y = 20

f"{x=}"                            # → "x=10"
f"{y=}"                            # → "y=20"
f"{x + y=}"                        # → "x + y=30"

numbers = [1, 2, 3]
f"{sum(numbers)=}"                 # → "sum(numbers)=6"

# С форматированием
pi = 3.14159
f"{pi=:.2f}"                       # → "pi=3.14"

# Несколько переменных
name = "Alice"
f"{name=}, {x=}"                   # → "name='Alice', x=10"
```

## ⚡ Быстрые примеры

```python
price = 19.9
big = 1234567
ratio = 0.756
n = 42

# Числа
f"{price:.2f}"                     # → "19.90"
f"{big:,}"                         # → "1,234,567"
f"{ratio:.1%}"                     # → "75.6%"
f"{n:05d}"                         # → "00042"
f"{n:+}"                           # → "+42"
f"{n:b}"                           # → "101010"
f"{255:x}"                         # → "ff"

# Выравнивание
f"{'Hi':<10}"                      # → "Hi        "
f"{'Hi':>10}"                      # → "        Hi"
f"{'Hi':^10}"                      # → "    Hi    "
f"{'Hi':*^10}"                     # → "****Hi****"

# Прогресс-бар
current, total = 75, 100
pct = current / total
bar = "█" * int(50 * pct) + "░" * (50 - int(50 * pct))
f"{bar} {pct:.1%}"

# Таблица
for name, price in [("Apple", 2.5), ("Banana", 1.8)]:
    print(f"{name:<10} {price:>8.2f} руб.")
# Apple          2.50 руб.
# Banana         1.80 руб.
```

## 💡 Практические замечания

- f-строки **быстрее** `%` и `.format()` — Python вычисляет выражения напрямую
- f-строки **вычисляются сразу** при создании — нельзя сохранить как шаблон для повторного использования
- Для шаблонов которые используются многократно — лучше `.format()`
- `f"Hello"` без `{}` — лишняя f, лучше просто `"Hello"`

## ⚠️ Частые ошибки

**❌ Обратный слэш внутри `{}`:**
```python
f"{'\n'}"           # ❌ SyntaxError
nl = '\n'
f"{nl}"             # ✅
```

**❌ Пустые `{}`:**
```python
f"{}"               # ❌ SyntaxError
```

**❌ Думает что f-строка — шаблон:**
```python
x = 10
s = f"{x}"          # s = "10"
x = 20
print(s)            # → "10"  (не "20"! вычислилось при создании)
```

**❌ f-строка без переменных:**
```python
f"Hello, World!"    # ⚠️ работает, но бессмысленно — убери f
"Hello, World!"     # ✅ быстрее
```
