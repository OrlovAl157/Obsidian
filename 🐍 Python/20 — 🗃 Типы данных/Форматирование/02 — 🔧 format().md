# 🔧 Метод .format() — памятка

> Универсальный метод форматирования строк через `"шаблон {}".format(значения)`. Работает с Python 2.6+, поддерживает позиции, имена, атрибуты объектов и повторное использование аргументов.

## Справка

| Синтаксис | Что делает | Пример |
|---|---|---|
| `{}` | позиция по порядку | `"{} {}".format("a", "b")` → `"a b"` |
| `{0}` `{1}` | явная позиция | `"{1} {0}".format("a", "b")` → `"b a"` |
| `{name}` | именованный аргумент | `"{name}".format(name="Alice")` |
| `{0.attr}` | атрибут объекта | `"{0.name}".format(person)` |
| `{0[key]}` | элемент по ключу | `"{0[name]}".format(data)` |
| `{:формат}` | спецификатор формата | `"{:.2f}".format(3.14)` → `"3.14"` |

---

## 📊 Общая схема

```
"шаблон {поле:формат}".format(аргументы)
           │       │
           │       └── спецификатор (необязательно)
           │            .2f, >10, 05d, , и т.д.
           │
           └── поле (необязательно)
                пусто → по порядку
                0, 1  → явная позиция
                name  → именованный
                0.attr → атрибут объекта
```

## 🟢 Позиционные и именованные поля

**Позиционные — по порядку или явно:**

```python
# Пустые {} — по порядку
"Hello {} и {}".format("Alice", "Bob")     # → "Hello Alice и Bob"
"{} + {} = {}".format(2, 3, 5)            # → "2 + 3 = 5"

# Явные индексы — можно менять порядок
"{1} и {0}".format("Alice", "Bob")        # → "Bob и Alice"

# Повтор значения
"{0} {0} {0}".format("ha")               # → "ha ha ha"
```

**Именованные — через ключевые аргументы:**

```python
# Базовый синтаксис
"{name} — {age} лет".format(name="Alice", age=25)  # → "Alice — 25 лет"

# Из словаря через **
user = {"name": "Bob", "age": 30}
"{name} — {age} лет".format(**user)       # → "Bob — 30 лет"

# Шаблон используется повторно
template = "Привет, {name}! Ты записан на {date}."
print(template.format(name="Alice", date="01.01"))
print(template.format(name="Bob", date="02.01"))
```

## 🔵 Атрибуты и элементы

**Доступ к атрибутам объекта:**

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

person = Person("Alice", 25)
"{0.name} — {0.age} лет".format(person)   # → "Alice — 25 лет"
```

**Доступ к элементам коллекций:**

```python
# Список
data = [10, 20, 30]
"{0[0]} {0[1]} {0[2]}".format(data)       # → "10 20 30"

# Словарь
user = {"name": "Bob", "age": 30}
"{0[name]} — {0[age]} лет".format(user)   # → "Bob — 30 лет"
```

## 🔴 Динамическая ширина и точность

Ширину и точность можно передавать как аргументы:

```python
# Динамическая ширина
"{text:{width}}".format(text="Hello", width=10)    # → "Hello     "

# Динамическая точность
"{num:.{prec}f}".format(num=3.14159, prec=2)       # → "3.14"

# Оба параметра динамические
"{:{width}.{prec}f}".format(3.14159, width=8, prec=2)  # → "    3.14"
```

## ⚡ Быстрые примеры

```python
# Форматирование чисел
"{:.2f}".format(3.14159)          # → "3.14"
"{:05d}".format(42)               # → "00042"
"{:,}".format(1000000)            # → "1,000,000"
"{:.1%}".format(0.756)            # → "75.6%"
"{:+d}".format(42)                # → "+42"

# Выравнивание
"{:<10}".format("Hi")             # → "Hi        "
"{:>10}".format("Hi")             # → "        Hi"
"{:^10}".format("Hi")             # → "    Hi    "
"{:*^10}".format("Hi")            # → "****Hi****"

# Таблица
for name, qty, price in [("Apple", 150, 2.5), ("Banana", 200, 1.8)]:
    print("{:<10} {:>5} {:>8.2f}".format(name, qty, price))
# Apple         150     2.50
# Banana        200     1.80

# Время
"{:02d}:{:02d}:{:02d}".format(2, 35, 8)   # → "02:35:08"
```

## ⚠️ Частые ошибки

**❌ Смешал пустые `{}` и индексы:**
```python
"{} и {1}".format("Alice", "Bob")   # ❌ ValueError
"{} и {}".format("Alice", "Bob")    # ✅
"{0} и {1}".format("Alice", "Bob")  # ✅
```

**❌ Несуществующий индекс:**
```python
"{0} и {1}".format("Alice")         # ❌ IndexError
"{0} и {1}".format("Alice", "Bob")  # ✅
```

**❌ Неправильный порядок спецификаторов:**
```python
"{:5.2>f}".format(3.14)             # ❌ ValueError
"{:>5.2f}".format(3.14)             # ✅
```
