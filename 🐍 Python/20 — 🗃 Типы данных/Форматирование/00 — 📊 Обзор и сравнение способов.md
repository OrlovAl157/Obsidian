# 📊 Форматирование строк — обзор и сравнение

> В Python три основных способа форматирования строк: старый `%`, универсальный `.format()` и современный `f-строки`. Каждый имеет свою нишу, но для нового кода почти всегда выбирай f-строки.

## Справка

| Способ | Синтаксис | Python | Скорость |
|---|---|---|---|
| `%` | `"Hello %s" % name` | все версии | средняя |
| `.format()` | `"Hello {}".format(name)` | 2.6+ | средняя |
| f-строки | `f"Hello {name}"` | 3.6+ | быстрая |
| T-строки | `t"Hello {name}"` | 3.14+ | — |

---

## 📊 Общая схема

```
Форматирование строк
        │
        ├── % — старый стиль (legacy, но ещё встречается)
        │       "Hello %s, ты %d лет" % (name, age)
        │
        ├── .format() — универсальный (Python 2.6+)
        │       "Hello {}, ты {} лет".format(name, age)
        │
        ├── f-строки — современный (Python 3.6+) ✅ рекомендуется
        │       f"Hello {name}, ты {age} лет"
        │
        └── T-строки — для безопасности (Python 3.14+)
                t"SELECT * WHERE name = {name}"
```

## 🔧 Три способа рядом

Одна и та же задача — три способа:

```python
name = "Alice"
age = 25
price = 19.9

# % — старый стиль
"Hello %s, ты %d лет" % (name, age)          # → "Hello Alice, ты 25 лет"
"Цена: %.2f руб." % price                     # → "Цена: 19.90 руб."

# .format() — универсальный
"Hello {}, ты {} лет".format(name, age)       # → "Hello Alice, ты 25 лет"
"Цена: {:.2f} руб.".format(price)             # → "Цена: 19.90 руб."

# f-строки — современный
f"Hello {name}, ты {age} лет"                 # → "Hello Alice, ты 25 лет"
f"Цена: {price:.2f} руб."                     # → "Цена: 19.90 руб."
```

**Сравнение по ключевым параметрам:**

| Параметр | `%` | `.format()` | f-строки |
|---|---|---|---|
| Читаемость | 🟡 средняя | 🟡 средняя | 🟢 лучшая |
| Скорость | 🟡 средняя | 🟡 средняя | 🟢 быстрая |
| Выражения внутри | ❌ | ❌ | ✅ `f"{x + y}"` |
| Повтор значения | ✅ `%(n)s %(n)s` | ✅ `{0} {0}` | ✅ `{n} {n}` |
| Шаблоны | ✅ удобно | ✅ удобно | 🟡 менее удобно |
| Python 2 | ✅ | ✅ 2.6+ | ❌ |

## 🎯 Когда что использовать

**`%` — когда:**
- Читаешь или правишь старый код
- Простой вывод одной-двух переменных
- Привычен синтаксис `%s`, `%d`, `%f`

```python
# Типичный случай для %
print("Ошибка: %s в строке %d" % (msg, lineno))
```

**`.format()` — когда:**
- Нужен шаблон который используется много раз
- Нужно переставить аргументы `{1} {0}`
- Поддержка Python < 3.6

```python
# Шаблон используется повторно
template = "Привет, {name}! Ты записан на {date}."
print(template.format(name="Alice", date="01.01"))
print(template.format(name="Bob", date="02.01"))
```

**f-строки — когда:**
- Новый код на Python 3.6+
- Нужно вычисление прямо в строке
- Важна читаемость

```python
# Выражения прямо в строке
f"Итого: {price * quantity:.2f} руб."
f"Статус: {'активен' if is_active else 'неактивен'}"
```

**T-строки — когда:**
- Нужна защита от SQL/HTML инъекций
- Python 3.14+

```python
# Безопасный SQL
query = t"SELECT * FROM users WHERE name = {name}"
```

## ⚠️ Частые ошибки

**❌ Забыл кортеж в `%` с несколькими значениями:**
```python
"%s и %s" % "Alice", "Bob"   # ❌ TypeError
"%s и %s" % ("Alice", "Bob") # ✅
```

**❌ Смешал пустые `{}` и индексы в `.format()`:**
```python
"{} и {1}".format("Alice", "Bob")  # ❌ ValueError
"{} и {}".format("Alice", "Bob")   # ✅
"{0} и {1}".format("Alice", "Bob") # ✅
```

**❌ Обратный слэш внутри `{}` в f-строке:**
```python
f"{'\n'}"        # ❌ SyntaxError
nl = '\n'
f"{nl}"          # ✅
```
