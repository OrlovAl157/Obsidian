# 📆 Тип date — памятка

> `date` хранит только дату (год, месяц, день) — без времени. Используй его когда время суток не имеет значения: день рождения, дата события, крайний срок в днях.

## Справка

| Что нужно | Код |
|---|---|
| Сегодняшняя дата | `date.today()` |
| Конкретная дата | `date(2024, 12, 31)` |
| Из ISO-строки | `date.fromisoformat('2024-12-31')` |
| В ISO-строку | `d.isoformat()` |
| В свой формат | `d.strftime('%d.%m.%Y')` |
| День недели (0=пн) | `d.weekday()` |
| День недели (1=пн, ISO) | `d.isoweekday()` |
| Заменить поле | `d.replace(year=2025)` |
| Прибавить дни | `d + timedelta(days=7)` |
| Разница между датами | `d1 - d2` → `timedelta` |

## 🟢 Создание

```python
from datetime import date

today = date.today()                    # сегодняшняя дата — самый частый способ
d = date(2024, 12, 31)                  # конкретная дата (год, месяц, день)

# Из строки
date.fromisoformat('2024-12-31')        # только формат ISO: YYYY-MM-DD
date.fromordinal(738885)                # из порядкового номера дня (с 01.01.0001)
date.fromtimestamp(1704063599)          # из Unix timestamp
```

## 🔵 Атрибуты и методы

```python
from datetime import date

d = date(2024, 12, 31)

# Атрибуты — только для чтения
d.year          # 2024
d.month         # 12
d.day           # 31

# День недели
d.weekday()     # 0-6, где 0 = понедельник (в стиле Python)
d.isoweekday()  # 1-7, где 1 = понедельник (в стиле ISO-стандарта)

# Строковое представление
d.isoformat()          # '2024-12-31' — стандартный ISO-формат
d.strftime('%d.%m.%Y') # '31.12.2024' — свой формат (см. [[05 — 📝 Форматирование]])

# Порядковый номер дня с начала "эры" Python (01.01.0001 = день 1)
d.toordinal()   # 738885 — редко нужен напрямую, но полезен для расчётов интервалов

# Замена отдельных полей — создаёт НОВЫЙ объект, исходный не меняется
d.replace(year=2025)    # date(2025, 12, 31)
d.replace(month=1)      # date(2024, 1, 31)
```

**Важно:** `date` неизменяем (immutable) — все методы вроде `replace()` возвращают новый объект, а не меняют существующий.

## 🔴 Арифметика

`date` умеет складываться и вычитаться только с `timedelta` (интервалом) — полная таблица правил в [[04 — ⏱ timedelta]]. Здесь — самое частое:

```python
from datetime import date, timedelta

today = date.today()

today + timedelta(days=1)       # завтра
today - timedelta(days=1)       # вчера
today - timedelta(weeks=1)      # неделю назад

# Разница между двумя датами — всегда возвращает timedelta
d1 = date(2024, 12, 31)
d2 = date(2024, 1, 1)
diff = d1 - d2          # timedelta(days=365)
diff.days               # 365 — самое частое, что нужно из разницы дат

# Сравнение — работает как обычно
date(2024, 1, 1) < date(2024, 12, 31)   # True
```

**Нельзя:** складывать `date + date` (ошибка `TypeError`) — логически бессмысленно, две даты не образуют третью дату.

## 💻 Практические примеры

```python
from datetime import date

# ⚠️ Наивный способ через // 365 — неточный!
birth = date(1990, 5, 15)
today = date.today()
age_days = (today - birth).days
age_years_naive = age_days // 365   # приблизительно, накапливает погрешность из-за високосных лет

# ✅ Точный способ — учитывает, был ли уже день рождения в этом году
def calculate_age(birth_date):
    today = date.today()
    age = today.year - birth_date.year
    if (today.month, today.day) < (birth_date.month, birth_date.day):
        age -= 1   # день рождения ещё не наступил в этом году
    return age
```

**Почему `// 365` не годится:** каждый 4-й год — високосный (366 дней), поэтому за большой промежуток лет деление на 365 накапливает ошибку — может сместить результат на день или больше при длинных интервалах. Для точного возраста нужно сравнивать не общее число дней, а именно месяц-и-день.

```python
from datetime import date, timedelta

# Последний день месяца — трюк через переход в следующий месяц
def last_day_of_month(d):
    next_month = d.replace(day=28) + timedelta(days=4)  # точно попадём в следующий месяц
    return next_month - timedelta(days=next_month.day)
```
