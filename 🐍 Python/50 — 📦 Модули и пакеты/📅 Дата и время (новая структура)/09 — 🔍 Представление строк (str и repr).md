# 🔍 Представление строк: str() и repr()

> Общая памятка по `str()`/`repr()` для всех типов данных лежит в [[__str__, __repr__ Строковое представление объектов]] (папка ООП → Магические методы). Этот файл — версия, сфокусированная конкретно на объектах `datetime`, оставлена здесь для быстрого доступа без ухода в другую папку.

## 📌 Коротко

> **str()** — красивое представление для пользователей, **repr()** — точное представление для разработчиков. Для datetime они отличаются форматом и назначением.

---

## Справка

| Что нужно | Код |
|---|---|
| Для вывода пользователю | `str(dt)` или `print(dt)` |
| Для отладки/логов | `repr(dt)` |
| Переопределить у своего класса | `__str__(self)`, `__repr__(self)` |

---

## 💡 Полезные советы

- **str()** → в `print()` и для вывода пользователю
- **repr()** → в отладке, консоли и логах
- **repr() должен быть точным** — идеально если `eval(repr(obj)) == obj`
- **Для datetime используйте strftime()** → если нужен свой формат
- **В логах используйте repr()** → полная информация об объекте

---

## 🚀 Быстрая справка

| Параметр | `str()` | `repr()` |
|---|---|---|
| **Для кого** | 👤 Пользователей | 👨‍💻 Разработчиков |
| **Цель** | 📖 Читаемость | 🎯 Точность |
| **Вызов** | `str(obj)` или `print(obj)` | `repr(obj)` или в консоли |
| **Метод** | `__str__()` | `__repr__()` |

## 📖 Теория

### `str()` — для пользователей

```python
from datetime import datetime

dt = datetime(2025, 10, 16, 14, 30, 45)

print(str(dt))      # 2025-10-16 14:30:45
print(dt)            # то же самое (print использует str())
```

- ✅ Красивый, понятный формат
- ✅ Можно опускать технические детали
- ✅ Для `print()`, `format()`, f-строк

### `repr()` — для разработчиков

```python
print(repr(dt))     # datetime.datetime(2025, 10, 16, 14, 30, 45)
dt                   # в консоли выводит то же самое
```

- ✅ Максимально точное представление
- ✅ Идеально: `eval(repr(obj)) == obj`
- ✅ Для консоли, отладки, логов

### То же самое для date и time

Правило одинаковое для всех типов модуля `datetime` — не только для `datetime`, но и для `date` и `time` по отдельности:

```python
from datetime import date, time

my_date = date(2021, 12, 31)
my_time = time(11, 20, 54)

print(str(my_date))    # 2021-12-31
print(str(my_time))    # 11:20:54

print(repr(my_date))   # datetime.date(2021, 12, 31)
print(repr(my_time))   # datetime.time(11, 20, 54)
```

### Одиночный объект vs список объектов

Для одиночного объекта `print()` сам вызывает `str()` за кулисами — явно вызывать не нужно. А вот при печати **списка** объектов Python использует `repr()` для каждого элемента, даже если сам список выводится через `print()`:

```python
from datetime import date

dates = [date(2021, 12, 31), date(2019, 10, 6), date(2022, 11, 8)]

print(dates)
# [datetime.date(2021, 12, 31), datetime.date(2019, 10, 6), datetime.date(2022, 11, 8)]
# ↑ это repr() каждого элемента, а не str()!

# Чтобы вывести список в удобном человеку виде — распаковка через *
print(*dates, sep='\n')
# 2021-12-31
# 2019-10-06
# 2022-11-08
```

## 💻 Примеры

```python
from datetime import datetime, timezone, timedelta

dt = datetime(2025, 10, 16, 14, 30, 45)
print(str(dt))      # 2025-10-16 14:30:45
print(repr(dt))     # datetime.datetime(2025, 10, 16, 14, 30, 45)

# С микросекундами
dt_micro = datetime(2025, 10, 16, 14, 30, 45, 123456)
print(str(dt_micro))    # 2025-10-16 14:30:45.123456
print(repr(dt_micro))   # datetime.datetime(2025, 10, 16, 14, 30, 45, 123456)

# С временной зоной
tz = timezone(timedelta(hours=3))
dt_tz = datetime(2025, 10, 16, 14, 30, 45, tzinfo=tz)
print(str(dt_tz))       # 2025-10-16 14:30:45+03:00
print(repr(dt_tz))      # datetime.datetime(2025, 10, 16, 14, 30, 45, tzinfo=datetime.timezone(datetime.timedelta(seconds=10800)))
```

## 🎯 Когда что использовать

| Ситуация | Использовать |
|---|---|
| Вывод для пользователя | `str()` |
| Отладка / логирование | `repr()` |
| Консоль Python | `repr()` |
| Форматирование для UI | `str()` |
