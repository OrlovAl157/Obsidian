# 📝 Форматирование дат — памятка

> Форматирование — это преобразование объектов `date`/`time`/`datetime` в строки и обратно. `strftime()` превращает объект в строку по шаблону, `strptime()` — парсит строку в объект по тому же шаблону. Коды формата (`%Y`, `%m`, `%d`...) чувствительны к регистру — `%Y` и `%y` это разные годы.

## Справка

| Что нужно | Код |
|---|---|
| Объект → строка | `dt.strftime('%d.%m.%Y')` |
| Строка → объект по формату | `datetime.strptime(s, '%d.%m.%Y')` |
| Строка → объект (ISO) | `datetime.fromisoformat(s)` |
| Объект → строка (ISO) | `dt.isoformat()` |
| Установить русскую локаль | `locale.setlocale(locale.LC_TIME, 'ru_RU.UTF-8')` |
| Год/месяц/день | `%Y` `%m` `%d` |
| Час/минута/секунда | `%H` `%M` `%S` |
| Название дня/месяца | `%A` `%B` |

## 🚀 Частые форматы

| Что нужно | Формат | Пример |
|---|---|---|
| Российская дата | `%d.%m.%Y` | 16.10.2025 |
| Российская дата + время | `%d.%m.%Y %H:%M:%S` | 16.10.2025 14:30:45 |
| ISO дата | `%Y-%m-%d` | 2025-10-16 |
| ISO дата + время | `%Y-%m-%d %H:%M:%S` | 2025-10-16 14:30:45 |
| Американская дата | `%m/%d/%Y` | 10/16/2025 |
| Время 24-часовое | `%H:%M:%S` | 14:30:45 |
| Время 12-часовое | `%I:%M:%S %p` | 02:30:45 PM |

**Совет:** для хранения в БД и логах используй ISO (`%Y-%m-%d %H:%M:%S`) — сортируется как строка в правильном порядке. Для отчётов на русском — привычный `%d.%m.%Y`.

## 📋 Полная таблица кодов

### 📅 День недели

| Код | Значение | Пример |
|---|---|---|
| `%a` | Сокращённый день недели | Mon, ..., Sun |
| `%A` | Полный день недели | Monday, ..., Sunday |
| `%w` | Номер дня [0-6] | 0 (вс), ..., 6 (сб) — в стиле C, воскресенье первое! |

### 📆 День

| Код | Значение | Пример |
|---|---|---|
| `%d` | День месяца [01-31] | 01, ..., 31 |
| `%e` | День месяца без лидирующего нуля | 1, ..., 31 |
| `%j` | День года [001-366] | 001, ..., 366 |

### 📋 Месяц

| Код | Значение | Пример |
|---|---|---|
| `%b` | Сокращённый месяц | Jan, ..., Dec |
| `%B` | Полный месяц | January, ..., December |
| `%m` | Номер месяца [01-12] | 01, ..., 12 |

### 📊 Год

| Код | Значение | Пример |
|---|---|---|
| `%y` | Год без века [00-99] | 00, ..., 99 |
| `%Y` | Год с веком | 0001, ..., 2025, ..., 9999 |

### ⏰ Время

| Код | Значение | Пример |
|---|---|---|
| `%H` | Час 24ч [00-23] | 00, ..., 23 |
| `%I` | Час 12ч [01-12] | 01, ..., 12 |
| `%M` | Минуты [00-59] | 00, ..., 59 |
| `%S` | Секунды [00-59] | 00, ..., 59 |
| `%f` | Микросекунды | 000000-999999 |
| `%p` | AM/PM | AM, PM |

### 🌍 Временная зона

| Код | Значение | Пример |
|---|---|---|
| `%z` | UTC смещение | +0000, -0400, +1030 |
| `%Z` | Название зоны | UTC, EST, CST |

### 📍 Неделя года

| Код | Значение | Пример |
|---|---|---|
| `%U` | Неделя [00-53], неделя начинается с воскресенья | 00, ..., 53 |
| `%W` | Неделя [00-53], неделя начинается с понедельника | 00, ..., 53 |

### 🔀 Комбинированные

| Код | Значение | Пример |
|---|---|---|
| `%c` | Дата и время (локаль) | Tue Aug 16 21:30:00 1988 |
| `%x` | Дата (локаль) | 08/16/1988 |
| `%X` | Время (локаль) | 21:30:00 |
| `%%` | Символ % | % |

## 🔄 strftime и strptime

Легко перепутать местами — вот мнемоника: **strf**time = strf**ormat**, "форматирование" (объект → строка). **strp**time = str**p**arse, "разбор" (строка → объект).

### Дата → Строка (strftime)

```python
from datetime import datetime

dt = datetime(2025, 10, 16, 14, 30, 45)

dt.strftime('%d.%m.%Y')              # '16.10.2025'
dt.strftime('%Y-%m-%d %H:%M:%S')     # '2025-10-16 14:30:45'
dt.strftime('%A, %d %B %Y')          # 'Thursday, 16 October 2025'
dt.strftime('%a, %d %b %Y %H:%M:%S') # 'Thu, 16 Oct 2025 14:30:45' — формат RFC 2822 для email
dt.strftime('%A, %B %d, %Y')         # 'Thursday, October 16, 2025' — полная дата текстом
dt.strftime('%Y-%m-%d %H:%M:%S.%f')  # '2025-10-16 14:30:45.123456' — с микросекундами
```

### Строка → Дата (strptime)

Формат в `strptime()` должен ТОЧНО совпадать со структурой строки:

```python
from datetime import datetime

dt = datetime.strptime('16.10.2025 14:30:45', '%d.%m.%Y %H:%M:%S')
dt.day, dt.month, dt.year   # 16, 10, 2025

# Разные форматы одной и той же даты — результат одинаковый
dt1 = datetime.strptime('16.10.2025', '%d.%m.%Y')
dt2 = datetime.strptime('10/16/2025', '%m/%d/%Y')
dt3 = datetime.strptime('2025-10-16', '%Y-%m-%d')
dt1 == dt2 == dt3   # True
```

### Локализация (названия месяцев/дней на русском)

По умолчанию `%A`, `%B` и подобные коды выводят названия на английском. Чтобы получить русские — нужно установить локаль:

```python
import locale
from datetime import datetime

locale.setlocale(locale.LC_TIME, 'ru_RU.UTF-8')   # может отличаться в зависимости от ОС

now = datetime.now()
now.strftime('%A, %d %B %Y')   # 'понедельник, 16 октября 2025' — уже на русском
```

**На практике** нужная локаль может быть не установлена в системе (особенно на серверах/в контейнерах) — тогда `setlocale()` выбросит `locale.Error`. Оборачивай в `try/except`, чтобы приложение не падало, если локали нет:

```python
import locale
from datetime import datetime

try:
    locale.setlocale(locale.LC_TIME, 'ru_RU.UTF-8')
except locale.Error:
    pass   # локаль недоступна — останется английский вывод, но код не упадёт

dt = datetime.now()
user_format = dt.strftime('%d %B %Y года, %A')
# 'на русском, если локаль установилась, иначе на английском — но без падения'
```

### Практические примеры

```python
from datetime import datetime

# Имя файла с датой — сортируется корректно благодаря числовому формату
dt = datetime.now()
filename = f"report_{dt.strftime('%Y%m%d_%H%M%S')}.txt"   # report_20251016_143045.txt

# Логирование с временной меткой
def log_message(msg):
    timestamp = datetime.now().strftime('%Y-%m-%d %H:%M:%S')
    print(f"[{timestamp}] {msg}")
```

## ⚠️ Частые ошибки

```python
from datetime import datetime

# ❌ Перепутан %Y и %y
# datetime.strptime('25', '%Y')      # ValueError — %Y ждёт 4 цифры, а не 2
datetime.strptime('2025', '%Y')      # ✅

# ❌ Формат не совпадает со структурой строки
# datetime.strptime('16.10.2025', '%Y-%m-%d')   # ValueError!
datetime.strptime('16.10.2025', '%d.%m.%Y')     # ✅

# ❌ %H — 24-часовой формат, но используется вместе с %p (AM/PM)
# dt.strftime('%H:%M:%S %p')   # технически работает, но %H игнорирует AM/PM — путаница
dt = datetime.now()
dt.strftime('%I:%M:%S %p')     # ✅ %I — правильный код для 12-часового формата

# ❌ Забыли про микросекунды в формате при парсинге строки с ними
# datetime.strptime('2025-10-16 14:30:45.123456', '%Y-%m-%d %H:%M:%S')   # ValueError!
datetime.strptime('2025-10-16 14:30:45.123456', '%Y-%m-%d %H:%M:%S.%f')  # ✅ добавлен %f
```
