# ⏰ Тип time — памятка

> `time` хранит только время суток (час, минута, секунда, микросекунда) — без привязки к какой-либо дате. Используется реже, чем `date`/`datetime`, потому что у него нет арифметики.

**Не путай с модулем `time`!** Это тип данных из модуля `datetime` (`from datetime import time`). Модуль `time` — совсем другая вещь, про паузы и замер производительности, см. [[06 — 📚 Модуль time]].

## Справка

| Что нужно | Код |
|---|---|
| Создать время | `time(14, 30, 45)` |
| С микросекундами | `time(14, 30, 45, 500000)` |
| Из ISO-строки | `time.fromisoformat('14:30:45')` |
| В ISO-строку | `t.isoformat()` |
| В свой формат | `t.strftime('%H:%M')` |
| Заменить поле | `t.replace(hour=15)` |
| Арифметика | ❌ не поддерживается — см. ниже |

## 🟢 Создание

```python
from datetime import time

t = time(14, 30, 45)              # 14:30:45 (час, минута, секунда)
t = time(14, 30, 45, 500000)      # 14:30:45.500000 (+ микросекунды)
t = time(14, 30)                  # секунды необязательны — 14:30:00

# Из строки (только ISO-формат)
time.fromisoformat('14:30:45')
```

## 🔵 Атрибуты и методы

```python
from datetime import time

t = time(14, 30, 45, 500000)

# Атрибуты
t.hour          # 14
t.minute        # 30
t.second        # 45
t.microsecond   # 500000

# Строковое представление
t.isoformat()          # '14:30:45.500000'
t.strftime('%H:%M')    # '14:30' — свой формат, см. [[05 — 📝 Форматирование]]

# Замена значений — новый объект, исходный не меняется
t.replace(hour=15)      # time(15, 30, 45, 500000)
t.replace(minute=0)     # time(14, 0, 45, 500000)
```

## 🔴 Почему у time нет арифметики

```python
from datetime import time, timedelta

t = time(14, 30, 45)

# t + timedelta(hours=1)   # ❌ TypeError!
# t - timedelta(hours=1)   # ❌ TypeError!
# time(15, 45) - time(14, 30)   # ❌ TypeError!
```

Причина логичная: время "14:30" без даты — это не точка на временной шкале, а просто отметка внутри суток. Прибавить к нему час можно легко (15:30), но что делать при переходе через полночь (23:30 + 2 часа = 01:30 следующего дня)? Для этого уже нужна дата, а `time` её не хранит. Python не берёт на себя это решение — и просто не разрешает арифметику.

**Решение** — сначала объединить `time` с `date` через `datetime.combine()`, и уже с получившимся `datetime` делать арифметику:

```python
from datetime import datetime, time, date, timedelta

t = time(14, 30)
today = date.today()

dt = datetime.combine(today, t)   # получили полноценный datetime

new_dt = dt + timedelta(hours=2)  # теперь арифметика работает
new_time = new_dt.time()          # обратно достаём time — 16:30:00
```
