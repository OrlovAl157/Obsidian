# 🏠 Дата и время в Python — обзор

> Python работает с датой и временем через модуль `datetime`, в котором есть 4 типа данных (`date`, `time`, `datetime`, `timedelta`), плюс два отдельных модуля — `time` (низкоуровневые функции: паузы, замер времени, Unix timestamp) и `calendar` (текстовые календари, проверка високосных годов). Важно не путать тип `time` из `datetime` с одноимённым модулем `time` — это два разных инструмента с разным назначением.

## ⚡ Быстрая шпаргалка (самое частое)

```python
from datetime import datetime, date, timedelta

# Текущие дата и время
datetime.now()                  # 2025-10-16 14:30:45.123456
date.today()                    # 2025-10-16

# Строка → дата
datetime.strptime('16.10.2025', '%d.%m.%Y')
date.fromisoformat('2025-10-16')

# Дата → строка
dt.strftime('%d.%m.%Y')         # '16.10.2025'

# Арифметика
date.today() + timedelta(days=7)     # через неделю
d1 - d2                              # разница → timedelta
(d1 - d2).days                       # разница в днях
```
