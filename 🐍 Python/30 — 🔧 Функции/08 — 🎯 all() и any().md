# 🎯 all() и any() — памятка

> `all()` возвращает `True`, если **все** элементы итерируемого объекта истинны. `any()` возвращает `True`, если истинен **хотя бы один**. Оба останавливаются, как только результат известен.

## Справка

| Функция | Возвращает `True`, если | Для пустого итерируемого | Останавливается |
|---|---|---|---|
| `all(iterable)` | все элементы истинны | `True` | на первом ложном |
| `any(iterable)` | хотя бы один элемент истинен | `False` | на первом истинном |

| Возвращает | Тип |
|---|---|
| Результат проверки | всегда `bool` (`True` / `False`), а не сам элемент |

| Ложные значения | Всё остальное |
|---|---|
| `False`, `None`, `0`, `0.0`, `''`, `[]`, `()`, `{}`, `set()` | истинно |

---

## 📊 Общая схема

```
all([a, b, c])  ≡  bool(a) and bool(b) and bool(c)
any([a, b, c])  ≡  bool(a) or  bool(b) or  bool(c)

all([True, True, False])   → False   ← нашли ложный, дальше не смотрим
any([False, True, False])  → True    ← нашли истинный, дальше не смотрим
```

> 💡 Аналогия: `all` — «горят **все** лампочки в гирлянде», `any` — «горит **хотя бы одна**».

## 🤝 Функция all

```python
all([True, True, True])     # → True
all([True, False, True])    # → False
all([1, 2, 3])              # → True   (все числа ≠ 0)
all([1, 0, 3])              # → False  (0 — ложное значение)
all(['a', 'b'])             # → True
all(['a', ''])              # → False  (пустая строка ложная)
```

С условием через генератор:

```python
numbers = [2, 4, 6, 8]

all(x % 2 == 0 for x in numbers)   # → True   (все чётные)
all(x > 3 for x in numbers)        # → False  (2 не больше 3)

# Заполнены ли все поля формы
fields = ['Alice', 'alice@mail.com', '']
all(fields)                        # → False  (последнее поле пустое)
```

---

## 🔍 Функция any

```python
any([False, False, True])   # → True
any([False, False, False])  # → False
any([0, 0, 5])              # → True   (5 истинно)
any([0, '', None])          # → False  (все элементы ложные)
```

С условием через генератор:

```python
numbers = [3, -1, 7]

any(x < 0 for x in numbers)        # → True   (есть отрицательное)
any(x > 10 for x in numbers)       # → False  (больших десяти нет)

# Есть ли в пароле цифра
password = 'abc123'
any(c.isdigit() for c in password) # → True
any(c.isupper() for c in password) # → False
```

## 🕳 Пустой итерируемый объект

```python
all([])   # → True    (нет ни одного ложного элемента)
any([])   # → False   (нет ни одного истинного элемента)
```

> 💡 Аналогия: в пустой аудитории «все сдали экзамен» — верно, ведь нет ни одного, кто не сдал. А «хоть кто-то сдал» — неверно: некому было сдавать.

Это самая частая ловушка: если условие проверяют на пустом списке, `all` вернёт `True`.

```python
scores = []
all(s >= 60 for s in scores)             # → True  ❌ зачёт «у всех», хотя оценок нет
bool(scores) and all(s >= 60 for s in scores)   # → False  ✅ пустоту проверяем отдельно
```

## 🚦 Ленивость и остановка

Обе функции перебирают элементы по одному и **прекращают работу**, как только ответ очевиден.

```python
def check(x):
    print(f'проверяю {x}')
    return x > 0

all(check(x) for x in [1, -2, 3, 4])
# проверяю 1
# проверяю -2
# → False   (3 и 4 даже не проверялись)

any(check(x) for x in [-1, 2, 3])
# проверяю -1
# проверяю 2
# → True    (3 не проверялось)
```

Остановка работает только с **генератором**. Списковое включение сначала вычисляется целиком:

```python
all(check(x) for x in [1, -2, 3, 4])    # ✅ генератор: остановится на -2
all([check(x) for x in [1, -2, 3, 4]])  # ❌ список: проверит все 4 элемента, потом all
```

## 🧩 Типичные шаблоны

```python
# Все элементы нужного типа
data = [1, 2, 3]
all(isinstance(x, int) for x in data)        # → True

# Список отсортирован по возрастанию
nums = [1, 2, 2, 5]
all(a <= b for a, b in zip(nums, nums[1:]))  # → True

# Встречается ли любое из слов
text = 'build failed with error'
any(word in text for word in ['error', 'fail'])   # → True

# Все строки состоят из цифр
items = ['12', '7', '305']
all(map(str.isdigit, items))                 # → True

# Нет ни одного отрицательного (эквивалентные записи)
nums = [4, 8, 15]
not any(x < 0 for x in nums)                 # → True
all(x >= 0 for x in nums)                    # → True
```

Связь между функциями (законы де Моргана):

```
not all(cond(x))  ≡  any(not cond(x))
not any(cond(x))  ≡  all(not cond(x))
```

## ⚡ Быстрые примеры

```python
all([])                              # True
any([])                              # False
all(x > 0 for x in [1, 2, 3])        # True
any(x > 2 for x in [1, 2, 3])        # True
all('abc')                           # True   (все символы непустые)
any('')                              # False
all({1: 0})                          # True   (словарь — по ключам: ключ 1 истинен)
any({0: 'x'})                        # False  (ключ 0 ложный)
all(range(1, 5))                     # True   (1, 2, 3, 4 — нет нуля)
all(range(0, 5))                     # False  (есть 0)
any(c in 'aeiou' for c in 'sky')     # False
```

## 💡 Практические замечания

- Принимают **один** любой итерируемый объект: список, кортеж, строку, множество, словарь, `range`, генератор
- Проверяют **истинность** элемента, а не равенство `True`: `all([1, 'a'])` → `True`
- Для словаря перебираются **ключи**, а не значения
- Возвращают `bool`, в отличие от `and` / `or`, которые возвращают сам элемент
- С генератором работают лениво и экономят время и память
- Условие лучше выносить в генератор: `all(x > 0 for x in nums)`, а не заранее строить список

## ⚠️ Частые ошибки

**❌ Ждать `False` от `all([])`:**
```python
all([])   # → True, а не False
# Если пустой список — это ошибка данных, проверяй его отдельно
```

**❌ Передавать несколько аргументов:**
```python
any(1, 2, 3)     # ❌ TypeError: any() takes exactly one argument (3 given)
any([1, 2, 3])   # ✅ один итерируемый объект
```

**❌ Ждать, что `any` вернёт найденный элемент:**
```python
any([0, 'a', ''])   # → True, а не 'a'
# Нужен сам элемент — используй next() с генератором:
next((x for x in [0, 'a', ''] if x), None)   # → 'a'
```

**❌ Список вместо генератора внутри `all` / `any`:**
```python
any([expensive(x) for x in items])   # ❌ считает всё, потом ищет
any(expensive(x) for x in items)     # ✅ остановится на первом истинном
```

**❌ Забыть, что истинность ≠ равенство `True`:**
```python
all([2, 'a'])                       # → True, хотя 2 == True → False
all(x is True for x in [2, 'a'])    # → False, если нужна именно проверка на True
```

## ✅ Главные правила

✅ `all` — все истинны, `any` — хотя бы один  
✅ `all([])` → `True`, `any([])` → `False`  
✅ Обе функции ленивы: останавливаются на первом решающем элементе  
✅ Условие передавай генератором, а не списком  
✅ Результат всегда `bool`, а не найденный элемент  
✅ На пустых данных проверяй пустоту отдельно  
✅ `not any(...)` ≡ `all(not ...)`, `not all(...)` ≡ `any(not ...)`
