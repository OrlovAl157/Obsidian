## 🗄 SQL-термины

| Слово | Перевод | Пример |
|---|---|---|
| `AUTO_INCREMENT` | автоувеличение (автоинкремент) | `id INT PRIMARY KEY AUTO_INCREMENT` |
| `PRIMARY KEY` | первичный ключ | `id INT PRIMARY KEY` |
| `REFERENCES` | ссылается на | `FOREIGN KEY (author_id) REFERENCES Authors(id)` |
| `CASCADE` | каскад, каскадный | `ON DELETE CASCADE` |
| `ALTER` | изменить, изменять | `ALTER TABLE Books ADD COLUMN price DECIMAL(10,2);` |
