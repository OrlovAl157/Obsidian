# 📖 IT-термины — английские слова для программирования

> Слова и выражения, которые часто встречаются в коде, документации и общении на тему программирования (SQL, Python, общий IT-английский). Формат: слово → перевод → пример использования в предложении.

## 🔤 Общие IT-термины

| Слово | Перевод | Пример |
|---|---|---|
| `bug` | ошибка, баг | `There's a bug in the login form.` |
| `debug` | отлаживать | `I spent an hour debugging this function.` |
| `feature` | функция, возможность | `We added a new feature to the app.` |
| `deploy` | развернуть (в продакшн) | `We deploy the app every Friday.` |
| `commit` | зафиксировать изменения | `Don't forget to commit your changes.` |
| `merge` | слить (ветки) | `Merge the branch into main.` |
| `bump` | бросить, забить на что-то / повысить версию | `Let's bump the version number.` |
| `deprecated` | устаревший, не рекомендуется к использованию | `This method is deprecated, use the new one.` |
| `refactor` | переработать код без изменения поведения | `We need to refactor this messy function.` |
| `verbose` | подробный (о выводе/логах) | `Run the script in verbose mode to see details.` |

## 🗄 SQL-термины

| Слово | Перевод | Пример |
|---|---|---|
| `query` | запрос | `Write a query to select all users.` |
| `constraint` | ограничение | `Add a NOT NULL constraint to this column.` |
| `row` | строка (записи в таблице) | `This table has 10,000 rows.` |
| `column` | столбец | `Add a new column called "email".` |
| `join` | объединение (таблиц) | `Use a JOIN to combine data from two tables.` |
| `nested` | вложенный | `This is a nested subquery.` |
| `retrieve` | извлекать (данные) | `Retrieve all records where the price is above 100.` |
| `duplicate` | дубликат, дублирующийся | `Remove duplicate rows from the table.` |
| `schema` | схема (базы данных) | `The schema defines the structure of the database.` |
| `index` | индекс | `An index speeds up search on this column.` |

## 🐍 Python-термины

| Слово | Перевод | Пример |
|---|---|---|
| `loop` | цикл | `Use a loop to iterate over the list.` |
| `iterable` | итерируемый объект | `A list is an iterable in Python.` |
| `mutable` | изменяемый | `Lists are mutable, tuples are not.` |
| `raise` | вызвать (исключение) | `Raise a ValueError if the input is invalid.` |
| `catch` (исключение) | перехватить (ошибку) | `Catch the exception with a try/except block.` |
| `inherit` | наследовать | `This class inherits from the base class.` |
| `override` | переопределить (метод) | `Override the __str__ method in your class.` |
| `namespace` | пространство имён | `Each module has its own namespace.` |
| `wrapper` | обёртка (декоратор/функция) | `This decorator is a wrapper around the original function.` |
| `keyword argument` | именованный аргумент | `Pass the value as a keyword argument.` |
