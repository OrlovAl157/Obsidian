# 🧹 Очистка данных

> Реальные данные почти всегда «грязные»: пропуски, дубли, неверные типы, строковые даты. Pandas даёт набор инструментов привести их в порядок до того, как считать статистику или строить графики.

## Справка

| Метод | Что делает |
|---|---|
| `df.isna()` / `df.isnull()` | где есть пропуски (True/False) |
| `df.dropna()` | удалить строки с пропусками |
| `df.fillna(value)` | заполнить пропуски значением |
| `df.duplicated()` | где есть дубли строк |
| `df.drop_duplicates()` | удалить дубли |
| `df.astype(type)` | привести к типу |
| `pd.to_datetime(col)` | строку превратить в дату |
| `df['col'].apply(func)` | применить функцию к каждому значению колонки |
| `df.apply(func, axis=1)` | применить функцию к каждой строке |
| `df['col'].map(func_or_dict)` | применить функцию/словарь поэлементно к Series |
| `df.applymap(func)` | применить функцию к каждой ячейке всего DataFrame |

## 🕳 Пропуски (NaN)

```python
df = pd.DataFrame({
    'name': ['Alice', 'Bob', None],
    'age': [28, None, 25]
})

df.isna()
#     name    age
# 0  False  False
# 1  False   True
# 2   True  False

df.isna().sum()     # количество пропусков по каждой колонке
# name    1
# age     1
```

**Удалить строки с пропусками:**

```python
df.dropna()                       # удалить строку, если есть хоть один NaN
df.dropna(subset=['age'])         # удалить, только если NaN именно в age
df.dropna(how='all')              # удалить, только если ВСЕ значения в строке — NaN
```

**Заполнить пропуски:**

```python
df['age'].fillna(0)                        # заполнить конкретным значением
df['age'].fillna(df['age'].mean())          # заполнить средним
df['age'].fillna(method='ffill')            # заполнить предыдущим значением (forward fill)
df.fillna({'age': 0, 'name': 'Unknown'})    # разные значения для разных колонок
```

> ⚠️ `fillna` по умолчанию возвращает **новый** `DataFrame`, не меняет исходный. Чтобы изменить на месте — `df['age'].fillna(0, inplace=True)` или переприсвоить: `df['age'] = df['age'].fillna(0)`.

## 🔁 Дубликаты

```python
df = pd.DataFrame({
    'name': ['Alice', 'Bob', 'Alice'],
    'age': [28, 34, 28]
})

df.duplicated()
# 0    False
# 1    False
# 2     True   ← полностью совпадает со строкой 0

df.drop_duplicates()            # удалить полные дубли строк
df.drop_duplicates(subset=['name'])   # дубль — если совпало только имя
df.drop_duplicates(keep='last')       # оставить последний дубль, а не первый
```

## 🧬 Приведение типов (astype)

```python
df['age'] = df['age'].astype(int)        # float64 → int64 (не сработает, если остались NaN)
df['id'] = df['id'].astype(str)          # число → строка (защита ведущих нулей)
df['price'] = df['price'].astype(float)
df['is_active'] = df['is_active'].astype(bool)
```

> ⚠️ `astype(int)` упадёт с ошибкой, если в колонке есть `NaN` — целочисленный тип не умеет хранить пропуски. Сначала `fillna`, потом `astype(int)`.

```python
df['age'].fillna(0).astype(int)   # ✅ сначала убрали NaN, потом привели к int
```

## 📅 Даты (to_datetime)

Даты из CSV/Excel почти всегда приходят как строки — их нужно явно превратить в дату.

```python
df['created_at'] = pd.to_datetime(df['created_at'])
# '2024-01-15' (строка) → Timestamp('2024-01-15 00:00:00')
```

После этого доступны операции с датами:

```python
df['created_at'].dt.year        # год
df['created_at'].dt.month       # месяц
df['created_at'].dt.day_name()  # день недели
df['created_at'].dt.date        # только дата, без времени

df[df['created_at'] > '2024-01-01']    # сравнение дат как строк тоже работает
```

Если формат даты нестандартный, нужно указать его явно:

```python
pd.to_datetime(df['created_at'], format='%d.%m.%Y')   # '15.01.2024'
```

## 🔧 apply, map, applymap

Когда готовых методов pandas не хватает — нужна своя функция, применённая к данным.

**`Series.map`** — применяет функцию или словарь к каждому значению одной колонки:

```python
df['city_code'] = df['city'].map({'London': 'LDN', 'Paris': 'PAR'})
# словарь — как замена значений по справочнику

df['age_doubled'] = df['age'].map(lambda x: x * 2)
# функция — как произвольное преобразование
```

**`Series.apply`** — то же самое, но обычно для функций сложнее одной лямбды:

```python
def categorize(age):
    if age < 30:
        return 'young'
    return 'adult'

df['category'] = df['age'].apply(categorize)
```

**`DataFrame.apply(func, axis=1)`** — применяет функцию к каждой **строке** целиком, а не к одной колонке:

```python
def full_info(row):
    return f"{row['name']} ({row['age']})"

df['info'] = df.apply(full_info, axis=1)
# 'Alice (28)', 'Bob (34)', ...
```

`axis=1` — обязателен, по умолчанию `apply` на `DataFrame` идёт по колонкам (`axis=0`), а не по строкам.

**`DataFrame.applymap`** — применяет функцию к **каждой ячейке** всего `DataFrame`, без разбора по колонкам/строкам:

```python
df[['age', 'price']].applymap(lambda x: round(x, 1))
```

> 💡 Для простых операций — сложения, сравнения, арифметики — векторные операции (`df['age'] * 2`) быстрее `apply`/`map`, потому что выполняются сразу над всем массивом, а не поэлементно через Python-цикл под капотом. `apply`/`map` нужны, когда логика нестандартная и векторно её не выразить.

## ⚡ Быстрые примеры

```python
df.isna().sum()                              # сколько пропусков в каждой колонке
df.dropna(subset=['age'])                    # удалить строки без возраста
df['age'].fillna(df['age'].median())         # заполнить медианой
df.drop_duplicates(subset=['email'])         # дубли по email
df['id'] = df['id'].astype(str)              # id как строка
df['date'] = pd.to_datetime(df['date'])      # строка → дата
df['year'] = df['date'].dt.year              # год из даты
df['category'] = df['age'].map(lambda x: 'adult' if x >= 18 else 'minor')
df['full_name'] = df.apply(lambda r: f"{r['first']} {r['last']}", axis=1)
```

## 💡 Практические замечания

- Порядок обычно такой: сначала разобраться с пропусками, потом с дублями, потом с типами
- `fillna`/`drop_duplicates`/`astype` по умолчанию не меняют исходный `DataFrame` — нужно либо `inplace=True`, либо переприсвоить результат
- `to_datetime` стоит делать сразу после загрузки — иначе каждое следующее сравнение дат будет сравнивать строки, а не реальные даты
- `map` — для одной колонки и простой замены/функции; `apply` — когда логика сложнее или нужна вся строка (`axis=1`); `applymap` — когда нужно применить ко всем ячейкам сразу
- Векторные операции предпочтительнее `apply` везде, где это возможно — `apply` в pandas медленнее, чем кажется

## ⚠️ Частые ошибки

**❌ `astype(int)` на колонке с пропусками:**
```python
df['age'].astype(int)
# ❌ ValueError: Cannot convert non-finite values (NA or inf) to integer
df['age'].fillna(0).astype(int)   # ✅ сначала убрать NaN
```

**❌ Забыть `axis=1` в `df.apply`:**
```python
df.apply(lambda row: row['a'] + row['b'])   # ❌ TypeError — по умолчанию idёт по колонкам
df.apply(lambda row: row['a'] + row['b'], axis=1)   # ✅ по строкам
```

**❌ Сравнивать даты как строки, забыв про to_datetime:**
```python
df['date'] > '2024-01-01'
# Технически может сработать для простых случаев, но ненадёжно для разных форматов/часовых поясов
df['date'] = pd.to_datetime(df['date'])   # ✅ сначала привести к дате
```

**❌ Думать, что `fillna`/`dropna` меняют df сразу:**
```python
df.dropna()           # ❌ не меняет df, возвращает новый DataFrame
df = df.dropna()       # ✅ переприсвоить
df.dropna(inplace=True)  # ✅ или inplace
```

---

## ✅ Главные правила

✅ `isna().sum()` — первый шаг, чтобы понять масштаб пропусков  
✅ `dropna`/`fillna` не меняют `df` без `inplace=True` или переприсваивания  
✅ Перед `astype(int)` убери `NaN` — целочисленный тип их не хранит  
✅ `to_datetime` — сразу после загрузки, не откладывать до сравнения дат  
✅ `map` — одна колонка, `apply(axis=1)` — вся строка, `applymap` — весь DataFrame  
✅ Векторные операции быстрее `apply` — используй `apply` только когда без него не обойтись
