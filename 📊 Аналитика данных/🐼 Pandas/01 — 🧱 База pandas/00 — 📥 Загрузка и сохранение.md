# 📥 Загрузка и сохранение данных

> `read_*` загружает данные в `DataFrame` из файла или БД, `to_*` сохраняет `DataFrame` обратно. Это первый и последний шаг почти любого анализа в pandas.

## Справка

| Функция | Источник | Возвращает |
|---|---|---|
| `pd.read_csv(path)` | CSV-файл | `DataFrame` |
| `pd.read_excel(path)` | Excel-файл | `DataFrame` |
| `pd.read_sql(query, conn)` | SQL-запрос + подключение | `DataFrame` |
| `pd.read_json(path)` | JSON-файл | `DataFrame` |

| Метод | Сохраняет в | Параметр |
|---|---|---|
| `df.to_csv(path)` | CSV-файл | `index=False` — не писать индекс |
| `df.to_excel(path)` | Excel-файл | `sheet_name='...'` |
| `df.to_sql(table, conn)` | SQL-таблицу | `if_exists='replace'/'append'/'fail'` |
| `df.to_json(path)` | JSON-файл | `orient='records'` |

## 📄 Чтение CSV

Самый частый источник данных в pandas.

```python
import pandas as pd

df = pd.read_csv('users.csv')
```

```csv
id,name,age,city
1,Alice,28,New York
2,Bob,34,London
```

```python
df
#    id   name  age      city
# 0   1  Alice   28  New York
# 1   2    Bob   34    London
```

Частые параметры:

```python
pd.read_csv('data.csv', sep=';')                 # разделитель не запятая, а ;
pd.read_csv('data.csv', encoding='cp1251')        # явная кодировка (частая проблема с русским текстом)
pd.read_csv('data.csv', usecols=['id', 'name'])   # только нужные колонки — экономит память
pd.read_csv('data.csv', nrows=1000)               # только первые 1000 строк (для теста на большом файле)
pd.read_csv('data.csv', index_col='id')           # колонка id сразу становится индексом
pd.read_csv('data.csv', parse_dates=['created_at'])  # сразу распарсить колонку как дату
```

## 📊 Чтение Excel

```python
df = pd.read_excel('report.xlsx')                     # первый лист по умолчанию
df = pd.read_excel('report.xlsx', sheet_name='Sales')  # конкретный лист по имени
df = pd.read_excel('report.xlsx', sheet_name=1)        # конкретный лист по номеру (с 0)

# Все листы сразу — вернёт словарь {имя_листа: DataFrame}
sheets = pd.read_excel('report.xlsx', sheet_name=None)
sheets['Sales']
```

> ⚠️ Для чтения `.xlsx` нужна библиотека `openpyxl` (`pip install openpyxl`). Без неё `read_excel` упадёт с ошибкой об отсутствующем движке.

## 🗄 Чтение из SQL

```python
import sqlite3
import pandas as pd

conn = sqlite3.connect('library.db')
df = pd.read_sql('SELECT * FROM Books WHERE price > 10', conn)
```

Для MySQL/PostgreSQL используется аналогичное подключение через `sqlalchemy`:

```python
from sqlalchemy import create_engine

engine = create_engine('mysql+pymysql://user:password@localhost/library')
df = pd.read_sql('SELECT * FROM Books', engine)
```

`read_sql` принимает готовый SQL-запрос — вся логика фильтрации, `JOIN`, `GROUP BY` может быть сделана на стороне БД, а pandas получает уже готовый результат. Для больших таблиц это эффективнее, чем тащить всё в pandas и фильтровать там.

## 💾 Сохранение данных

```python
df.to_csv('output.csv')             # с индексом (0,1,2... отдельной колонкой)
df.to_csv('output.csv', index=False)  # без индекса — обычно то, что нужно

df.to_excel('output.xlsx', index=False)
df.to_excel('output.xlsx', sheet_name='Result', index=False)

df.to_sql('Books', conn, if_exists='replace', index=False)
```

`if_exists` для `to_sql`:

| Значение | Поведение |
|---|---|
| `'fail'` | ошибка, если таблица уже существует (по умолчанию) |
| `'replace'` | удалить старую таблицу и создать заново |
| `'append'` | добавить строки к существующей таблице |

## 🔧 Частые параметры при чтении

Эти параметры есть практически у всех `read_*` функций:

```python
pd.read_csv('data.csv', na_values=['N/A', 'нет данных'])  # что считать пропуском, кроме пустой ячейки
pd.read_csv('data.csv', dtype={'id': str})                 # явно задать тип колонки (id не превратится в число)
pd.read_csv('data.csv', skiprows=2)                         # пропустить первые 2 строки файла
pd.read_csv('data.csv', header=None, names=['a', 'b', 'c']) # в файле нет заголовка — задать имена колонок самим
```

> 💡 `dtype={'id': str}` особенно важно для полей вроде телефонов, почтовых индексов, кодов товаров — всего, что выглядит как число, но им не является (мы разбирали эту же логику для `VARCHAR` в SQL). Без явного `dtype` pandas сам решит, что это число, и обрежет ведущие нули.

## ⚡ Быстрые примеры

```python
pd.read_csv('file.csv')                              # обычное чтение
pd.read_csv('file.csv', sep=';', encoding='cp1251')   # не-English CSV
pd.read_csv('file.csv', usecols=['id', 'name'])       # только нужные колонки
pd.read_excel('file.xlsx', sheet_name='Sheet1')       # конкретный лист
pd.read_sql('SELECT * FROM Books', conn)              # из БД
df.to_csv('out.csv', index=False)                     # сохранить без индекса
df.to_sql('Books', conn, if_exists='append', index=False)  # добавить в таблицу
```

## 💡 Практические замечания

- `read_csv` — самая частая точка входа; у неё больше 50 параметров, но на практике хватает `sep`, `encoding`, `usecols`, `dtype`, `parse_dates`
- Загружай только нужные колонки (`usecols`) и строки (`nrows` для теста) — на больших файлах это существенно экономит память и время
- `to_csv` без `index=False` добавит лишнюю колонку с номерами строк — почти всегда это не нужно
- Для SQL важно помнить то же, что и в самом SQL: `read_sql` выполняет ровно тот запрос, который ты написал, фильтрация и агрегация на стороне БД эффективнее, чем в pandas после загрузки всей таблицы
- Для больших SQL-таблиц полезен параметр `chunksize` — `read_sql` вернёт не `DataFrame`, а итератор по частям

## ⚠️ Частые ошибки

**❌ Забыть `index=False` при сохранении:**
```python
df.to_csv('out.csv')
# out.csv получит лишнюю первую колонку: ",id,name" вместо "id,name"
```

**❌ Не указать кодировку для файла с русским текстом:**
```python
pd.read_csv('data.csv')
# ❌ UnicodeDecodeError или кракозябры вместо кириллицы
pd.read_csv('data.csv', encoding='cp1251')   # ✅ частая кодировка для файлов из Excel/1C
```

**❌ Дать pandas самому угадать тип для «числового» текста:**
```python
df = pd.read_csv('users.csv')   # колонка phone: '+79001234567'
df['phone'][0]
# 79001234567   ← '+' и ведущие нули потеряны, если pandas принял это за число

df = pd.read_csv('users.csv', dtype={'phone': str})   # ✅ явно строка
```

**❌ Загружать весь файл, когда нужно только посмотреть структуру:**
```python
df = pd.read_csv('huge_file.csv')          # ❌ может не влезть в память
df = pd.read_csv('huge_file.csv', nrows=5)  # ✅ для разведки достаточно
```

## ✅ Главные правила

✅ `read_csv`/`read_excel`/`read_sql` — загрузка, `to_csv`/`to_excel`/`to_sql` — сохранение  
✅ `to_csv(..., index=False)` — почти всегда нужно, иначе появится лишняя колонка  
✅ `dtype={'col': str}` — для всего, что выглядит числом, но им не является (телефоны, коды, id с ведущими нулями)  
✅ `encoding` — первое, что проверять при ошибке чтения русского текста  
✅ `usecols`/`nrows` — экономия памяти и времени на больших файлах  
✅ `read_sql` выполняет весь SQL на стороне БД — фильтруй там, а не после загрузки в pandas
