# 🔍 Индексация и выборка

> `loc` выбирает по меткам (именам), `iloc` — по позиции (числам). Булева индексация — выбор строк по условию. Это основной инструмент, чтобы вытащить из `DataFrame` ровно те данные, которые нужны.

## Справка

| Способ | Адресация | Пример |
|---|---|---|
| `df.loc[label]` | по метке индекса | `df.loc['Alice']` |
| `df.iloc[pos]` | по числовой позиции | `df.iloc[0]` |
| `df.loc[row, col]` | метка строки + метка колонки | `df.loc['Alice', 'age']` |
| `df.iloc[row, col]` | позиция строки + позиция колонки | `df.iloc[0, 1]` |
| `df[условие]` | булева индексация | `df[df['age'] > 30]` |

| Оператор в условиях | Значение | Аналог в Python |
|---|---|---|
| `&` | И | `and` |
| `\|` | ИЛИ | `or` |
| `~` | НЕ | `not` |

> ⚠️ В pandas всегда `&`, `|`, `~` с обязательными скобками вокруг каждого условия — не `and`/`or`/`not`.

---

## 🏷 loc — выбор по меткам

`loc` обращается к данным по **значению индекса**, а не по порядковому номеру.

```python
df = pd.DataFrame({
    'name': ['Alice', 'Bob', 'Charlie'],
    'age': [28, 34, 25]
}, index=['a', 'b', 'c'])

df.loc['b']            # строка с индексом 'b' (Bob)
df.loc['a', 'name']    # 'Alice' — конкретная ячейка
df.loc['a':'b']        # срез по меткам — включает ОБЕ границы!
df.loc[:, 'age']       # вся колонка age (эквивалент df['age'])
df.loc[df['age'] > 30] # loc понимает и булево условие
```

> ⚠️ Срез `loc['a':'b']` включает **обе** границы — в отличие от обычных срезов Python, где конец исключается. Это частый источник путаницы.

Если индекс — обычные числа 0,1,2..., `loc` всё равно работает по **значению**, не по позиции:

```python
df2 = df.reset_index(drop=True)
df2 = df2.drop(0)        # удалили строку с меткой 0

df2.loc[1]      # ✅ работает — ищет строку с меткой 1
df2.loc[0]      # ❌ KeyError — метки 0 больше нет, хотя позиционно это первая строка
```

## 🔢 iloc — выбор по позиции

`iloc` работает так же, как обычная индексация списков в Python — только по числовым позициям, независимо от значений индекса.

```python
df.iloc[0]          # первая строка (всегда, вне зависимости от меток)
df.iloc[0, 1]        # первая строка, вторая колонка
df.iloc[0:2]         # срез по позиции — конец ИСКЛЮЧАЕТСЯ, как в обычном Python
df.iloc[:, 0]         # все строки, первая колонка
df.iloc[-1]           # последняя строка
```

```python
df2.iloc[0]      # ✅ всегда вернёт первую по счёту строку, даже если её метка не 0
```

## ✅ Булева индексация

Самый частый способ отфильтровать строки — по условию, похоже на `WHERE` в SQL.

```python
df[df['age'] > 30]
#       name  age
# 1      Bob   34

df[df['city'] == 'London']
```

Под капотом: `df['age'] > 30` возвращает `Series` из `True`/`False` (по одному на строку), а `df[...]` оставляет только строки, где `True`.

```python
mask = df['age'] > 30
print(mask)
# 0    False
# 1     True
# 2    False
df[mask]   # то же самое, что df[df['age'] > 30]
```

## 🔗 Несколько условий

```python
df[(df['age'] > 25) & (df['city'] == 'London')]    # И
df[(df['age'] < 26) | (df['age'] > 33)]            # ИЛИ
df[~(df['city'] == 'London')]                       # НЕ (эквивалент !=)
```

> ⚠️ Каждое условие нужно обязательно оборачивать в скобки — без них `&`/`|` попытаются применить операцию раньше, чем вычислятся сравнения, и Python выдаст ошибку приоритета операторов.

```python
df[df['age'] > 25 & df['city'] == 'London']   # ❌ TypeError
df[(df['age'] > 25) & (df['city'] == 'London')]   # ✅
```

## 🎯 isin, between, query

**`isin`** — проверка на вхождение в список (аналог SQL `IN`):

```python
df[df['city'].isin(['London', 'Paris'])]
```

**`between`** — диапазон значений (аналог SQL `BETWEEN`, включает обе границы):

```python
df[df['age'].between(25, 30)]
```

**`query`** — то же самое, но в виде строки с условием, иногда читается проще:

```python
df.query('age > 25 and city == "London"')
# эквивалент df[(df['age'] > 25) & (df['city'] == 'London')]
```

В `query` можно использовать обычные `and`/`or`/`not`, а не `&`/`|`/`~` — потому что это отдельный мини-язык выражений pandas, а не обычный Python.

---

## ⚠️ SettingWithCopyWarning

Частое и не всегда понятное предупреждение pandas. Возникает, когда непонятно, работаешь ли ты с оригинальным `DataFrame` или с его временной копией.

```python
df_london = df[df['city'] == 'London']   # результат булевой индексации — может быть "вид" (view), а не копия
df_london['age'] = 0                      # ⚠️ SettingWithCopyWarning
```

Pandas не уверен: `df_london` — это независимая копия или просто другой способ посмотреть на `df`? Если это view, изменение может неожиданно затронуть исходный `df`, а может и не затронуть — поведение не гарантировано.

**Как избежать:** явно указать, что нужна копия, если собираешься её менять:

```python
df_london = df[df['city'] == 'London'].copy()   # ✅ явная независимая копия
df_london['age'] = 0                              # предупреждения нет, безопасно
```

Или использовать `loc` для изменения сразу на исходном `DataFrame`, без промежуточной переменной:

```python
df.loc[df['city'] == 'London', 'age'] = 0   # ✅ меняет df напрямую, без двусмысленности
```

## ⚡ Быстрые примеры

```python
df.loc['a']                          # строка по метке
df.iloc[0]                           # строка по позиции
df.loc[:, 'age']                     # колонка через loc
df.iloc[0:3]                         # первые 3 строки по позиции
df[df['age'] > 30]                   # фильтр по условию
df[(df['age'] > 25) & (df['city'] == 'London')]   # два условия
df[df['city'].isin(['London', 'Paris'])]          # вхождение в список
df.query('age > 25')                 # то же через query
df.loc[df['age'] > 30, 'age'] = 99   # изменение по условию, без warning
```

## 💡 Практические замечания

- `loc` — по меткам, включает обе границы среза; `iloc` — по позициям, как обычный Python-срез (конец исключается)
- Булева индексация — основной способ фильтрации, работает как `WHERE` в SQL
- `&`/`|`/`~` с обязательными скобками вместо `and`/`or`/`not` — потому что эти операции применяются поэлементно к целым `Series`, а не к единственному булеву значению
- `.copy()` или `.loc[условие, колонка] = значение` — чтобы не словить `SettingWithCopyWarning`
- `query()` читается ближе к SQL `WHERE`, но работает медленнее `&`/`|` на маленьких таблицах — для них разница не важна

## ⚠️ Частые ошибки

**❌ Забыть скобки вокруг условий:**
```python
df[df['age'] > 25 & df['age'] < 30]     # ❌ TypeError
df[(df['age'] > 25) & (df['age'] < 30)]  # ✅
```

**❌ Использовать `and`/`or` вместо `&`/`|`:**
```python
df[df['age'] > 25 and df['city'] == 'London']  # ❌ ValueError: truth value of Series ambiguous
df[(df['age'] > 25) & (df['city'] == 'London')]  # ✅
```

**❌ Путать `loc['a':'b']` и `iloc[0:2]` по включению границ:**
```python
df.loc['a':'c']   # включает И 'a', И 'c'
df.iloc[0:2]       # НЕ включает позицию 2, вернёт только 0 и 1
```

**❌ Менять данные через промежуточную переменную без `.copy()`:**
```python
sub = df[df['age'] > 30]
sub['status'] = 'adult'   # ⚠️ SettingWithCopyWarning, не ясно, изменится ли df
```

## ✅ Главные правила

✅ `loc` — по меткам (включая обе границы среза), `iloc` — по позиции (конец среза исключается)  
✅ Булева индексация `df[условие]` — основной способ фильтрации строк  
✅ В условиях pandas — только `&`/`|`/`~` со скобками, никогда `and`/`or`/`not`  
✅ `isin` — вхождение в список, `between` — диапазон, `query` — условие строкой  
✅ Для изменения через подвыборку — `.copy()` или `df.loc[условие, col] = значение`
