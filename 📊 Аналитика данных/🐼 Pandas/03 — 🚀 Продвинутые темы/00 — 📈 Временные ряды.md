# 📈 Временные ряды

> `resample` меняет частоту временного ряда (например, из дневных данных сделать месячные), `rolling` считает статистику по скользящему окну (например, среднее за последние 7 дней). Обе темы требуют, чтобы индекс `DataFrame` был датой.

## Справка

| Метод | Что делает |
|---|---|
| `df.set_index('date')` + `pd.to_datetime` | подготовка: дата становится индексом |
| `df.resample('M').sum()` | пересчитать на новую частоту (например, по месяцам) |
| `df.rolling(7).mean()` | статистика по скользящему окну из 7 точек |
| `df.expanding().sum()` | накопительная статистика с начала ряда |
| `df.shift(1)` | сдвинуть значения на 1 период вперёд/назад |

| Код частоты | Период |
|---|---|
| `'D'` | день |
| `'W'` | неделя |
| `'M'` | месяц (конец месяца) |
| `'Q'` | квартал |
| `'Y'` | год |
| `'H'` | час |

## 📅 DatetimeIndex — дата как индекс

Почти все операции с временными рядами требуют, чтобы индекс `DataFrame` был датой (`DatetimeIndex`), а не обычным числовым индексом.

```python
df = pd.DataFrame({
    'date': ['2024-01-01', '2024-01-02', '2024-01-03'],
    'sales': [100, 120, 90]
})

df['date'] = pd.to_datetime(df['date'])   # сначала строка → дата (см. «Очистка данных»)
df = df.set_index('date')                  # потом дата становится индексом

#             sales
# date
# 2024-01-01    100
# 2024-01-02    120
# 2024-01-03     90
```

После этого доступны срезы по дате и все операции ниже:

```python
df['2024-01']          # все строки за январь 2024
df['2024-01-01':'2024-01-02']   # диапазон дат
```

## 🔄 resample — смена частоты

Меняет частоту временного ряда, агрегируя данные внутри нового периода — похоже на `groupby`, но по времени.

```python
daily = pd.DataFrame({
    'date': pd.date_range('2024-01-01', periods=10, freq='D'),
    'sales': [100, 120, 90, 110, 95, 130, 105, 115, 100, 125]
}).set_index('date')

daily.resample('W').sum()     # сумма продаж по неделям
#             sales
# date
# 2024-01-07    650
# 2024-01-14    460
```

```python
daily.resample('M').mean()    # среднее за месяц
daily.resample('D').ffill()   # заполнить пропущенные дни предыдущим значением (понижение → повышение частоты)
```

`resample` — это **понижение** частоты (день → неделя, агрегация) либо **повышение** (день → час, нужно заполнение, а не агрегация).

## 🪟 rolling — скользящее окно

Считает статистику по «окну» из N последних точек, сдвигая его на каждую строку. Классический пример — скользящее среднее, чтобы сгладить шумный график.

```python
daily['rolling_avg_3'] = daily['sales'].rolling(3).mean()
#             sales  rolling_avg_3
# date
# 2024-01-01    100            NaN
# 2024-01-02    120            NaN
# 2024-01-03     90     103.333333   ← среднее от 100,120,90
# 2024-01-04    110     106.666667   ← среднее от 120,90,110
# 2024-01-05     95      98.333333   ← среднее от 90,110,95
```

Первые `N-1` строк — `NaN`, потому что окну ещё не хватает точек позади.

```python
daily['sales'].rolling(7).sum()     # сумма за последние 7 дней (скользящая)
daily['sales'].rolling(3).max()     # максимум в окне из 3 точек
daily['sales'].rolling(3, min_periods=1).mean()   # не ждать полного окна, считать и по неполным
```

## 📊 expanding — накопительное окно

В отличие от `rolling` (окно фиксированного размера), `expanding` считает статистику **от начала ряда до текущей точки** — окно растёт с каждой строкой.

```python
daily['cumulative_sum'] = daily['sales'].expanding().sum()
# эквивалентно .cumsum(), но expanding умеет любую агрегирующую функцию
daily['running_max'] = daily['sales'].expanding().max()   # максимум с начала и до этой точки
```

---

## ⏮ shift — сдвиг во времени

Сдвигает значения на N периодов — полезно, чтобы сравнить текущее значение с предыдущим (например, день к дню или месяц к месяцу).

```python
daily['prev_day'] = daily['sales'].shift(1)       # значение предыдущего дня
daily['change'] = daily['sales'] - daily['prev_day']   # изменение день к дню

daily['sales'].shift(-1)   # сдвиг в обратную сторону — следующее значение
```

```python
daily['pct_change'] = daily['sales'].pct_change()   # то же самое, но сразу в процентах
```

## ⚡ Быстрые примеры

```python
df['date'] = pd.to_datetime(df['date'])
df = df.set_index('date')
df.resample('M').sum()                    # сумма по месяцам
df.resample('W').mean()                    # среднее по неделям
df['sales'].rolling(7).mean()              # скользящее среднее за 7 точек
df['sales'].rolling(3, min_periods=1).mean()  # не ждать полного окна
df['sales'].expanding().sum()              # накопительная сумма
df['sales'].shift(1)                        # значение предыдущего периода
df['sales'].pct_change()                    # изменение в процентах к предыдущему
```

## 💡 Практические замечания

- Почти всё в этом разделе требует `DatetimeIndex` — без `set_index` на колонке с датой `resample`/`shift` либо не сработают, либо дадут неверный результат
- `rolling(N)` — окно фиксированного размера, первые `N-1` значений — `NaN`; `min_periods=1` убирает это ограничение, считая по неполным окнам
- `resample` — это группировка по времени, под капотом похоже на `groupby`, но с пониманием календарных периодов (недели, месяцы, кварталы)
- `shift` чаще всего используют для расчёта изменения период-к-периоду; `pct_change()` — готовая обёртка для этого же в процентах
- Скользящее среднее (`rolling().mean()`) — стандартный способ сгладить шумный график перед визуализацией

## ⚠️ Частые ошибки

**❌ Применить resample/rolling без DatetimeIndex:**
```python
df.resample('M').sum()
# ❌ TypeError: Only valid with DatetimeIndex — если индекс обычный, не дата
df = df.set_index(pd.to_datetime(df['date']))   # ✅ сначала дата как индекс
```

**❌ Не учитывать NaN в начале rolling-окна:**
```python
df['sales'].rolling(7).mean()
# первые 6 значений — NaN, это нормально, но может сломать дальнейшие вычисления,
# если забыть про dropna() или min_periods=1
```

**❌ Путать rolling и expanding:**
```python
df['sales'].rolling(len(df)).mean()   # громоздкий способ получить то же, что и expanding
df['sales'].expanding().mean()         # ✅ то же самое, но прямо выражает намерение
```

**❌ Забыть, что resample с повышением частоты (день → час) требует заполнения, а не агрегации:**
```python
daily.resample('H').sum()    # ❌ почти везде NaN/0 — часовых данных исходно не было
daily.resample('H').ffill()  # ✅ заполнить предыдущим известным значением
```

---

## ✅ Главные правила

✅ `resample`/большинство операций временных рядов требуют `DatetimeIndex`  
✅ `rolling(N)` — окно фиксированного размера, первые `N-1` строк — `NaN`  
✅ `expanding()` — окно растёт от начала ряда, альтернатива `rolling(len(df))`  
✅ `shift(1)` — сравнение с предыдущим периодом, `pct_change()` — то же в процентах  
✅ Понижение частоты (день→месяц) — агрегация; повышение (день→час) — нужно заполнение (`ffill`)
