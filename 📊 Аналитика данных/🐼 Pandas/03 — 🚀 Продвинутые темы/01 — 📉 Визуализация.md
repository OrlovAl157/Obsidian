## Справка

| Способ | Когда использовать |
|---|---|
| `df.plot()` | быстро посмотреть на данные, минимум кода |
| `matplotlib.pyplot` | нужен полный контроль над видом графика |
| `seaborn` | статистические графики (распределения, корреляции), симпатичнее по умолчанию |

| `kind=` в plot | Тип графика |
|---|---|
| `'line'` | линия (по умолчанию) |
| `'bar'` / `'barh'` | столбчатая диаграмма (вертикальная/горизонтальная) |
| `'hist'` | гистограмма распределения |
| `'box'` | box-plot (квартили, выбросы) |
| `'scatter'` | точечная диаграмма |
| `'pie'` | круговая диаграмма |

## ⚡ plot — встроенная визуализация

`.plot()` есть у любого `DataFrame` и `Series` — строит график в одну строку, без импорта matplotlib напрямую (хотя под капотом использует именно его).

```python
import pandas as pd

df = pd.DataFrame({
    'month': ['Jan', 'Feb', 'Mar', 'Apr'],
    'sales': [100, 120, 90, 140]
}).set_index('month')

df.plot()                  # линейный график по умолчанию
df['sales'].plot(kind='bar')   # столбчатая диаграмма
```

Для `Series` вызов ещё короче:

```python
df['sales'].plot()
```

---

## 📊 Типы графиков

```python
df['sales'].plot(kind='line', title='Продажи по месяцам')
df['sales'].plot(kind='bar', color='steelblue')
df['age'].plot(kind='hist', bins=10)              # распределение значений
df[['sales', 'profit']].plot(kind='box')           # сравнение распределений нескольких колонок
df.plot(kind='scatter', x='age', y='salary')       # зависимость между двумя колонками
df.groupby('city')['sales'].sum().plot(kind='pie')  # доли по категориям
```

Несколько линий на одном графике — если выбрать несколько колонок:

```python
df[['sales', 'profit']].plot()   # обе колонки на одном графике, разными цветами
```

## 🎨 matplotlib напрямую

`df.plot()` — это сокращение для вызовов matplotlib. Когда нужен полный контроль (несколько графиков на одной фигуре, точная настройка осей, подписи) — matplotlib используется напрямую.

```python
import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(8, 4))
df['sales'].plot(ax=ax)                 # df.plot умеет рисовать в заданные оси
ax.set_title('Продажи по месяцам')
ax.set_xlabel('Месяц')
ax.set_ylabel('Продажи')
plt.show()
```

Несколько графиков рядом (subplots):

```python
fig, axes = plt.subplots(1, 2, figsize=(10, 4))
df['sales'].plot(ax=axes[0], title='Продажи')
df['profit'].plot(ax=axes[1], title='Прибыль')
plt.tight_layout()
plt.show()
```

## 🌊 seaborn — поверх matplotlib

`seaborn` строится на matplotlib, но даёт более симпатичный вид «из коробки» и готовые статистические графики, которые на чистом matplotlib пришлось бы собирать вручную.

```python
import seaborn as sns

sns.histplot(df['age'])                          # гистограмма
sns.boxplot(x='department', y='salary', data=df)  # box-plot по категориям
sns.scatterplot(x='age', y='salary', data=df, hue='department')  # точки, цвет по категории
sns.heatmap(df.corr(), annot=True)                # тепловая карта корреляций
```

`sns.heatmap(df.corr())` — частый первый шаг разведочного анализа: сразу видно, какие числовые колонки сильно коррелируют друг с другом.

## ⚡ Быстрые примеры

```python
df['sales'].plot()                                  # линия
df['sales'].plot(kind='bar')                          # столбцы
df['age'].plot(kind='hist', bins=20)                   # гистограмма
df.plot(kind='scatter', x='age', y='salary')           # точки
df[['sales', 'profit']].plot()                          # несколько линий на одном графике
df.groupby('city')['sales'].sum().plot(kind='bar')      # после groupby — сразу в график
sns.heatmap(df.corr(), annot=True)                       # корреляции
plt.savefig('chart.png')                                 # сохранить график в файл
```

## 💡 Практические замечания

- `.plot()` — для быстрого взгляда на данные во время анализа; для презентационных графиков обычно переходят на matplotlib/seaborn напрямую
- Результат `groupby`/`pivot_table` можно сразу рисовать через `.plot()`, без промежуточного сохранения — это частый паттерн: группировка → график в одну цепочку
- `plt.show()` нужен в обычном `.py` скрипте; в Jupyter Notebook графики показываются автоматически после `%matplotlib inline`
- Для сохранения графика — `plt.savefig('file.png')`, вызывается **до** `plt.show()` (после `show()` фигура может очиститься)
- `sns.heatmap(df.corr())` — быстрый способ увидеть, какие колонки связаны между собой, до более глубокого анализа

## ⚠️ Частые ошибки

**❌ Строить scatter без явного указания x и y:**
```python
df.plot(kind='scatter')
# ❌ TypeError: не хватает обязательных x, y
df.plot(kind='scatter', x='age', y='salary')   # ✅
```

**❌ Вызывать plt.savefig() после plt.show():**
```python
plt.show()
plt.savefig('chart.png')   # ❌ может сохраниться пустой/некорректный файл
plt.savefig('chart.png')   # ✅ сначала сохранить
plt.show()
```

**❌ Пытаться построить гистограмму по нечисловой колонке:**
```python
df['city'].plot(kind='hist')
# ❌ не имеет смысла для текстовых категорий
df['city'].value_counts().plot(kind='bar')   # ✅ для категорий — подсчёт + столбцы
```

**❌ Забыть, что `df.corr()` считает корреляцию только по числовым колонкам:**
```python
df.corr()   # текстовые колонки автоматически игнорируются, не ошибка, но может удивить
```

## ✅ Главные правила

✅ `.plot()` — быстрый график прямо из `DataFrame`/`Series`, без лишнего импорта  
✅ `kind=` — тип графика: `line`, `bar`, `hist`, `box`, `scatter`, `pie`  
✅ matplotlib напрямую — когда нужен полный контроль (subplots, подписи, несколько графиков)  
✅ seaborn — для статистических графиков «из коробки» (`heatmap`, `boxplot`, `scatterplot` с цветом по категории)  
✅ Результат `groupby`/`pivot_table` можно рисовать сразу, без промежуточных переменных  
✅ `plt.savefig()` — до `plt.show()`, не после
