# 🐼 Series и DataFrame

> `Series` — одномерный массив с индексом (одна колонка), `DataFrame` — двумерная таблица (несколько колонок). Это две базовые структуры pandas, на которых строится вся остальная библиотека.

## Справка

| Структура | Размерность | Аналог |
|---|---|---|
| `Series` | 1D (одна колонка + индекс) | список с подписями, словарь |
| `DataFrame` | 2D (таблица: строки × колонки) | таблица в Excel, SQL-таблица |

| Выражение | Что возвращает |
|---|---|
| `df['col']` | `Series` (одна колонка) |
| `df[['col']]` | `DataFrame` (одна колонка, но как таблица) |
| `df[['col1', 'col2']]` | `DataFrame` (несколько колонок) |
| `df.col` | `Series`, то же что `df['col']`, но не работает с именами-не-идентификаторами |

| Атрибут/метод | Что показывает |
|---|---|
| `df.shape` | (число строк, число колонок) |
| `df.columns` | названия колонок |
| `df.index` | индекс (подписи строк) |
| `df.dtypes` | тип данных каждой колонки |
| `df.info()` | сводка: типы, непустые значения, память |
| `df.describe()` | статистика по числовым колонкам |

---

## 📏 Series — одна колонка

`Series` — одномерный массив значений, у каждого из которых есть подпись (индекс).

```python
import pandas as pd

s = pd.Series([10, 20, 30])
print(s)
# 0    10
# 1    20
# 2    30
# dtype: int64
```

Слева — индекс (по умолчанию числа 0, 1, 2...), справа — значения. Индекс можно задать явно:

```python
s = pd.Series([10, 20, 30], index=['a', 'b', 'c'])
print(s['b'])    # → 20
```

`Series` можно создать и из словаря — ключи станут индексом:

```python
s = pd.Series({'a': 10, 'b': 20, 'c': 30})
# a    10
# b    20
# c    30
```

> 💡 Аналогия: `Series` — это как один столбец в Excel вместе с номерами строк слева. Числа, текст, даты в соседних строках принадлежат разным объектам, но столбец — один.

## 📋 DataFrame — таблица

`DataFrame` — это таблица: несколько `Series` с общим индексом, каждая колонка — отдельная `Series`.

**Из словаря списков** (самый частый способ создать вручную):

```python
data = {
    'name': ['Alice', 'Bob', 'Charlie'],
    'age': [28, 34, 25],
    'city': ['New York', 'London', 'Paris']
}
df = pd.DataFrame(data)

print(df)
#       name  age      city
# 0    Alice   28  New York
# 1      Bob   34    London
# 2  Charlie   25     Paris
```

**Из списка словарей** (каждый словарь — одна строка):

```python
data = [
    {'name': 'Alice', 'age': 28},
    {'name': 'Bob', 'age': 34}
]
df = pd.DataFrame(data)
```

**Из списка списков** (нужно явно указать колонки):

```python
data = [['Alice', 28], ['Bob', 34]]
df = pd.DataFrame(data, columns=['name', 'age'])
```

На практике таблицы чаще не создают вручную, а загружают через `read_csv`/`read_sql` — это отдельная тема в «01 — Загрузка и сохранение».

## 🔑 Индекс

Индекс — не просто номер строки, а подписи, по которым можно адресоваться к данным. По умолчанию это `RangeIndex` (0, 1, 2...), но его можно заменить:

```python
df = pd.DataFrame(data)
df = df.set_index('name')

print(df)
#          age      city
# name
# Alice     28  New York
# Bob       34    London

df.loc['Alice']    # → строка по значению индекса, а не по номеру
```

```python
df = df.reset_index()    # вернуть индекс обратно в обычную колонку, индекс снова 0,1,2...
```

Индекс не обязан быть уникальным — но если он не уникален, операции вроде `.loc['Alice']` вернут несколько строк вместо одной, что часто неожиданно.

## 🏷 Выбор колонки

```python
df['age']          # → Series: одна колонка
df[['age']]         # → DataFrame: та же колонка, но как таблица (с заголовком)
df[['age', 'city']] # → DataFrame: несколько колонок
df.age              # → то же, что df['age'], но короче
```

> ⚠️ `df.age` не работает, если имя колонки содержит пробелы, совпадает с именем метода (`df.count`) или начинается с цифры. `df['age']` работает всегда — это основной, самый надёжный способ.

Выбор строк по позиции и по условию — отдельная большая тема, разобрана в «01 — Индексация и выборка» (`loc`, `iloc`, булева индексация).

## 🧬 Типы данных (dtype)

Каждая колонка `DataFrame` имеет свой тип — как колонка в SQL-таблице.

```python
df.dtypes
# name    object
# age      int64
# city    object
```

| dtype | Что означает |
|---|---|
| `int64` | целые числа |
| `float64` | числа с плавающей точкой (в том числе если есть `NaN`) |
| `object` | обычно строки (или смешанный тип) |
| `bool` | `True`/`False` |
| `datetime64[ns]` | дата/время |
| `category` | категориальный тип — экономит память при малом числе уникальных значений |

> 💡 Если в числовой колонке есть хотя бы один пропуск (`NaN`), тип автоматически станет `float64`, даже если все остальные значения — целые. Это частый источник путаницы: `age` может оказаться `28.0`, а не `28`.

## 📐 Основные атрибуты и методы

```python
df.shape        # → (3, 3) — 3 строки, 3 колонки
df.columns      # → Index(['name', 'age', 'city'])
df.index        # → RangeIndex(start=0, stop=3, step=1)
df.size         # → 9 — всего ячеек (строки × колонки)

df.head(2)      # первые 2 строки
df.tail(2)      # последние 2 строки
df.sample(2)    # 2 случайные строки

df.info()
# RangeIndex: 3 entries, 0 to 2
# Data columns (total 3 columns):
#  #   Column  Non-Null Count  Dtype
# ---  ------  --------------  -----
#  0   name    3 non-null      object
#  1   age     3 non-null      int64
#  2   city    3 non-null      object

df.describe()
#              age
# count   3.000000
# mean   29.000000
# std     4.582576
# min    25.000000
# 50%    28.000000
# 75%    31.000000
# max    34.000000
```

`describe()` по умолчанию считает статистику только по числовым колонкам. Чтобы включить и текстовые — `df.describe(include='all')`.

## ➕ Векторные операции и выравнивание

Операции с `Series`/`DataFrame` применяются сразу ко всем элементам — без явного цикла:

```python
df['age'] * 2            # умножить весь столбец на 2, поэлементно
df['age'] > 30            # → Series из True/False
df['age_plus_1'] = df['age'] + 1   # новая колонка
```

**Выравнивание по индексу** — важная и неочевидная особенность: при операции между двумя `Series` значения сопоставляются **по индексу**, а не по позиции.

```python
a = pd.Series([1, 2, 3], index=['x', 'y', 'z'])
b = pd.Series([10, 20, 30], index=['y', 'z', 'x'])

a + b
# x    31   (a['x']=1 + b['x']=30)
# y    22   (a['y']=2 + b['y']=20)
# z    13   (a['z']=3 + b['z']=10)
```

Результат сложился не «по порядку», а по совпадающим меткам индекса — как `JOIN` по ключу в SQL, а не склейка строк одна к одной.

Если индексы не совпадают полностью, в результате появится `NaN` на несовпавших позициях:

```python
a = pd.Series([1, 2], index=['x', 'y'])
b = pd.Series([10, 20], index=['y', 'z'])

a + b
# x    NaN   (нет 'x' в b)
# y    12.0  (2 + 10)
# z    NaN   (нет 'z' в a)
```

## ⚡ Быстрые примеры

```python
pd.Series([1, 2, 3])                          # Series из списка
pd.Series({'a': 1, 'b': 2})                   # Series из словаря
pd.DataFrame({'x': [1, 2], 'y': [3, 4]})      # DataFrame из словаря
df.shape                                       # (строки, колонки)
df.columns.tolist()                            # список названий колонок
df['col'].dtype                                # тип одной колонки
df.set_index('id')                             # колонка id становится индексом
df.reset_index(drop=True)                      # сбросить индекс, старый не сохранять
df['col'].astype(int)                          # привести колонку к типу
```

## 💡 Практические замечания

- `DataFrame` — это набор `Series`, у которых общий индекс. Выбрав одну колонку (`df['col']`), ты получаешь обратно `Series`
- `df['col']` всегда надёжнее `df.col` — работает с любыми именами колонок
- Пустое значение в pandas — это `NaN` (не `None` и не SQL `NULL`, хотя по смыслу то же самое); из-за него числовая колонка может незаметно превратиться в `float64`
- Индекс — не просто номер строки, а инструмент адресации; `set_index`/`reset_index` переключают между «индекс как колонка» и «индекс как метаданные»
- `df.copy()` создаёт независимую копию — без него изменения в одном `DataFrame` иногда затрагивают другой (подробнее — в «01 — Индексация и выборка», тема `SettingWithCopyWarning`)

## ⚠️ Частые ошибки

**❌ Ждать целые числа там, где есть пропуски:**
```python
df = pd.DataFrame({'age': [25, 30, None]})
df.dtypes
# age    float64   ← не int64, хотя значения похожи на целые
```

**❌ Путать `df['col']` и `df[['col']]`:**
```python
type(df['col'])     # → Series
type(df[['col']])   # → DataFrame
# Второе нужно, когда дальше ожидается именно таблица, например для merge
```

**❌ Складывать Series, не проверив индексы:**
```python
a = pd.Series([1, 2], index=[0, 1])
b = pd.Series([10, 20], index=[1, 2])
a + b
# 0     NaN   ← неожиданно, если забыл про выравнивание по индексу
# 1    12.0
# 2     NaN
```

**❌ Обращаться к колонке через точку, если в имени пробел:**
```python
df['first name']   # ✅ работает
df.first name       # ❌ SyntaxError
```

## ✅ Главные правила

✅ `Series` — одна колонка с индексом, `DataFrame` — таблица из нескольких `Series`  
✅ `df['col']` — надёжный способ выбрать колонку, работает всегда  
✅ Операции между `Series` выравниваются по индексу, а не по позиции  
✅ Пропуск (`NaN`) в числовой колонке переводит её в `float64`  
✅ `set_index`/`reset_index` — переключение между индексом-данными и индексом-метаданными  
✅ `df.info()` — быстрый обзор типов и пропусков, `df.describe()` — статистика
