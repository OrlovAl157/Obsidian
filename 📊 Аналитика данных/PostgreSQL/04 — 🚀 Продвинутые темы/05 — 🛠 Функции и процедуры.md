# 🛠 Функции и процедуры — памятка

> В PostgreSQL функции (`FUNCTION`) возвращают значение, процедуры (`PROCEDURE`) — нет. Язык `PL/pgSQL` — основной язык для процедурного кода. Нет `DELIMITER` — используют `$$`.

## Справка

| Синтаксис | Что делает |
|---|---|
| `CREATE FUNCTION f() RETURNS type` | создать функцию |
| `CREATE OR REPLACE FUNCTION` | создать или заменить |
| `CREATE PROCEDURE p()` | создать процедуру |
| `CALL p()` | вызвать процедуру |
| `SELECT f()` | вызвать функцию |
| `RETURNS TABLE(...)` | функция возвращает таблицу |
| `$$ ... $$ LANGUAGE plpgsql` | тело функции |
| `DROP FUNCTION f()` | удалить функцию |

## 🟢 Функции

```sql
-- Простая функция
CREATE OR REPLACE FUNCTION add_numbers(a INTEGER, b INTEGER)
RETURNS INTEGER AS $$
BEGIN
    RETURN a + b;
END;
$$ LANGUAGE plpgsql;

SELECT add_numbers(3, 5);   -- 8

-- Функция с SQL (без блока BEGIN...END)
CREATE OR REPLACE FUNCTION book_count(author_name TEXT)
RETURNS INTEGER AS $$
    SELECT COUNT(*) FROM Books WHERE author = author_name;
$$ LANGUAGE sql;

-- Функция возвращает TABLE
CREATE OR REPLACE FUNCTION get_expensive_books(min_price NUMERIC)
RETURNS TABLE(id INTEGER, title TEXT, price NUMERIC) AS $$
BEGIN
    RETURN QUERY
        SELECT b.id, b.title, b.price
        FROM Books b
        WHERE b.price > min_price;
END;
$$ LANGUAGE plpgsql;

SELECT * FROM get_expensive_books(15);
```

## 🔵 Процедуры

```sql
-- Процедура (без RETURNS, вызывается через CALL)
CREATE OR REPLACE PROCEDURE archive_old_books(cutoff_date DATE)
LANGUAGE plpgsql AS $$
BEGIN
    INSERT INTO BooksArchive
    SELECT * FROM Books WHERE created_at < cutoff_date;

    DELETE FROM Books WHERE created_at < cutoff_date;

    COMMIT;  -- процедуры могут управлять транзакциями!
END;
$$;

CALL archive_old_books('2020-01-01');
```

**Разница функции и процедуры:**
- Функция: `RETURNS type`, вызов `SELECT f()`
- Процедура: без `RETURNS`, вызов `CALL p()`, может делать `COMMIT`/`ROLLBACK`

## 🔴 Управление потоком

```sql
CREATE OR REPLACE FUNCTION classify_price(price NUMERIC)
RETURNS TEXT AS $$
BEGIN
    -- IF / ELSIF / ELSE
    IF price < 5 THEN
        RETURN 'дёшево';
    ELSIF price < 15 THEN
        RETURN 'средне';
    ELSE
        RETURN 'дорого';
    END IF;
END;
$$ LANGUAGE plpgsql;

-- CASE
CREATE OR REPLACE FUNCTION day_name(day_num INTEGER)
RETURNS TEXT AS $$
BEGIN
    RETURN CASE day_num
        WHEN 1 THEN 'Понедельник'
        WHEN 2 THEN 'Вторник'
        ELSE 'Другой день'
    END;
END;
$$ LANGUAGE plpgsql;

-- LOOP
CREATE OR REPLACE FUNCTION sum_to_n(n INTEGER)
RETURNS INTEGER AS $$
DECLARE
    total INTEGER := 0;
    i     INTEGER := 1;
BEGIN
    WHILE i <= n LOOP
        total := total + i;
        i := i + 1;
    END LOOP;
    RETURN total;
END;
$$ LANGUAGE plpgsql;
```

## ✅ Главные правила

✅ `$$` вместо `DELIMITER //` из MySQL  
✅ `LANGUAGE plpgsql` — процедурный язык, `LANGUAGE sql` — чистый SQL  
✅ `CREATE OR REPLACE` — обновить без DROP  
✅ `DECLARE` — блок объявления переменных  
✅ Процедуры (`PROCEDURE`) могут управлять транзакциями, функции — нет  
✅ `RETURNS TABLE` — для функций, возвращающих набор строк
