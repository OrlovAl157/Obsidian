# 🪟 Оконные функции — памятка

> Оконные функции вычисляют значение для каждой строки на основе набора связанных строк (окна), не сворачивая результат как GROUP BY. Синтаксис одинаков в PostgreSQL и стандартном SQL.

## Справка

| Функция | Что делает |
|---|---|
| `ROW_NUMBER()` | порядковый номер строки |
| `RANK()` | ранг с пропусками при одинаковых |
| `DENSE_RANK()` | ранг без пропусков |
| `NTILE(n)` | разбить на n групп |
| `LAG(col, n)` | значение на n строк назад |
| `LEAD(col, n)` | значение на n строк вперёд |
| `FIRST_VALUE(col)` | первое значение в окне |
| `LAST_VALUE(col)` | последнее значение в окне |
| `SUM() OVER (...)` | накопительная сумма |
| `AVG() OVER (...)` | скользящее среднее |

## 🟢 Базовый синтаксис

```sql
-- Структура: функция OVER (PARTITION BY ... ORDER BY ...)
SELECT
    title,
    price,
    ROW_NUMBER() OVER (ORDER BY price DESC) AS rank,
    AVG(price) OVER () AS avg_price   -- без секции = все строки
FROM Books;

-- PARTITION BY — разбить на группы (как GROUP BY, но без сворачивания)
SELECT
    author,
    title,
    price,
    ROW_NUMBER() OVER (PARTITION BY author ORDER BY price DESC) AS rank_in_author
FROM Books;
```

## 🔵 Ранжирование

```sql
SELECT author, title, price,
    ROW_NUMBER() OVER (PARTITION BY author ORDER BY price DESC) AS row_num,
    RANK()       OVER (PARTITION BY author ORDER BY price DESC) AS rank,
    DENSE_RANK() OVER (PARTITION BY author ORDER BY price DESC) AS dense_rank
FROM Books;

-- ROW_NUMBER: 1, 2, 3, 4  (уникальный)
-- RANK:       1, 1, 3, 4  (пропуск после одинаковых)
-- DENSE_RANK: 1, 1, 2, 3  (без пропусков)

-- Топ-1 книга каждого автора (через CTE)
WITH ranked AS (
    SELECT *, ROW_NUMBER() OVER (PARTITION BY author ORDER BY price DESC) AS rn
    FROM Books
)
SELECT * FROM ranked WHERE rn = 1;
```

## 🔴 Агрегация по окну

```sql
-- Накопительная сумма по дате
SELECT
    order_date,
    amount,
    SUM(amount) OVER (ORDER BY order_date) AS running_total
FROM Orders;

-- Скользящее среднее за 7 дней
SELECT
    date,
    sales,
    AVG(sales) OVER (ORDER BY date ROWS BETWEEN 6 PRECEDING AND CURRENT ROW) AS avg_7d
FROM DailySales;

-- LAG/LEAD — предыдущее/следующее значение
SELECT
    date,
    sales,
    LAG(sales, 1) OVER (ORDER BY date) AS prev_day,
    sales - LAG(sales, 1) OVER (ORDER BY date) AS diff
FROM DailySales;
```

## 🟡 ROWS и RANGE

```sql
-- ROWS BETWEEN — по физическим строкам
AVG(price) OVER (ORDER BY date ROWS BETWEEN 2 PRECEDING AND CURRENT ROW)
-- берёт текущую + 2 предыдущие строки

-- RANGE BETWEEN — по значениям
SUM(sales) OVER (ORDER BY date RANGE BETWEEN INTERVAL '7 days' PRECEDING AND CURRENT ROW)
-- берёт все строки за последние 7 дней
```

## ✅ Главные правила

✅ Оконные функции не сворачивают строки — каждая строка остаётся в результате  
✅ `PARTITION BY` — разбивка на группы (без сворачивания)  
✅ `ORDER BY` внутри `OVER` — порядок внутри окна  
✅ `ROW_NUMBER` → уникальный, `RANK` → с пропусками, `DENSE_RANK` → без пропусков  
✅ `LAG`/`LEAD` — доступ к соседним строкам без самосоединения
