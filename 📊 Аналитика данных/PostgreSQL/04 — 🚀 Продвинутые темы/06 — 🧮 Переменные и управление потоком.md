# 🧮 Переменные и управление потоком — памятка

> В PostgreSQL переменные объявляются в блоке `DECLARE` внутри `BEGIN...END`. Управление потоком: `IF/ELSIF/ELSE`, `CASE`, `LOOP`, `WHILE`, `FOR`. Используется внутри функций, процедур и блоков `DO`.

## Справка

| Синтаксис | Что делает |
|---|---|
| `DECLARE var TYPE := val` | объявить переменную |
| `var := expression` | присвоить значение |
| `SELECT col INTO var FROM ...` | значение из запроса |
| `IF ... THEN ... ELSIF ... ELSE ... END IF` | ветвление |
| `CASE ... WHEN ... THEN ... END CASE` | выбор |
| `LOOP ... EXIT WHEN ... END LOOP` | бесконечный цикл |
| `WHILE ... LOOP ... END LOOP` | цикл с условием |
| `FOR i IN 1..10 LOOP ... END LOOP` | цикл по диапазону |
| `FOR row IN SELECT ... LOOP ... END LOOP` | цикл по результату |
| `DO $$ ... $$ LANGUAGE plpgsql` | анонимный блок |

## 🟢 Переменные

```sql
-- В функции/процедуре
DECLARE
    total      INTEGER := 0;
    book_title TEXT;
    avg_price  NUMERIC(10,2);
BEGIN
    -- Присвоение
    total := 42;
    book_title := 'It';

    -- Значение из запроса
    SELECT AVG(price) INTO avg_price FROM Books;
    SELECT title INTO book_title FROM Books WHERE id = 1;
END;
```

## 🔵 IF / ELSIF / ELSE

```sql
IF price < 5 THEN
    category := 'дёшево';
ELSIF price < 15 THEN
    category := 'средне';
ELSIF price < 30 THEN
    category := 'дорого';
ELSE
    category := 'очень дорого';
END IF;
```

## 🔴 CASE

```sql
-- Простой CASE
result := CASE status
    WHEN 'new'      THEN 'Новый'
    WHEN 'active'   THEN 'Активный'
    WHEN 'archived' THEN 'Архив'
    ELSE 'Неизвестно'
END;

-- Поисковый CASE (как IF-ELSIF)
result := CASE
    WHEN price < 5  THEN 'дёшево'
    WHEN price < 15 THEN 'средне'
    ELSE 'дорого'
END;
```

## 🟡 Циклы

```sql
-- WHILE
i := 1;
WHILE i <= 10 LOOP
    total := total + i;
    i := i + 1;
END LOOP;

-- FOR по диапазону
FOR i IN 1..10 LOOP
    total := total + i;
END LOOP;

-- FOR по результату запроса
FOR rec IN SELECT id, title FROM Books WHERE price > 10 LOOP
    RAISE NOTICE 'Книга: %', rec.title;
END LOOP;

-- LOOP с EXIT
LOOP
    i := i + 1;
    EXIT WHEN i > 10;
END LOOP;
```

## 🟣 DO — анонимный блок

Выполнить PL/pgSQL-код без создания функции:

```sql
DO $$
DECLARE
    cnt INTEGER;
BEGIN
    SELECT COUNT(*) INTO cnt FROM Books;
    RAISE NOTICE 'Количество книг: %', cnt;
END;
$$ LANGUAGE plpgsql;
```

---

## ✅ Главные правила

✅ `DECLARE` — блок до `BEGIN` для объявления переменных  
✅ `:=` — оператор присвоения (не `=`)  
✅ `SELECT ... INTO var` — получить значение из запроса  
✅ `RAISE NOTICE '...'` — вывод для отладки (аналог print)  
✅ `DO $$...$$` — выполнить блок без создания функции
