# 🔗 Реляционные базы данных — памятка

> Реляционная модель организует данные в таблицы (отношения) со строгой схемой. Связи между таблицами строятся через первичные и внешние ключи. PostgreSQL — объектно-реляционная СУБД.

## Основные понятия

| Понятие | Описание |
|---|---|
| **Отношение (таблица)** | набор строк с одинаковой структурой |
| **Атрибут (столбец)** | поле таблицы с определённым типом |
| **Кортеж (строка)** | одна запись |
| **Первичный ключ** | уникальный идентификатор строки |
| **Внешний ключ** | ссылка на первичный ключ другой таблицы |
| **Кардинальность** | тип связи (1:1, 1:N, M:N) |

## Типы связей

```
1:1 — один к одному
Users ──── UserProfile

1:N — один ко многим (самая частая)
Authors ──<< Books

M:N — многие ко многим (через промежуточную таблицу)
Books >>──<< Tags
      BookTags
```

## Целостность данных

- **Доменная** — значения соответствуют типу данных
- **Сущностная** — первичный ключ уникален и не NULL
- **Ссылочная** — внешний ключ ссылается на существующую запись (FOREIGN KEY)
