# 🔗 JOIN шпаргалка

> Быстрая шпаргалка по всем видам JOIN с визуальными диаграммами.

```
A ∩ B          A            B            A ∪ B
INNER JOIN   LEFT JOIN   RIGHT JOIN    FULL JOIN
   ╔══╗       ╔══╗           ╔══╗       ╔════╗
  ╔╬██╬╗     ╔╬██╬╗         ╔╬██╬╗     ╔╬████╬╗
  ║██║ ║     ║████║         ║ ████║     ║██████║
  ╚╬██╬╝     ╚╬██╬╝         ╚╬██╬╝     ╚╬████╬╝
   ╚══╝       ╚══╝           ╚══╝       ╚════╝
```

## Примеры

```sql
-- INNER JOIN: только совпадения
SELECT b.title, a.name FROM Books b JOIN Authors a ON b.author_id = a.id;

-- LEFT JOIN: все книги, даже без автора
SELECT b.title, a.name FROM Books b LEFT JOIN Authors a ON b.author_id = a.id;

-- LEFT JOIN — только без пары (книги без автора)
SELECT b.title FROM Books b LEFT JOIN Authors a ON b.author_id = a.id WHERE a.id IS NULL;

-- RIGHT JOIN: все авторы, даже без книг
SELECT b.title, a.name FROM Books b RIGHT JOIN Authors a ON b.author_id = a.id;

-- FULL JOIN: все из обеих таблиц
SELECT b.title, a.name FROM Books b FULL JOIN Authors a ON b.author_id = a.id;

-- CROSS JOIN: каждая строка с каждой
SELECT a.name, b.title FROM Authors a CROSS JOIN Books b;
```

## Шпаргалка

| Тип | Что возвращает | Книги без автора | Авторы без книг |
|---|---|---|---|
| INNER JOIN | только совпадения | ❌ | ❌ |
| LEFT JOIN | все левые | ✅ | ❌ |
| RIGHT JOIN | все правые | ❌ | ✅ |
| FULL JOIN | все из обеих | ✅ | ✅ |
