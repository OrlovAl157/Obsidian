## Справка

| Оператор | Описание |
|---|---|
| `=`, `!=`, `<>` | равно, не равно |
| `<`, `>`, `<=`, `>=` | сравнение |
| `BETWEEN a AND b` | в диапазоне |
| `IN (...)` | в списке |
| `NOT IN (...)` | не в списке |
| `LIKE` | поиск по шаблону (регистрозависимо) |
| `ILIKE` | поиск по шаблону (регистронезависимо, PostgreSQL!) |
| `IS NULL` | равно NULL |
| `IS NOT NULL` | не равно NULL |
| `IS DISTINCT FROM` | не равно (с учётом NULL) |
| `AND`, `OR`, `NOT` | логические операторы |
| `EXISTS` | существует ли строка |

---

## 🟢 Операторы сравнения

```sql
SELECT * FROM Books WHERE price = 9.99;
SELECT * FROM Books WHERE price != 9.99;
SELECT * FROM Books WHERE price BETWEEN 5 AND 15;
SELECT * FROM Books WHERE author IN ('King', 'Orwell');
SELECT * FROM Books WHERE price > 10 AND author = 'King';
```

---

## 🔵 Специальные условия

```sql
-- LIKE / ILIKE
SELECT * FROM Books WHERE title LIKE '%Ring%';     -- регистрозависимо
SELECT * FROM Books WHERE title ILIKE '%ring%';    -- регистронезависимо (PostgreSQL!)

-- NULL
SELECT * FROM Books WHERE description IS NULL;
SELECT * FROM Books WHERE description IS NOT NULL;

-- IS DISTINCT FROM — безопасное сравнение с NULL
SELECT * FROM Books WHERE price IS DISTINCT FROM NULL;
-- WHERE price != NULL не работает! Используй IS NOT NULL или IS DISTINCT FROM

-- EXISTS
SELECT * FROM Authors a
WHERE EXISTS (SELECT 1 FROM Books b WHERE b.author_id = a.id);
```

---

## ✅ Главные правила

✅ `ILIKE` — регистронезависимый поиск без `LOWER()` (только PostgreSQL)  
✅ `NULL != NULL` — сравнение с NULL всегда даёт NULL, используй `IS NULL`  
✅ `IS DISTINCT FROM` — безопасное `!=` даже для NULL
