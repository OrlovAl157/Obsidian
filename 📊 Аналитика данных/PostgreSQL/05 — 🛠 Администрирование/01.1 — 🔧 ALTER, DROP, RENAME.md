# 🔧 ALTER, DROP, RENAME — памятка

> `ALTER TABLE` изменяет структуру таблицы. В PostgreSQL синтаксис похож на MySQL, но есть отличия: `RENAME TO` на уровне таблицы, `SET DATA TYPE` для изменения типа.

## Справка

| Синтаксис | Что делает |
|---|---|
| `DROP TABLE t` | удалить таблицу |
| `DROP TABLE IF EXISTS t` | удалить если существует |
| `DROP TABLE t CASCADE` | каскадно удалить зависимые объекты |
| `ALTER TABLE t RENAME TO new_t` | переименовать таблицу |
| `ALTER TABLE t ADD COLUMN col type` | добавить столбец |
| `ALTER TABLE t DROP COLUMN col` | удалить столбец |
| `ALTER TABLE t RENAME COLUMN old TO new` | переименовать столбец |
| `ALTER TABLE t ALTER COLUMN col TYPE type` | изменить тип |
| `ALTER TABLE t ALTER COLUMN col SET DEFAULT val` | установить дефолт |
| `ALTER TABLE t ALTER COLUMN col DROP DEFAULT` | убрать дефолт |
| `ALTER TABLE t ALTER COLUMN col SET NOT NULL` | добавить NOT NULL |
| `\d tablename` | структура таблицы (psql) |

---

## 🔴 DROP

```sql
-- Удалить таблицу
DROP TABLE Books;
DROP TABLE IF EXISTS Books;

-- CASCADE — удалить все зависимые объекты (вью, FK)
DROP TABLE Authors CASCADE;

-- Удалить несколько
DROP TABLE IF EXISTS Books, Authors, Genres;
```

---

## 🟡 RENAME

```sql
-- Переименовать таблицу
ALTER TABLE Books RENAME TO Library;

-- Переименовать столбец
ALTER TABLE Books RENAME COLUMN author TO author_name;
```

## 🟡 ALTER TABLE — поля

```sql
-- Добавить столбец
ALTER TABLE Books ADD COLUMN rating NUMERIC(3,1);
ALTER TABLE Books ADD COLUMN created_at TIMESTAMP DEFAULT NOW();

-- Удалить столбец
ALTER TABLE Books DROP COLUMN rating;
ALTER TABLE Books DROP COLUMN IF EXISTS rating;

-- Изменить тип (PostgreSQL: SET DATA TYPE или просто TYPE)
ALTER TABLE Books ALTER COLUMN price TYPE NUMERIC(12,2);
ALTER TABLE Books ALTER COLUMN price SET DATA TYPE NUMERIC(12,2);

-- DEFAULT
ALTER TABLE Books ALTER COLUMN status SET DEFAULT 'active';
ALTER TABLE Books ALTER COLUMN status DROP DEFAULT;

-- NOT NULL
ALTER TABLE Books ALTER COLUMN title SET NOT NULL;
ALTER TABLE Books ALTER COLUMN title DROP NOT NULL;

-- Несколько изменений за раз
ALTER TABLE Books
    ADD COLUMN tags TEXT[],
    ALTER COLUMN price TYPE NUMERIC(12,2),
    DROP COLUMN old_field;
```

## 🔑 Ключи и ограничения

```sql
-- Добавить PRIMARY KEY
ALTER TABLE Books ADD PRIMARY KEY (id);

-- Добавить FOREIGN KEY
ALTER TABLE Books ADD FOREIGN KEY (author_id) REFERENCES Authors(id);

-- Добавить именованное ограничение
ALTER TABLE Books ADD CONSTRAINT price_positive CHECK (price > 0);

-- Удалить ограничение
ALTER TABLE Books DROP CONSTRAINT price_positive;
ALTER TABLE Books DROP CONSTRAINT IF EXISTS price_positive;

-- Добавить UNIQUE
ALTER TABLE Books ADD CONSTRAINT unique_title UNIQUE (title);
```

---

## ✅ Главные правила

✅ `DROP TABLE CASCADE` — удаляет зависимые объекты (VIEW, FK) — осторожно!  
✅ `ALTER COLUMN TYPE` — изменение типа может завершиться ошибкой, если данные несовместимы  
✅ `IF EXISTS` — защита от ошибок при повторных запусках  
✅ Нет `MODIFY COLUMN` (MySQL) → `ALTER COLUMN ... TYPE` в PostgreSQL
