# 🏗 CREATE TABLE — памятка

> `CREATE TABLE` создаёт таблицу. В PostgreSQL вместо `AUTO_INCREMENT` используется `SERIAL`/`BIGSERIAL` или `GENERATED AS IDENTITY`. Нет `ENGINE`, `DELIMITER` — PostgreSQL проще в синтаксисе.

## Справка

| Оператор | Что делает |
|---|---|
| `CREATE TABLE t (...)` | создать таблицу |
| `CREATE TABLE IF NOT EXISTS t` | создать если не существует |
| `SERIAL` | автоинкремент (4 байта) |
| `BIGSERIAL` | автоинкремент (8 байт) |
| `GENERATED ALWAYS AS IDENTITY` | современный автоинкремент |
| `NOT NULL` | запрет NULL |
| `UNIQUE` | уникальность значений |
| `DEFAULT value` | значение по умолчанию |
| `CHECK (expr)` | проверка условия |
| `REFERENCES t(col)` | внешний ключ |
| `\d tablename` | структура таблицы (psql) |

## 🟢 Создание таблицы

```sql
CREATE TABLE Books (
    id      SERIAL PRIMARY KEY,
    title   VARCHAR(200) NOT NULL,
    author  VARCHAR(100),
    price   NUMERIC(10, 2) DEFAULT 0,
    created TIMESTAMP DEFAULT NOW()
);

-- IF NOT EXISTS — без ошибки если уже существует
CREATE TABLE IF NOT EXISTS Books (
    id SERIAL PRIMARY KEY,
    title VARCHAR(200) NOT NULL
);
```

## 🔑 PRIMARY KEY и SERIAL

В PostgreSQL нет `AUTO_INCREMENT` — вместо него три варианта:

```sql
-- 1. SERIAL — классический (4 байта, до ~2 млрд)
id SERIAL PRIMARY KEY

-- 2. BIGSERIAL — для больших таблиц (8 байт)
id BIGSERIAL PRIMARY KEY

-- 3. GENERATED AS IDENTITY — современный стандартный SQL (рекомендуется)
id INTEGER GENERATED ALWAYS AS IDENTITY PRIMARY KEY
id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY
-- ALWAYS — нельзя вставить id вручную
-- BY DEFAULT — можно вставить вручную если нужно
```

**Составной первичный ключ:**

```sql
CREATE TABLE BookAuthors (
    book_id   INTEGER,
    author_id INTEGER,
    PRIMARY KEY (book_id, author_id)
);
```

## 📌 DEFAULT и CHECK

```sql
CREATE TABLE Books (
    id          SERIAL PRIMARY KEY,
    title       VARCHAR(200) NOT NULL,
    price       NUMERIC(10,2) DEFAULT 0 CHECK (price >= 0),
    status      VARCHAR(20) DEFAULT 'active' CHECK (status IN ('active', 'archived')),
    created_at  TIMESTAMP DEFAULT NOW(),
    updated_at  TIMESTAMP DEFAULT NOW()
);

-- Именованное ограничение
CREATE TABLE Books (
    id    SERIAL PRIMARY KEY,
    price NUMERIC(10,2),
    CONSTRAINT price_positive CHECK (price > 0)
);
```

## 🔗 FOREIGN KEY

```sql
CREATE TABLE Authors (
    id      SERIAL PRIMARY KEY,
    name    VARCHAR(100) NOT NULL
);

CREATE TABLE Books (
    id        SERIAL PRIMARY KEY,
    title     VARCHAR(200) NOT NULL,
    author_id INTEGER REFERENCES Authors(id)
        ON UPDATE CASCADE
        ON DELETE SET NULL
);

-- Полный синтаксис
CREATE TABLE Books (
    id        SERIAL PRIMARY KEY,
    title     VARCHAR(200) NOT NULL,
    author_id INTEGER,
    FOREIGN KEY (author_id) REFERENCES Authors(id)
        ON UPDATE CASCADE
        ON DELETE RESTRICT
);
```

**PRIMARY KEY и FOREIGN KEY — роли поля:**

```
Authors                        Books
┌────┬──────────┐              ┌────┬────────┬───────────┐
│ id │ name     │              │ id │ title  │ author_id │
│(PK)│          │              │(PK)│        │   (FK)    │
├────┼──────────┤              ├────┼────────┼───────────┤
│ 1  │ King     │◄─────────────│ 1  │ It     │ 1         │
└────┴──────────┘              └────┴────────┴───────────┘
```

## ⚡ Быстрые примеры

```sql
-- Минимальная таблица
CREATE TABLE Users (
    id    SERIAL PRIMARY KEY,
    email VARCHAR(255) UNIQUE NOT NULL
);

-- Полная таблица с современным синтаксисом
CREATE TABLE Orders (
    id          INTEGER GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    user_id     INTEGER NOT NULL REFERENCES Users(id) ON DELETE CASCADE,
    total       NUMERIC(10,2) NOT NULL CHECK (total > 0),
    status      VARCHAR(20) DEFAULT 'new',
    created_at  TIMESTAMP DEFAULT NOW()
);
```

## ⚠️ Частые ошибки

```sql
-- ❌ AUTO_INCREMENT — MySQL, не PostgreSQL
id INT AUTO_INCREMENT PRIMARY KEY   -- ❌
id SERIAL PRIMARY KEY               -- ✅

-- ❌ ENGINE=InnoDB — только MySQL
CREATE TABLE Books (...) ENGINE=InnoDB;   -- ❌ PostgreSQL не знает ENGINE

-- ❌ GENERATED ALWAYS — нельзя вставить id вручную
INSERT INTO Books (id, title) VALUES (1, 'Test');   -- ❌ ошибка
-- Используй GENERATED BY DEFAULT если нужно вставлять вручную
```

## ✅ Главные правила

✅ `SERIAL` / `BIGSERIAL` — автоинкремент в PostgreSQL (нет AUTO_INCREMENT)  
✅ `GENERATED ALWAYS AS IDENTITY` — современный стандарт SQL, предпочтительнее SERIAL  
✅ `IF NOT EXISTS` — защита от ошибок при повторном запуске  
✅ `NUMERIC(n,d)` — для денег и точных чисел (не FLOAT!)  
✅ Нет `ENGINE`, нет `DELIMITER` — PostgreSQL проще в синтаксисе  
✅ Именуй `CHECK`-ограничения через `CONSTRAINT` — легче удалять
