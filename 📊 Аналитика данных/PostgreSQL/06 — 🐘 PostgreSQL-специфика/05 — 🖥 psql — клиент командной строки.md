# 🖥 psql — клиент командной строки

> `psql` — стандартный интерактивный клиент PostgreSQL. Все команды psql начинаются с `\` (бэкслэш) — это не SQL, а мета-команды клиента. Аналог MySQL Workbench / mysql CLI.

## Справка

| Команда | Что делает |
|---|---|
| `\l` | список баз данных |
| `\c dbname` | подключиться к базе |
| `\dt` | список таблиц |
| `\dt schema.*` | таблицы конкретной схемы |
| `\d tablename` | структура таблицы |
| `\d+ tablename` | расширенная информация |
| `\dn` | список схем |
| `\df` | список функций |
| `\dv` | список представлений |
| `\di` | список индексов |
| `\du` | список ролей/пользователей |
| `\timing` | включить замер времени |
| `\x` | расширенный вывод (построчный) |
| `\i file.sql` | выполнить SQL из файла |
| `\o file.txt` | вывод в файл |
| `\copy` | импорт/экспорт данных |
| `\q` | выйти |
| `\?` | справка по командам psql |
| `\h SELECT` | справка по SQL-команде |

## 🟢 Подключение

```bash
# Базовое подключение
psql -U username -d dbname

# С хостом и портом
psql -h localhost -p 5432 -U postgres -d mydb

# Строкой подключения
psql "postgresql://username:password@localhost:5432/mydb"

# Переменная окружения
export DATABASE_URL="postgresql://user:pass@localhost/mydb"
psql $DATABASE_URL
```

## 🔵 Навигация по базе

```
\l                    -- все базы данных
\c mydb               -- переключиться на базу mydb
\dt                   -- таблицы в текущей схеме (public)
\dt *.*               -- таблицы во всех схемах
\d Books              -- структура таблицы Books
\d+ Books             -- + размер, индексы, комментарии
\dn                   -- список схем
\df                   -- список функций
\dv                   -- список представлений (VIEW)
\di                   -- список индексов
```

## 🔴 Полезные режимы

```
\timing               -- включить/выключить замер времени запроса
\x                    -- extended mode (каждое поле на новой строке)
\x auto               -- автоматически при широких таблицах

-- Пример с \x:
\x
SELECT * FROM Books WHERE id = 1;
-- Вместо таблицы — построчный вывод:
-- id    | 1
-- title | It
-- price | 7.99
```

```bash
# Выполнить SQL не входя в psql
psql -U postgres -d mydb -c "SELECT COUNT(*) FROM Books;"

# Выполнить файл
psql -U postgres -d mydb -f script.sql
```

---

## ✅ Главные правила

✅ `\d tablename` — аналог `DESCRIBE` в MySQL  
✅ `\l` — аналог `SHOW DATABASES`  
✅ `\dt` — аналог `SHOW TABLES`  
✅ `\x` — удобен для таблиц с большим числом столбцов  
✅ `\timing` — всегда включай при оптимизации запросов
