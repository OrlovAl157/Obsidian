## Справка

| Функция | Описание |
|---|---|
| `ABS(n)` | модуль |
| `CEIL(n)` | округлить вверх |
| `FLOOR(n)` | округлить вниз |
| `ROUND(n, d)` | округлить до d знаков |
| `TRUNC(n, d)` | усечь до d знаков (не округлять) |
| `MOD(n, m)` | остаток от деления |
| `POWER(n, p)` | возведение в степень |
| `SQRT(n)` | квадратный корень |
| `RANDOM()` | случайное 0..1 |
| `GREATEST(a,b,...)` | максимум из списка |
| `LEAST(a,b,...)` | минимум из списка |

---

## 🟢 Основные функции

```sql
SELECT ABS(-42);           -- 42
SELECT SQRT(16);           -- 4
SELECT POWER(2, 10);       -- 1024
SELECT MOD(10, 3);         -- 1
SELECT GREATEST(3, 7, 1);  -- 7
SELECT LEAST(3, 7, 1);     -- 1
SELECT RANDOM();           -- 0.348...

-- Случайное целое от 1 до 100
SELECT FLOOR(RANDOM() * 100 + 1)::INTEGER;
```

---

## 🔵 Округление

```sql
SELECT ROUND(3.456, 2);   -- 3.46
SELECT ROUND(3.456);      -- 3 (до целого)
SELECT CEIL(3.1);         -- 4
SELECT FLOOR(3.9);        -- 3
SELECT TRUNC(3.789, 2);   -- 3.78 (не округляет, просто обрезает!)
```

---

## 🔴 Приведение типов

```sql
-- :: — оператор приведения (PostgreSQL-синтаксис)
SELECT 3.7::INTEGER;                    -- 3 (обрезает)
SELECT '3.14'::NUMERIC;                 -- 3.14
SELECT '2025-10-16'::DATE;
SELECT AVG(price)::NUMERIC(10,2);       -- округлить AVG

-- CAST — стандартный SQL
SELECT CAST(3.7 AS INTEGER);            -- 3
SELECT CAST('3.14' AS NUMERIC);
```

---

## ✅ Главные правила

✅ `::TYPE` — краткое приведение типа (PostgreSQL-специфика)  
✅ `TRUNC` не округляет — просто обрезает  
✅ `RANDOM()` возвращает 0..1 — для диапазона умножай
