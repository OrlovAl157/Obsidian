# 🕒 Функции даты и времени — памятка

> PostgreSQL имеет богатый набор функций для работы с датой и временем. Ключевые отличия от MySQL: `NOW()` возвращает `TIMESTAMPTZ`, `INTERVAL` вместо числовых дней, функции `DATE_TRUNC`, `EXTRACT`, `AGE`.

## Справка

| Функция | Описание |
|---|---|
| `NOW()` | текущая дата и время с TZ |
| `CURRENT_TIMESTAMP` | то же что NOW() |
| `CURRENT_DATE` | текущая дата |
| `CURRENT_TIME` | текущее время |
| `EXTRACT(field FROM dt)` | извлечь часть даты |
| `DATE_PART(field, dt)` | то же что EXTRACT |
| `DATE_TRUNC(field, dt)` | усечь до точности |
| `AGE(dt1, dt2)` | разница в виде INTERVAL |
| `TO_CHAR(dt, format)` | дата в строку |
| `TO_TIMESTAMP(str, format)` | строка в дату |
| `DATE_PART + INTERVAL` | арифметика с датами |

---

## 🟢 Текущее время

```sql
SELECT NOW();                  -- 2025-10-16 14:30:00.123456+03
SELECT CURRENT_TIMESTAMP;      -- то же
SELECT CURRENT_DATE;           -- 2025-10-16
SELECT CURRENT_TIME;           -- 14:30:00.123456+03
SELECT NOW()::DATE;            -- 2025-10-16 (приведение к DATE)
SELECT NOW()::TIME;            -- 14:30:00.123456
```

---

## 🔵 Извлечение частей

```sql
SELECT EXTRACT(YEAR  FROM NOW());    -- 2025
SELECT EXTRACT(MONTH FROM NOW());    -- 10
SELECT EXTRACT(DAY   FROM NOW());    -- 16
SELECT EXTRACT(HOUR  FROM NOW());    -- 14
SELECT EXTRACT(DOW   FROM NOW());    -- 4 (день недели, 0=вс)
SELECT EXTRACT(EPOCH FROM NOW());    -- Unix timestamp

-- DATE_TRUNC — усечь до нужной точности
SELECT DATE_TRUNC('month', NOW());    -- 2025-10-01 00:00:00+03
SELECT DATE_TRUNC('year',  NOW());    -- 2025-01-01 00:00:00+03
SELECT DATE_TRUNC('hour',  NOW());    -- 2025-10-16 14:00:00+03
```

---

## 🔴 Арифметика

```sql
-- Прибавить интервал
SELECT NOW() + INTERVAL '7 days';
SELECT NOW() + INTERVAL '1 month 2 weeks 3 days';
SELECT NOW() - INTERVAL '1 year';

-- Разница между датами
SELECT AGE(NOW(), '1990-05-15'::DATE);   -- 35 years 5 months 1 day

-- Количество дней
SELECT ('2025-12-31'::DATE - '2025-01-01'::DATE);  -- 364

-- Попасть в начало недели/месяца
SELECT DATE_TRUNC('week', NOW());
SELECT DATE_TRUNC('month', NOW());
```

---

## 🟡 Форматирование

```sql
-- Дата → строка
SELECT TO_CHAR(NOW(), 'DD.MM.YYYY');            -- 16.10.2025
SELECT TO_CHAR(NOW(), 'DD.MM.YYYY HH24:MI:SS'); -- 16.10.2025 14:30:00
SELECT TO_CHAR(NOW(), 'Day, DD Month YYYY');     -- Thursday, 16 October 2025

-- Строка → дата
SELECT TO_TIMESTAMP('16.10.2025', 'DD.MM.YYYY');
SELECT '2025-10-16'::DATE;                       -- приведение типа
SELECT '2025-10-16 14:30:00'::TIMESTAMP;
```

---

## ✅ Главные правила

✅ Хранить `TIMESTAMPTZ`, не `TIMESTAMP` — учитывает часовые пояса  
✅ `DATE_TRUNC` — для группировки по периодам  
✅ `EXTRACT(EPOCH FROM ...)` — получить Unix timestamp  
✅ `INTERVAL '7 days'` — читаемая арифметика дат  
✅ `AGE()` — человекочитаемая разница дат  
✅ `TO_CHAR` / `TO_TIMESTAMP` — аналог `DATE_FORMAT` / `STR_TO_DATE` в MySQL
