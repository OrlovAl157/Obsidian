## Справка

| Тип | Что возвращает | NULL |
|---|---|---|
| `INNER JOIN` | Только совпадения из A и B | Нет |
| `LEFT JOIN` | Все из A + совпадения из B | Да, для B |
| `RIGHT JOIN` | Все из B + совпадения из A | Да, для A |
| `FULL OUTER JOIN` | Все из A и B | Да, с обеих сторон |
| `LEFT EXCLUDING` | Только из A, которых нет в B | — |
| `RIGHT EXCLUDING` | Только из B, которых нет в A | — |

## 🔵 INNER JOIN

```
A ∩ B — только пересечение
( A  ( A∩B )  B )
       ████
```

```sql
SELECT * FROM A
INNER JOIN B ON A.id = B.id;
```

---

## 🟢 LEFT JOIN

```
Вся A + пересечение с B
( A  ( A∩B )  B )
 ████████
```

```sql
SELECT * FROM A
LEFT JOIN B ON A.id = B.id;
```

---

## 🟡 RIGHT JOIN

```
Вся B + пересечение с A
( A  ( A∩B )  B )
        ████████
```

```sql
SELECT * FROM A
RIGHT JOIN B ON A.id = B.id;
```

---

## 🟣 FULL OUTER JOIN

```
Вся A и вся B
( A  ( A∩B )  B )
 ████████████████
```

MySQL не поддерживает напрямую — эмулируется через UNION:

```sql
SELECT * FROM A LEFT JOIN B ON A.id = B.id
UNION
SELECT * FROM A RIGHT JOIN B ON A.id = B.id;
```

---

## 🔴 Исключающие JOIN

**LEFT EXCLUDING — только из A, которых нет в B:**

```
( A  (      )  B )
 ████
```

```sql
SELECT * FROM A
LEFT JOIN B ON A.id = B.id
WHERE B.id IS NULL;
```

&nbsp;

**RIGHT EXCLUDING — только из B, которых нет в A:**

```
( A  (      )  B )
                ████
```

```sql
SELECT * FROM A
RIGHT JOIN B ON A.id = B.id
WHERE A.id IS NULL;
```

---

## ✅ Главные правила

✅ `INNER JOIN` — только совпадения, строгий фильтр  
✅ `LEFT JOIN` — все из левой, NULL если нет совпадения справа  
✅ `RIGHT JOIN` — все из правой, NULL если нет совпадения слева  
✅ `WHERE B.id IS NULL` после LEFT JOIN — исключить совпадения  
✅ MySQL не имеет FULL OUTER JOIN — используй `LEFT JOIN UNION RIGHT JOIN`  
✅ `USING(col)` — короткий синтаксис когда столбец называется одинаково
