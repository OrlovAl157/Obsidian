# 📜 Процедуры (Stored Procedures) — памятка

> Хранимая процедура — набор SQL-операторов сохранённых на сервере. Вызывается через `CALL`. В отличие от функции — может изменять данные, возвращать несколько результатов, работать с транзакциями.

## Справка

| Синтаксис | Что делает |
|---|---|
| `CREATE PROCEDURE p() BEGIN ... END` | создать процедуру |
| `CALL p()` | вызвать процедуру |
| `DROP PROCEDURE p` | удалить процедуру |
| `DROP PROCEDURE IF EXISTS p` | удалить если существует |
| `SHOW PROCEDURE STATUS` | список всех процедур |
| `SHOW CREATE PROCEDURE p` | код процедуры |
| `IN param TYPE` | входной параметр |
| `OUT param TYPE` | выходной параметр |
| `INOUT param TYPE` | входной и выходной |
| `DECLARE var TYPE DEFAULT val` | локальная переменная |

## 📊 Общая схема

```
Создание:
DELIMITER //
CREATE PROCEDURE proc_name(IN p1 TYPE, OUT p2 TYPE)
BEGIN
    DECLARE local_var TYPE DEFAULT value;
    -- SQL операторы
    SET p2 := result;
END //
DELIMITER ;

Вызов:
SET @out_var = NULL;
CALL proc_name(input_value, @out_var);
SELECT @out_var;

Отличие от функции:
├── Функция:   SELECT func(args) → одно значение
└── Процедура: CALL proc(args)  → изменения, несколько SELECT, OUT параметры
```

## 🟢 Создание процедуры

**Простейшая процедура (SELECT):**

```sql
DELIMITER //
CREATE PROCEDURE GET_GOOD_STUDENTS()
BEGIN
    SELECT id, name, surname, grade
    FROM Math
    WHERE grade >= 4;
END //
DELIMITER ;

CALL GET_GOOD_STUDENTS();

-- Результат:
-- id | name  | surname | grade
--  2 | Peter | Parker  | 5
--  4 | Gwen  | Stacy   | 4
--  5 | Harry | Osborn  | 5
```

**Процедура изменяющая данные:**

```sql
DELIMITER //
CREATE PROCEDURE DELETE_FAILED_STUDENTS()
BEGIN
    DECLARE deleted_count INT;

    -- Считаем сколько удалим
    SELECT COUNT(*) INTO deleted_count
    FROM Math WHERE grade <= 2;

    -- Удаляем
    DELETE FROM Math WHERE grade <= 2;

    -- Показываем результат
    SELECT deleted_count AS deleted_students;
END //
DELIMITER ;

CALL DELETE_FAILED_STUDENTS();
-- deleted_students: 4
```

## 🔵 Параметры IN, OUT, INOUT

**IN — входной параметр:**

```sql
DELIMITER //
CREATE PROCEDURE STUDENTS_BY_GRADE(IN min_grade INT, IN max_grade INT)
BEGIN
    SELECT id, name, surname, grade
    FROM Math
    WHERE grade BETWEEN min_grade AND max_grade;
END //
DELIMITER ;

CALL STUDENTS_BY_GRADE(3, 5);
CALL STUDENTS_BY_GRADE(4, 4);
```

**OUT — выходной параметр:**

```sql
DELIMITER //
CREATE PROCEDURE GET_MAX_GRADE(OUT max_score INT)
BEGIN
    SET max_score := (SELECT MAX(grade) FROM Math);
END //
DELIMITER ;

SET @result = NULL;
CALL GET_MAX_GRADE(@result);
SELECT @result;   -- 5
```

**INOUT — и входной и выходной:**

```sql
DELIMITER //
CREATE PROCEDURE DOUBLE_VALUE(INOUT val INT)
BEGIN
    SET val := val * 2;
END //
DELIMITER ;

SET @num := 5;
CALL DOUBLE_VALUE(@num);
SELECT @num;   -- 10
```

**Несколько OUT параметров:**

```sql
DELIMITER //
CREATE PROCEDURE GET_GRADE_STATS(
    OUT min_g INT,
    OUT max_g INT,
    OUT avg_g DECIMAL(5,2)
)
BEGIN
    SELECT MIN(grade), MAX(grade), AVG(grade)
    INTO min_g, max_g, avg_g
    FROM Math;
END //
DELIMITER ;

SET @min = NULL, @max = NULL, @avg = NULL;
CALL GET_GRADE_STATS(@min, @max, @avg);
SELECT @min, @max, @avg;
-- 1 | 5 | 3.60
```

## 🔴 Условия и циклы

**IF-ELSEIF-ELSE:**

```sql
DELIMITER //
CREATE PROCEDURE CLASSIFY_STUDENT(IN student_id INT)
BEGIN
    DECLARE student_grade INT;
    DECLARE classification VARCHAR(20);

    SELECT grade INTO student_grade
    FROM Math WHERE id = student_id;

    IF student_grade >= 5 THEN
        SET classification := 'Отличник';
    ELSEIF student_grade >= 4 THEN
        SET classification := 'Хорошист';
    ELSEIF student_grade >= 3 THEN
        SET classification := 'Троечник';
    ELSE
        SET classification := 'Отстающий';
    END IF;

    SELECT student_id, student_grade, classification;
END //
DELIMITER ;

CALL CLASSIFY_STUDENT(2);
```

**WHILE:**

```sql
DELIMITER //
CREATE PROCEDURE INSERT_N_ROWS(IN n INT)
BEGIN
    DECLARE i INT DEFAULT 1;

    WHILE i <= n DO
        INSERT INTO TestTable (num) VALUES (i);
        SET i := i + 1;
    END WHILE;

    SELECT CONCAT('Добавлено ', n, ' строк') AS result;
END //
DELIMITER ;

CALL INSERT_N_ROWS(5);
```

**CASE:**

```sql
DELIMITER //
CREATE PROCEDURE GRADE_ACTION(IN grade INT)
BEGIN
    CASE grade
        WHEN 5 THEN SELECT 'Молодец!';
        WHEN 4 THEN SELECT 'Хорошо!';
        WHEN 3 THEN SELECT 'Надо лучше';
        ELSE SELECT 'Двоечник!';
    END CASE;
END //
DELIMITER ;
```

## 🟡 Курсоры

Курсор позволяет перебирать строки результата SELECT построчно:

```sql
DELIMITER //
CREATE PROCEDURE PROCESS_STUDENTS()
BEGIN
    DECLARE done INT DEFAULT 0;
    DECLARE student_name VARCHAR(50);
    DECLARE student_grade INT;

    -- Объявляем курсор
    DECLARE cur CURSOR FOR
        SELECT name, grade FROM Math ORDER BY grade DESC;

    -- Обработчик конца данных
    DECLARE CONTINUE HANDLER FOR NOT FOUND SET done := 1;

    -- Открываем курсор
    OPEN cur;

    read_loop: LOOP
        -- Читаем следующую строку
        FETCH cur INTO student_name, student_grade;

        -- Если строк нет — выходим
        IF done = 1 THEN
            LEAVE read_loop;
        END IF;

        -- Обрабатываем строку
        SELECT CONCAT(student_name, ': ', student_grade) AS info;
    END LOOP;

    -- Закрываем курсор
    CLOSE cur;
END //
DELIMITER ;

CALL PROCESS_STUDENTS();
```

## 🟣 Обработка ошибок

```sql
DELIMITER //
CREATE PROCEDURE SAFE_DELETE(IN student_id INT)
BEGIN
    DECLARE EXIT HANDLER FOR SQLEXCEPTION
    BEGIN
        -- Обработка любой SQL ошибки
        SELECT 'Ошибка при удалении' AS error_message;
        ROLLBACK;
    END;

    START TRANSACTION;

    DELETE FROM Math WHERE id = student_id;

    -- Проверяем что удалили хотя бы одну строку
    IF ROW_COUNT() = 0 THEN
        SIGNAL SQLSTATE '45000'
        SET MESSAGE_TEXT = 'Студент не найден';
    END IF;

    COMMIT;
    SELECT 'Успешно удалён' AS result;
END //
DELIMITER ;

CALL SAFE_DELETE(1);
CALL SAFE_DELETE(999);  -- 'Студент не найден'
```

## ⚡ Быстрые примеры

```sql
-- Простой SELECT
CREATE PROCEDURE get_all() BEGIN SELECT * FROM Books; END;
CALL get_all();

-- С параметром
CREATE PROCEDURE get_by_price(IN min_p DECIMAL(10,2))
BEGIN SELECT * FROM Books WHERE price >= min_p; END;
CALL get_by_price(10.00);

-- OUT параметр
CREATE PROCEDURE book_count(OUT cnt INT)
BEGIN SET cnt := (SELECT COUNT(*) FROM Books); END;
SET @cnt = NULL;
CALL book_count(@cnt);
SELECT @cnt;

-- С транзакцией
CREATE PROCEDURE transfer(IN from_id INT, IN to_id INT, IN amount DECIMAL)
BEGIN
    START TRANSACTION;
    UPDATE accounts SET balance = balance - amount WHERE id = from_id;
    UPDATE accounts SET balance = balance + amount WHERE id = to_id;
    COMMIT;
END;
CALL transfer(1, 2, 100.00);
```

## 💡 Практические замечания

- Процедура вызывается только через `CALL` — нельзя в `SELECT`
- `OUT` параметры передаются как `@переменная` — нельзя передать литерал
- Процедура может вернуть несколько результирующих наборов через несколько `SELECT`
- Курсоры медленнее чем массовые SQL операции — используй только когда нужна построчная обработка
- Транзакции в процедурах — удобное место для атомарных операций

## ⚠️ Частые ошибки

**❌ Передача литерала в OUT параметр:**
```sql
CALL GET_MAX_GRADE(5);       -- ❌ OUT параметр должен быть переменной!
CALL GET_MAX_GRADE(@result); -- ✅
```

**❌ Использование CALL в SELECT:**
```sql
SELECT CALL GET_GOOD_STUDENTS();  -- ❌ нельзя!
CALL GET_GOOD_STUDENTS();         -- ✅ просто вызов
```

**❌ DECLARE после первого оператора:**
```sql
BEGIN
    SELECT 1;         -- оператор
    DECLARE x INT;    -- ❌ DECLARE должен быть в начале BEGIN!
END;

BEGIN
    DECLARE x INT;    -- ✅ сначала все DECLARE
    SELECT 1;
END;
```

**❌ Курсор без HANDLER:**
```sql
-- Без HANDLER при конце данных будет ошибка NOT FOUND
-- Всегда объявляй:
DECLARE CONTINUE HANDLER FOR NOT FOUND SET done := 1;
```

## ✅ Главные правила

✅ Вызов только через `CALL proc_name(args)`  
✅ `IN` — входной, `OUT` — выходной, `INOUT` — оба  
✅ `OUT` и `INOUT` — только через `@переменная`, не литерал  
✅ `DECLARE` — в самом начале `BEGIN`, до любых операторов  
✅ Транзакции (`START TRANSACTION`, `COMMIT`, `ROLLBACK`) — в процедурах работают  
✅ Курсоры — для построчной обработки, медленнее массовых операций  
✅ `DROP PROCEDURE IF EXISTS` — безопасное удаление  
✅ `DELIMITER //` — обязателен для многострочного тела
