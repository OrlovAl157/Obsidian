# 🧮 Переменные в SQL — памятка

> В MySQL три вида переменных: пользовательские (`@var`) — живут в сессии, локальные (`DECLARE`) — только внутри процедуры/функции, системные (`@@var`) — настройки сервера.

## Справка

| Тип | Синтаксис | Область видимости |
|---|---|---|
| Пользовательская | `@var_name` | Текущая сессия |
| Локальная | `DECLARE var TYPE` | Внутри BEGIN...END |
| Системная сессионная | `@@var` или `@@session.var` | Текущая сессия |
| Системная глобальная | `@@global.var` | Весь сервер |

| Операция | Синтаксис |
|---|---|
| Присвоить | `SET @var := value` |
| Присвоить из SELECT | `SET @var := (SELECT ...)` или `SELECT ... INTO @var` |
| Прочитать | `SELECT @var` |
| Объявить локальную | `DECLARE var TYPE DEFAULT value` |
| Задать системную | `SET @@var := value` |
| Читать системную | `SELECT @@var` |

---

## 📊 Общая схема

```
@var — пользовательская:
  SET @x := 10;           ← живёт пока сессия активна
  SELECT @x;              ← 10
  -- после DISCONNECT исчезнет

DECLARE — локальная (только в процедуре/функции):
  BEGIN
      DECLARE x INT DEFAULT 0;  ← живёт только в этом блоке
      SET x := 10;
  END;
  -- за пределами BEGIN/END недоступна

@@ — системная:
  SELECT @@version;          ← версия сервера
  SET @@sort_buffer_size := 262146;  ← изменить настройку сессии
```

## 🟢 Пользовательские переменные @

Начинаются с `@`. Не требуют объявления. Живут до конца сессии.

```sql
-- Простое присвоение
SET @variable := 1;
SELECT @variable;
-- 1

-- Несколько переменных сразу
SET @x := 10,
    @y := 20,
    @z := 30;

SELECT @x, @y, @z;
-- 10 | 20 | 30

-- Вычисление
SET @total := @x + @y + @z;
SELECT @total;
-- 60

-- Строковая переменная
SET @greeting := 'Привет';
SELECT CONCAT(@greeting, ', Мир!');
-- Привет, Мир!

-- NULL по умолчанию если не задана
SELECT @undefined_var;
-- NULL

-- Использование в запросах
SET @min_price := 10.00;
SELECT * FROM Books WHERE price >= @min_price;

SET @dept := 'IT';
UPDATE Employees SET salary = salary * 1.1 WHERE department = @dept;
```

## 🔵 Локальные переменные DECLARE

Только внутри `BEGIN...END` процедур и функций. Требуют объявления. Строго типизированы.

```sql
DELIMITER //
CREATE PROCEDURE SHOW_STATS()
BEGIN
    -- DECLARE всегда в начале BEGIN
    DECLARE total_books INT;
    DECLARE avg_price DECIMAL(10, 2);
    DECLARE max_price DECIMAL(10, 2) DEFAULT 0;  -- с DEFAULT

    -- Присвоение
    SET total_books := (SELECT COUNT(*) FROM Books);
    SET avg_price := (SELECT AVG(price) FROM Books);

    SELECT MAX(price) INTO max_price FROM Books;

    -- Использование
    SELECT total_books, avg_price, max_price;
END //
DELIMITER ;

CALL SHOW_STATS();
```

**Типы данных для DECLARE:**

```sql
DECLARE n INT DEFAULT 0;
DECLARE price DECIMAL(10, 2) DEFAULT 0.00;
DECLARE name VARCHAR(100) DEFAULT '';
DECLARE flag BOOLEAN DEFAULT FALSE;
DECLARE dt DATE DEFAULT NULL;
DECLARE ts TIMESTAMP DEFAULT CURRENT_TIMESTAMP;
```

**Локальная переменная в условиях:**

```sql
DELIMITER //
CREATE FUNCTION CHECK_STOCK(product_id INT)
RETURNS VARCHAR(20)
NOT DETERMINISTIC READS SQL DATA
BEGIN
    DECLARE stock_count INT;
    DECLARE status VARCHAR(20);

    SELECT amount INTO stock_count FROM Books WHERE id = product_id;

    IF stock_count IS NULL THEN
        SET status := 'Не найден';
    ELSEIF stock_count = 0 THEN
        SET status := 'Нет в наличии';
    ELSEIF stock_count < 5 THEN
        SET status := 'Мало';
    ELSE
        SET status := 'В наличии';
    END IF;

    RETURN status;
END //
DELIMITER ;
```

## 🔴 Системные переменные @@

Начинаются с `@@`. Управляют поведением сервера MySQL.

**Просмотр:**

```sql
-- Версия сервера
SELECT @@version;

-- Текущая БД
SELECT @@database;

-- Кодировка
SELECT @@character_set_client;

-- Максимальный размер пакета
SELECT @@max_allowed_packet;

-- Глобальное vs сессионное значение
SELECT @@global.sort_buffer_size;
SELECT @@session.sort_buffer_size;
SELECT @@sort_buffer_size;  -- сессионное по умолчанию
```

**Изменение:**

```sql
-- Изменить сессионную (только для текущего соединения)
SET @@sort_buffer_size := 262146;
SET @@session.sort_buffer_size := 262146;  -- то же самое явно

-- Изменить глобальную (для всех новых соединений)
SET @@global.sort_buffer_size := 262146;   -- нужны права SUPER
```

**Полезные системные переменные:**

| Переменная | Что делает |
|---|---|
| `@@version` | версия MySQL |
| `@@database` | текущая БД |
| `@@autocommit` | авто-коммит транзакций (1/0) |
| `@@foreign_key_checks` | проверка внешних ключей (1/0) |
| `@@sql_mode` | режим SQL |
| `@@cte_max_recursion_depth` | глубина рекурсивных CTE |
| `@@max_allowed_packet` | макс. размер пакета |
| `@@time_zone` | часовой пояс |

**Практические примеры:**

```sql
-- Отключить проверку внешних ключей при массовом импорте
SET @@foreign_key_checks := 0;
-- ... массовая вставка данных ...
SET @@foreign_key_checks := 1;

-- Отключить автокоммит для ручного управления транзакциями
SET @@autocommit := 0;
-- ... операции ...
COMMIT;
SET @@autocommit := 1;

-- Увеличить глубину рекурсии CTE
SET @@cte_max_recursion_depth := 10000;
```

## 🟡 Присвоение из SELECT

Два способа получить значение из запроса в переменную:

```sql
-- Способ 1: SET + подзапрос
SET @min_price := (SELECT MIN(price) FROM Books);
SET @max_price := (SELECT MAX(price) FROM Books);

-- Способ 2: SELECT INTO
SELECT MIN(price), MAX(price)
INTO @min_price, @max_price
FROM Books;

SELECT @min_price, @max_price;
-- 3.49 | 15.99

-- В процедуре с локальными переменными
DECLARE min_p DECIMAL(10, 2);
SELECT MIN(price) INTO min_p FROM Books;

-- Присвоение из вычисления
SET @discount := @min_price * 0.9;
SET @range := @max_price - @min_price;
```

## ⚡ Быстрые примеры

```sql
-- Пользовательские
SET @x := 42;
SET @name := 'Alice';
SELECT @x, @name;

-- В запросе
SET @limit := 5;
SELECT * FROM Books ORDER BY price DESC LIMIT @limit;  -- ⚠️ LIMIT не принимает переменные напрямую

-- Через prepared statement
SET @sql := CONCAT('SELECT * FROM Books LIMIT ', @limit);
PREPARE stmt FROM @sql;
EXECUTE stmt;
DEALLOCATE PREPARE stmt;

-- Из SELECT
SET @cnt := (SELECT COUNT(*) FROM Books);
SELECT COUNT(*) INTO @cnt FROM Books;

-- Системные
SELECT @@version, @@database, @@autocommit;
SET @@foreign_key_checks := 0;
SET @@cte_max_recursion_depth := 5000;

-- Локальные (в процедуре)
DELIMITER //
CREATE PROCEDURE demo()
BEGIN
    DECLARE x INT DEFAULT 0;
    DECLARE msg VARCHAR(50);
    SET x := 42;
    SET msg := CONCAT('Значение: ', x);
    SELECT msg;
END //
DELIMITER ;
```

## 💡 Практические замечания

- Пользовательские `@var` не требуют объявления — неопределённая переменная = `NULL`
- Локальные `DECLARE` обязательно в начале `BEGIN`, до любых операторов
- `SET @var := value` и `SET @var = value` — оба работают, `:=` предпочтительнее
- `@@foreign_key_checks := 0` — удобно при массовом импорте, не забудь вернуть в 1
- Пользовательские переменные не типизированы — могут менять тип

## ⚠️ Частые ошибки

**❌ DECLARE не в начале BEGIN:**
```sql
BEGIN
    SET @x := 1;
    DECLARE y INT;  -- ❌ ошибка! DECLARE должен быть до SET
END;

BEGIN
    DECLARE y INT;  -- ✅ сначала все DECLARE
    SET @x := 1;
END;
```

**❌ Использование локальной переменной вне блока:**
```sql
DELIMITER //
CREATE PROCEDURE test()
BEGIN
    DECLARE x INT DEFAULT 10;
END //
DELIMITER ;

CALL test();
SELECT x;   -- ❌ x недоступна вне процедуры
SELECT @x;  -- ❌ это другая переменная (пользовательская), она NULL
```

**❌ Забыл вернуть foreign_key_checks:**
```sql
SET @@foreign_key_checks := 0;
-- ... вставка данных ...
-- ❌ забыл вернуть! Теперь ключи не проверяются во всей сессии
SET @@foreign_key_checks := 1;  -- ✅ обязательно вернуть
```

**❌ SELECT с несколькими строками в SET:**
```sql
SET @price := (SELECT price FROM Books WHERE author_id = 1);
-- ❌ если подзапрос вернёт несколько строк — ошибка!
-- Используй LIMIT 1 или агрегат:
SET @price := (SELECT MIN(price) FROM Books WHERE author_id = 1);
```

## ✅ Главные правила

✅ `@var` — пользовательская, живёт в сессии, не требует объявления  
✅ `DECLARE var TYPE` — локальная, только внутри BEGIN...END  
✅ `DECLARE` — всегда в начале BEGIN, до любых других операторов  
✅ `@@var` — системная настройка сервера  
✅ `@@session.var` — только текущее соединение, `@@global.var` — весь сервер  
✅ `SET @var := (SELECT ...)` или `SELECT ... INTO @var` — из запроса  
✅ `@@foreign_key_checks := 0` — не забудь вернуть в 1 после!  
✅ Неопределённая `@var` возвращает `NULL`, не ошибку
